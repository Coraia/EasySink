# V1.1 阅读闭环交互原型

用户体验入口：<http://127.0.0.1:8766/static/prototypes/v11-reading-loop/index.html?session=experience>。
无参数入口用于本轮走查。两者各自保存原型记录，均不接入正式数据库。

## 可操作范围

- 真实鼠标拖选（含部分单词与跨段）、拖动或方向键调整端点、划线并集合并、整条删除与撤销。
- 基础候选释义、短语整体注释、中文缺失示例；收藏词语、已掌握、保留注释独立。
- 预设语境解释、实际示例上下文展示、本地结果保存、收藏解释先看后采用与旧解释历史。
- 引用笔记自动保存、编辑和删除；我的释义独立保存；本书收藏和全局收藏筛选。
- 书架再次遇见（当天固定、换一条、暂不推荐、持续隐藏），来源预览与明确继续读，来源不可定位快照。
- 演示资料导出预览/下载和独立清理范围；正式迁移格式另定。

这是交互原型，不是 V1.1 正式实现。词典与 AI 内容预设，无模型调用或费用；原版/翻译/语法/语音提供入口说明。两节材料模拟续读位置，不替代正式分页和纸张翻页。

## 文件

- `index.html`：独立页面与浮层容器。
- `style.css`：沿用产品色彩和字体的响应式样式。
- `app.js`：示例数据、独立状态与可操作交互。
