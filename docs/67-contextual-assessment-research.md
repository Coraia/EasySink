## 判断与方法比较

**研究判断（推断）**：可复用的是“背景测量＋无提示的语境核验＋覆盖未标注内容的抽样”方法组合。现有证据不支持将词汇量、查词、收藏、保留注释或没有操作直接作为个人语境帮助需求的真值。词汇辨认、接受性词汇量、理解表现和想看注释是不同对象；依据如下。

| 方法 | 已有事实与一手来源 | 中文读者适用界限／项目推断 |
|---|---|---|
| LexTALE | 60项词／非词判断；原研究为荷兰语、韩语背景学习者，验证词汇知识及相关表现。[原论文，方法部分](https://lextale.com/pdf/Lemhofer_Broersma_2012.pdf) | 适合作背景参考；不直接测当前词义理解，也不能将该人群验证推广为中文读者或全产品验证。官方定位中高水平第二语言使用者。[官方说明](https://lextale.com/whatislextale.html) |
| Vocabulary Size Test（VST） | 原版140题，测书面接受性词汇量；短句是非定义性语境，不能等同真实篇章理解。[Nation与Beglar，2007，页9–13](https://jalt-publications.org/sites/default/files/pdf/the_language_teacher/07_2007tlt.pdf) | 中文短版有177名中国大学生、三个水平组的初步效度证据，同时指出借词问题；本轮核对到出版方摘要，不能扩展到全部年龄、水平及表达类型。[Zhao与Ji，2018](https://journals.sagepub.com/doi/10.1177/0033688216639761) |
| 自评／掌握反馈 | Ross的研究报告自评效度随被评技能经验而异；包含236名学习者的实证部分。[原文摘要](https://journals.sagepub.com/doi/abs/10.1177/026553229801500101) | 可作为简短声明入口，实际负担待验；不是独立理解证据。“认识”“此处理解”“想保留解释”应分开记录。 |
| 语境题／意义解释核验 | CWI 2018在句段中收集词与多词表达的困难判断，并避免预先高亮候选；它并非个人理解考试。[原报告，第3节](https://aclanthology.org/W18-0507.pdf) | 可借鉴原文锚点和开放发现困难处；群体困难标签不能替代中文读者本人无提示理解证据。 |
| 主动校准 | 主动学习研究指出不确定性采样并非总胜过随机采样；非均匀抽样涉及权重与方差。[Imberg等，2020](https://proceedings.mlr.press/v108/imberg20a/imberg20a.pdf) | 可优先询问有争议处以更新个人判断，但校准样本不能兼作无偏验收集；本产品收益未验证。 |

## 建议执行流程：采样与核验，不建立新量表

以下全部是**项目设计建议，尚未试行**。不制作新标准化测验，也不把自编少量语境题称为已验证量表。

1. **先冻结测量对象。** 记录读者、书籍、篇章、原文锚点、语境、时间及转换版本。建议正类为“未见辅助时，对该处含义的理解不足，影响当前句段理解”。由本人简短说明含义，人工据原文判断充分／不足／无法判断；它是操作性代理标签，不证明提供注释一定有益。另记想看／保留注释的偏好。跳过、未回答、题意不清不得算负类。
2. **先排来源错误。** 对抽中位置核对原版；分列OCR／阅读顺序错误、目标范围错误、解释词义错误、读者理解不足和主动偏好。来源损坏项不用于纯理解识别指标，但须计入整链失败清单与覆盖率，不能删掉后宣称全链准确。
3. **抽查系统没有选中的内容。** 先固定阅读片段和候选范围规则，再按系统拟展示／未展示两层随机抽样，记录各层总数、抽中数、抽样概率和随机种子。另抽整段人工巡视，以发现候选生成器遗漏的表达；该发现清单另报，不能直接混入词级F1。只检查已标注项目属于选择性核验问题；遗漏未核验者会造成偏差。[Begg与Greenes原研究摘要](https://asu.elsevierpure.com/en/publications/assessment-of-diagnostic-tests-when-disease-verification-is-subje/)
4. **核验先于提示。** 冻结预测，不向读者或判读者展示系统分数；在首次呈现的无辅助语境取得理解证据后，才看解释并记录帮助与打断。已看过释义、译文或选项者单列，不能靠隐藏界面恢复为“未暴露”。原始“不会”与“暂不回答”分别记录。中国大学生研究表明，“不知道”选项也会改变猜测和部分知识表达，不能随意改造标准测试并沿用原分数解释。[Zhang，2013摘要](https://onlinelibrary.wiley.com/doi/abs/10.1002/tesq.98)
5. **约束负担、隔离校准。** 在自然阅读停顿处做少量核验；可先提出每次最多4处、额外不超过2分钟的试行上限，由读者决定是否接受。这是工作量预算，不是有效样本量或体验承诺。允许随时停止并保留未完成项。主动校准另池记录，可混合争议处与随机探索；不能只询问模型最不确定的位置，再据此宣布准确率。
6. **固定密度与解释质量再比较选择。** 比较策略时先固定自动辅助数量预算、显示形式和解释版本；保留注释另计。分别报告“选择正确”“实际展示正确”“解释符合语境”；密度截断造成的漏展示与识别漏判分开。改变密度的实验另做，避免更多注释自然提高召回却掩盖阅读打断。

## 防泄漏、指标与不确定性

**事实依据**：测试本身可改变后续记忆，重复题不是独立的新证据。[Roediger与Karpicke原研究摘要](https://journals.sagepub.com/doi/abs/10.1111/j.1467-9280.2006.01693.x?journalCode=pssa) 分组、时间依赖数据不适合直接套用独立同分布随机拆分。[scikit-learn官方说明](https://scikit-learn.org/stable/modules/cross_validation.html)

**建议**：先按原文出处合并重复、近重复和相邻重叠语境，再区分三项评估：同读者未来时间段、未见过的书籍、未见过的语境。不同版本同书及改写题不得跨组泄漏；同词不同语境与新词分层报告。有多名读者时另做留出读者评估。校准反馈只能用于之后的预测，验收标签不参与本轮调参；重复题留作暴露后观察，不并入首次判断。

报告TP、FP、FN、TN及分母；F1采用正类口径 `2TP/(2TP+FP+FN)`，同时给precision、recall，分母为零写“不可估”。[F1官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.f1_score.html) 两层抽样比例不同时，按已知纳入概率加权混淆计数，再求比值；这不保证小样本F1无偏。未响应不能仅靠抽样权重消除，需报告各层缺失和结论敏感性。

**建议**：与F1并行报告每千原文词的自动注释数、每次阅读被打断次数、辅助占用时间、主动查阅和主观干扰；将研究提问耗时单列。查阅次数不作为理解真值，也不预设越少越好。保存逐次记录，而不只报均值。

**统计边界**：Wilson／精确二项区间有各自假设，不能把同一人同书的相邻词当成大量独立试验。[NIST说明](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm) 聚类相关可使常规标准误过小，少量簇仍有推断困难。[Cameron与Miller，2015](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf) 单用户优先给逐书、逐次的计数、范围和失败案例；不报总体人群置信度。将来具备足够独立簇后，才考虑按读者／书／时段重采样并说明假设；不能用逐词bootstrap制造窄区间。没有正例、簇不足或缺失过多时保留“无法判断”，不承诺F1目标。
