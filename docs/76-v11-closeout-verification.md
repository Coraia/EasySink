## 加强领域的实际作用

过去真实词典候选缺少领域信息，设置提升规则不代表正文会改变。本轮只为七个有精确词典证据的条目补充领域，已有分析缓存会随源码身份失效。

在真实原文、固定词汇量8000/辅助密度1的隔离阅读器中，宗教领域使 `monotheism` 进入辅助预算，技术领域使 `codec` 进入辅助预算；清空领域分别恢复原候选。没有为 `grace`、`thread`、`bank`、`class` 等多义词强行贴领域标签。**七词证据不是全领域覆盖，也不是 V2 词汇量/F1 验收。** [来源与限制](parallel/v11-closeout-domains-status.md)、[界面走查](../outputs/v11-closeout-20261011/domains/ui-walkthrough.json)。

同一实际供应商、固定30条真实例句，v8和v9最终批次均为26条达到原判据、4条失败。v9仍有未给出的经文和神学对照、将 `thread` 扩为“线程锁”、遗漏 Python 版本限定。没有把定向四条通过替代最终三十条；没有改变原判据。新增真实调用共67次，自动重试0；缓存、请求重放及重开后历史读取均未新增传输。

停止追加随机重试。纯本地保守校验方案在已有响应上筛查，能命中4份错误，但也拒收11份原本合理的解释；用户明确答复“暂不接受，AI质量另行调整后再验收”，**该路线未接受、未实施**。不能宣称未命中规则就等于语义正确，也不能把离线旧响应筛查称为新一轮真实调用通过。[完整证据与成本](parallel/v11-closeout-ai-status.md)。

- 扫描书相邻阅读范围正向进入首屏、反向返回前范围末屏已走通；EPUB末尾没有绕回首页。
