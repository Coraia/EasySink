# 用户仍看到纸面扭曲：诊断边界

当前正式版20261008-local-root，用户反馈未通过。先复述并确认现象，复现之前不修改生产几何，更换整体模型必须先给原型。

已知覆盖缺口：当前用户单页窗口约796×1135、DPR2.2；前一轮single测试1100×1000。相同归一化手势在不同页宽高比下可能扫过不同书脊高度。前一轮根部倾角、锚点、带外与旧曲面相同不等于整页不扭曲。

诊断失败模式：装订补偿造成材料横/纵向拉伸或剪切；根部局部混合沿y剧烈变化形成局部拧转；圆柱与绑定约束本身互相冲突；纹理投影/法线造成视觉误判；原生手势与鼠标路径并非相同。不能把任何一种数值异常自动当成用户描述的同一个问题。

先通过真实页面/Metal GPU鼠标按住扫过浅中深斜折，读取实际生产shader材料网格，记录最大材料边拉伸（3D实际长度/未变形材料长度）。圆柱离散弦长可以小于材料长度，但超过1.15的拉伸不是透视旋转或弦长导致。该阈值只用于发现不自然材料伸长，不证明视觉完全复现，也不证明所有物理特征。保留最坏姿态截图与完整GPU坐标，正式书籍不被测试写入。

本轮先诊断，单一紧凑E2E，不跑完整套件。累计上限：2种没有进展的复现路径或约10分钟；若不能和用户画面对齐，明确缺失证据，先请用户指明形变位置，不继续堆补丁。不得提高阈值以宣称验收通过。

## 本轮结论

36姿态发现材料边3.70倍伸长；同uniforms旧模型2.87倍，自由圆柱约1.00倍。另一个31%行程场景当前1.2674、旧1.1050。固定书脊补偿本身会伸长，局部补丁在特定姿态继续放大。该发现是GPU因果证据，不能替代和用户当前画面精确对齐。正式版未再次改动，红色回归保留。
