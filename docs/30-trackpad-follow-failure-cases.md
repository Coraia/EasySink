# 跟手触控板翻页：编码前边界（2026-10-07）

替换上一版“累计超过 80px 自动播放完整动画”：一整个横向 wheel 手势驱动同一个纸张预览会话，期间不可提交页码/源文位置；反向输入让折页退回。

失败路径与验收：

- 前进和后退方向错、位移不连续、每次事件重建纸张/上下文、动画速度跟手势无关。通过正反两个方向的实际 wheel 与折页 pin/进度变化验证。
- 到半页提前提交；反向回滑仍因历史累计/速度判定翻页；退到起点后立即翻另一方向；半页以下松手仍提交。明确只在 240ms 无事件后松手结算；最终超过半页且最后有效输入非回滑才提交，其他回弹。
- 本人的预览会话因 animating=true 被当作其他动画拒绝，导致纸页卡住。只对当前触控板会话放宽 busy 条件，其余选区/浮层边界继续执行。
- 手势内惯性重复提交，跨章节重复跳，未完成分页/没有邻页使拖动异常。页面内复用 beginTurn/update/release；章节边界暂用同样可撤销的距离判定，结束后再导航，不冒充跨章连续纸张预览。
- Esc、打开工具、离开页面、窗口失焦、隐藏、排版重排后定时器迟到提交。取消时清定时器/释放 Reader；只注册一次每 Reader 清理钩子，不为每个手势积累 cleanup。
- reduced-motion/关闭动画时提交规则不同，源文 DOM/锚点被提前替换；卡片/笔记/译文滚动穿透；缩放误翻。
- 录屏/截图/断言阻塞造成测试输入间隔超过手势结束阈值。中间状态截图时持续送真实微量 wheel 保持手势；惯性流单独记录实际事件间隔，不把两个手势当一个。
- 软件 GPU 帧率波动，必须保留首次失败，不放宽性能门槛或降低画质来换通过。

手势行程根据纸页宽度换算，限制在 280–600 CSS 像素；每输入帧更新原有 RAF/WebGL 纸张弯曲及光影。Web wheel 无统一的手指离开/惯性结束标志，以无事件 240ms 近似结束；真实 Mac 手感待人工体验。没有页面内新控件。

E2E：跟手正反/撤销/提交/锚点不变、完整惯性单次提交、所有原触控板隔离、布局/动画开关/缩小窗口、取消与路由清理、章节边界可撤销。开发期间仅跑专项，结束后完整套件，并生成 JSON/trace/截图及复现命令。

## 自动化输入的停止边界

软件 GPU 冷启动连续惯性注入多轮出现 256–335ms 的实际空档，超过产品的 240ms 手势定义；停止继续重试这个冷启动自动化用例。惯性单会话 E2E 改为先通过真实前/后翻页准备 GPU/纹理，然后验证连续 warm 输入；独立的冷启动跟手/回滑用例继续保留。不能把 warm 惯性结果作为冷启动实际硬件已通过。
