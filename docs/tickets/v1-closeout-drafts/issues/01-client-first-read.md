## What to build

交付可安装的最小 macOS 候选客户端：用户安装、打开、导入 EPUB、阅读和查词、记笔记、退出重开后继续阅读。复用现有 Web 阅读核心，优先验证系统 WebView；运行时、文件入口、必要词库、应用资料目录与基本进程管理随这条完整路径交付，不另拆前后端或打包工具任务。

本票提供 [客户端原型决策](https://github.com/Coraia/EasySink/issues/34) 所需的第一份可体验产物，不意味着最终框架或正式发行已选定。本票不需要等待全部 PDF 功能或客户端原型决策先完成。

## Acceptance criteria

- [ ] 产出可复现构建的安装包或应用包及版本/摘要；用户无需仓库目录、Python、Xcode、命令行启动或预先运行开发服务，即可安装、启动并到达可操作书架。仅模拟无开发环境时注明限制，不称干净系统安装通过。
- [ ] 从客户端真实文件入口导入固定 EPUB，不点击开始阅读而关闭导入界面后，书仍保留；重新打开默认专注，可用原有点击/键盘翻页、基础词注、原文选择及笔记入口。
- [ ] 笔记、书签和续读位置经退出重开实际回读保持，使用隔离的客户端资料目录，不迁移或覆盖用户现有个人书库；保留既有原文锚点语义。
- [ ] 阅读必需的运行时与词库在可控首次准备后可用；重型 OCR/语音模型不成为每次阅读前置。分别列出安装包、解包、必要资源及可选下载成本，不把小启动器当完整体积。
- [ ] 处理重复启动和端口冲突；只管理可确认属于自身的服务与进程，不杀未知进程、不让客户端误连另一个实例的资料库。正常关闭有明确的基本生命周期，不暗定未来后台驻留政策。
- [ ] 优先系统 WebView 承载并保留既有排版、选区和纸面内容；若出现不能维持阅读质量的兼容阻断，保留首失败及替代路线依据，不以禁用功能或降 DPI 宣称达标。
- [ ] 记录首安装/首次准备、冷启动至可阅读及暖重开的真实时间，不能用健康接口或窗口出现代替正文可操作；此票记录基线，客户端新增预算由最终原型体验决定。
- [ ] 从安装至退出重开完整点击走查，保存包摘要、固定源码、设备/运行条件、步骤、截图或录屏、原始测量及首失败；不新增单元测试，不在开发中运行完整 E2E 套件。
