# 已认可薄纸原型接入正式阅读器：改动前约束

用户认可paper-shape原型并要求进入开发。替换旧的自由圆柱+绑定位移补偿+局部根部补丁，使用原型认可的圆柱退化/圆锥可展曲面、同一可达点求解和沿卷曲线排布网格。

失败模式：复制时曲面/端点求解偏离原型；高/低precision链接不一致；动态网格/书脊诊断线共享错buffer；双页中缝留空导致终点错位；翻页覆盖选区/笔记、词卡滚动归属退步；原生保持/抬手/连续行为变化；DPI或缓存退步；窄高窗口仍伸缩；极细圆锥数值失稳；旧外形比较测试继续约束被用户拒绝的变形；性能测试阈值被放宽或首轮失败被覆盖。

先保存当前正式版文件和输入模块SHA，复跑reader-twist的原有真实GPU失败（材料边3.70倍），再接入。CPU曲面/mesh与已认可原型保持字节一致；正式光影片元保留。仅顶点加入固定书脊距离与诊断字段，renderer切换uniforms/动态buffer。双页纸页共用零间隙中缝，原文稳定锚点保存不变。五个手势/阶段/判定模块不改。没有高precision的设备安全退化到既有无动画导航，不画有数值风险的细锥。

正式E2E覆盖206以上姿态、single796×1135/DPR2.2与double、正反上下、0/微小/大斜移、浅深翻；实际GPU材料边≤1.02、全装订边误差≤1CSSpx、有效抓取点≤1px、非负高度；保留装订线截图检查。取消已不适用的“12%外必须与旧扭曲完全相同”，用用户认可曲面的材料长度、书脊及原型等价性取代，不降低新阈值。旧root/control对照完整归档，不静默skip。

先跑针对性E2E，开发结束再完整套件；保留完整首次失败。原有帧/输入34ms、native收尾240ms、DPR与缓存守卫不放宽。最多两次无进展的性能尝试，仍不达标明确报告。真实phase fixture不同于实机输入，本机更新后核对版本、原文锚点与native接入，物理手感由用户体验验收。

## 首轮完整性能失败的排查

完整套件软件GPU帧守卫34.1ms，阈值34ms。三个可证伪假设：1）像素栅格/片元成本主导，减少仅软件动画像素会降低持续帧间隔；2）纹理准备主导，超时集中于未暖缓存/textureWait；3）调度抖动，充分暖缓存后仍有输入或RAF长间隔，像素调整无持续改善。先只将软件动画和软件纹理匹配预算从400k降至320k，保留硬件DPI和8M/6M预算、静止正文DOM清晰度；同一真实页面12次连续翻页对照。若没有改善，恢复该调整，不以降低清晰度掩盖未定位耗时。保留首次完整结果；末次实际输入模型参数在指标中保存便于后续复现。
