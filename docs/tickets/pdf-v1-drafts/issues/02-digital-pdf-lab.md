## What to build

在隔离入口导入有使用权的数字英文 PDF，形成一个实验书籍条目，查看原版并读取真实提取的有序段落，留下候选转换的真实结果和时间记录。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 从浏览器选择实际 PDF，经本地接收、元数据/来源、转换、持久化与显示闭环；不把文件名或伪造结果当识别成功。
- [ ] 导入完成后不点开始阅读也可在实验书架重开；一份 PDF 保持一个书籍归属，接收/原版/转换状态分别表达。
- [ ] 使用可复用的真实候选转换 Adapter 与独立参考段落核对文字、连字、标题/列表/代码和顺序，不仅检查 DOM 或数据表存在。
- [ ] 记录模型准备、原版可见、首范围可读、全书结束、资源与当前配置；首范围提前可读须有实际单元完成证据。
- [ ] 候选只作为实验接入，未在正式入口启用；在累计实验预算内比较，保存不支持渐进或来源的真实失败。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
