## What to build

在同一实验阅读路径读到真实扫描件识别文字，并看清低清、错误文字层或混合语言的质量边界，使本机 OCR 选择有实际依据。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 没有外部 AI 配置也能对固定印刷体扫描范围实际运行本机 OCR，读取识别文字并定位对应原页。
- [ ] 清晰、倾斜/低清、错误文字层和混合语言样本有独立参考及分类结果，不用主语言平均成绩掩盖其他语言。
- [ ] 从浏览器显示首可读范围、未就绪范围与原因，严重乱码不冒充可读正文；模型未准备不显示文件损坏。
- [ ] 固定引擎/模型/后端/设置并保存耗时、峰值与错误；模型下载与文档外发区分，不自动转云端。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
