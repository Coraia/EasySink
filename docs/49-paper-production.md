# 正式阅读器：已认可薄纸曲面接入

版本20261008-paper。用户认可独立paper-shape原型后要求进入正式开发。

## 模块和行为

`paper-model.js`复制已认可原型的纯几何模块：曲面参数/可达端点求解、顶点着色器、沿卷曲线排列网格。复制内容保持字节一致，原型保留为固定验收参考，不由生产改动隐式覆盖。

`page-fold.js`保持生产光影片元着色器，给认可顶点增加装订距离和诊断字段；`page-curl-renderer.js`负责同一GPU上下文、纹理/预算、动态材质网格、书脊诊断线和绘制性能数据。诊断线使用独立x=0材料buffer和同一曲面shader，不能用覆盖条掩盖裂缝。双页间隙为0，与认可原型一致；整个内侧材料边保持装订坐标，最终平放时不需要移动中缝或拉伸页面补偿。

五个输入模块保持原字节内容，原生接触/结束、停驻、回滑、连续/交替及兼容wheel规则没有重新发明。正式版原有鼠标/单击与native/兼容手势各自收尾策略保持，模型只负责画面与物理可达点。不可达位移有限位，不宣称能百分之百满足任何原始指针位置。

原有光影开关、硬件GPU高清纹理/画布预算、24M缓存、上下文释放保留。软件GPU的动画像素预算由400k调整至320k，静态正文DOM仍保持原生分辨率；顶点与片元统一高precision；设备不提供该精度时走既有无动画阅读导航，不画可能失稳的极细圆锥。原文、词卡、选区翻译、语法、笔记、书签、插件和书籍持久化链路保持。

## 验收范围替换

用户确认旧扭曲问题后批准新原型，旧reader-root测试强制“12%外保持旧扭曲”的条件已不再适用，归档到本轮before，换为reader-paper对正式GPU全部点/法线和已认可原型同uniforms的比较，另查材料长度、装订坐标、投影端点和非负高度。原型不是完整物理薄壳模拟器，连续可展片+有限精度GPU近似需要可测量误差守卫。

原reader-twist材料拉伸红色回归保留并收紧至1.02（原1.15）。旧自由圆柱/旧绑定shader对照只用于历史因果诊断，新uniforms模型不再兼容该对照，完整归档，不用缺失uniform产生的假结果冒充测试。reader-spine像素位置检查、输入性能和DPR检查保留；renderer元数据名更新为webgl-developable-paper。

开发先保存当前源码和输入SHA，复跑正式缺陷失败3.7021，接入后通过，再针对性测试。开发完成后运行完整浏览器套件，所有首次失败保存。最后本机部署验证服务/前端版本与实际提供的shader，刷新用户正式页时按原文锚点核对；页码仅为布局表现。原生phase fixture与实机手感验收分开。

## 软件渲染性能对照

第一次完整回归保存在full：109通过、1失败、1跳过。唯一失败是软件GPU帧间隔P95为34.1ms，超过既有34ms守卫；失败发生在已预热、纹理等待0的翻页中。只缩减软件动画的画布及匹配纹理像素预算，不改硬件高清比例、不改输入模块、不放宽守卫。software-headroom的12次连续翻页P95最大21.2ms（原控制34.1ms），保留这次有效调整，最终再完整回归。帧间隔和输入调度样本为浏览器内部计时，不等同于物理指尖到屏幕的延迟，也不保证所有设备同样结果。
