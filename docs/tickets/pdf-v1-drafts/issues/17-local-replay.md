## What to build

读者利用保留响应和中间资料本地重建有效阅读内容，在调用额度耗尽时也不新增外部请求；资料不足和重新生成明确区分。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 真实业务入口可选择本地重放，响应/中间产物完整时重建对应范围，经来源/结构校验和版本更新闭环读取。
- [ ] 供应商收件及尝试/限额记录证明重放零新付费请求，限额耗尽不阻断本地处理；有效结果复用仍不占次数。
- [ ] 缺资料、输入版本不兼容或内容检查失败时显示不能重放，不自动切成重新生成或补发模型请求。
- [ ] 重新生成由明确操作建立新尝试，按既有限额和未知结果规则处理；界面清楚区分三种行为。
- [ ] 重启及旧响应提交失败后能使用保留资料恢复；不因普通缓存清理丢掉必要重放依据。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
