## What to build

在真实数字和扫描材料中读到正确顺序，并从实验阅读内容定位到正确原页区域，证明来源、结构和严重错误处理足以支持后续阅读记录。

## Acceptance criteria

- [ ] 固定多栏、脚注、跨页段落与重复引文样本有独立顺序与来源标注，不让待测引擎生成参考答案。
- [ ] 原页序号、印刷页码标签、旋转/裁剪坐标明确；缩放/旋转后高亮仍对应正确来源区域，必要用例零错页或错区域。
- [ ] 文字连字规范化仍可回溯原文，复杂对象可保留多个来源区域；块/区域精度与未验证的逐词框分清。
- [ ] 被发现的严重乱码/串栏/错序范围拒绝作为就绪正文；其他合格范围及原版仍可读，不承诺发现所有错误。
- [ ] 扫描公式/表格、混合语言与低清类别的结果分别记录，保留未通过范围及忠实来源，不靠删样本提高分数。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
