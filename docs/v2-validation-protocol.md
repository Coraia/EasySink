# V2 个人标注匹配验证协议（设计稿）

状态：暂缓的验证设计，尚未执行；用户已转向 [V1.2](v1.2-scope.md)，当前不推进本协议的校准或真人实验。下列数量是未来先导规模建议，不是功效分析结果。用户已确认的目标见 [北极星契约](v2-north-star.md)，待验证机制见 [方案提案](v2-design-proposal.md)。本轮仅设计协议，不招募、不读取或修改正式个人资料、不实现正式功能。

## 核心判断

困难是构造可信的反事实，而不是运行多少自动测试：帮助需求随人和语境变化，展示解释会改变知识，校准本身可能教会用户，没点击无法证明正确理解。

将验证拆成三个不能互相替代的层次：
1. **工程正确性**：候选过滤、证据作用域和撤销是否工作，能够通过规则反例和真实 UI 操作验证。
2. **匹配有效性**：给相同候选与预算，个人证据是否让帮助选择更符合读者的独立判断。
3. **阅读价值**：在未预先测过的新内容上，是否增加无需额外查词且理解正确的片段；额外校准是否值得。

工程通过不等于匹配通过；匹配代理指标改善不等于北极星改善。先导数据不足时结论是“尚不能判断”，不是通过，也不自动判为无效。

## 实验前失效清单

| 失效方式 | 对策 |
|---|---|
| 变量清理收益被算成个性化收益 | 所有个人模型与对照共享同一候选修复版，旧版只作内容问题基线 |
| 只打败糟糕的默认词频阈值 | 增加“使用相同反馈调单一阈值”的强简单对照 |
| 问用户是否认识就当成真值 | 自报与无释义语境释义/理解表现分别保留，疑难项标不确定 |
| 先看注释/题目导致学会或注意目标 | 诊断材料与真实阅读材料分离；真实阅读无逐词前测 |
| 新策略多标、释义更好或响应更快，误算为匹配收益 | 相同可用释义、相同预算规则；记录实际版面负担和延迟 |
| 只评价已标内容，漏标不可见 | 从完整原文抽样，包括无候选、被过滤、未标位置 |
| 同一人重读同一段，记忆提高成绩 | 每人每段只进入一个阅读条件，采用不同新材料交叉平衡 |
| 校准教会了词，误算为算法收益 | 同一时点用不同模型快照比较信息利用；学习总收益另设随机条件 |
| 测试标签进入更新、按测试结果挑模型 | 冻结开发/先导/正式评估分割，先落盘预测再解封标签 |
| 同词词形、重复句、相邻篇章泄漏 | 按原文来源、表达及用法分组；新词轨排除校准词形/同表达变体 |
| 少数词贡献大量样本，伪装大样本 | 按读者和篇章聚类分析，重复表达单独报告 |
| 人工看完全部答案替模型推断 | 算法接触范围可审计；人工只准备材料和盲评，不冒充自动模型 |
| 释义错误、OCR/语法障碍被随意剔除 | 主结果保留真实失败；归因另记，不事后改变分母 |
| 强制完成校准才看见好结果 | 跳过、退出和不足样本都保留；自愿采用单独评价 |

## 第一关：先确认量尺能用，不先做完整产品

### 研究材料

使用已授权、可重放的真实原文；人工核对原文、目标用法和可用解释。覆盖普通叙述、技术/学术材料、领域用语、熟词新义、短语和公式/代码混排。当前无法可靠判断的项目不强贴标签。

准备三类互不混用的材料：
- **开发材料**：用于发现错误与调策略，可以反复查看，不进入效果结论。
- **诊断材料**：用于个人帮助需求判断；人为突出目标和提问会干扰阅读，因此只用于离线匹配实验。
- **真实阅读材料**：从未给该参与者做过前测或校准的新片段，用于北极星测量。

候选过滤先建立带原文位置的挑战清单：既有变量等必须排除的例子，也有不能被粗规则排除的正常表达。样例通过只能证明所测反例；随机原文审计用于发现清单之外的遗漏。不把“删除所有单字母/大写词”作为合格策略。

### 个人需求的参考标签

诊断界面先呈现英文语境，不显示译文、词注或模型选择。读者先报告“无需帮助/需要帮助/拿不准”，再用一句短中文说明目标在此处的意思。不考拼写、术语中文名或逐词直译，只核对影响句意的语义。

参考标签保留两个轴：
- **自报需求**：读者是否希望得到帮助。
- **语境理解表现**：正确、错误/无法说明、不确定。

工作标签用于诊断，而非不可争辩的能力真值：
- **明确无需帮助 N**：自报无需帮助，且独立理解正确。
- **明确需要帮助 D**：不能正确理解关键含义，并经核对与该词语/表达有关；读者自信但误解也计入该类。
- **不确定 U**：能理解但仍希望核对、自报与表现冲突且无法裁决、评分有争议或障碍并非词汇。保留，不算作 N。

在需要释义辅助诊断原因时，先保存首次无提示表现，再展示核对材料；将这些项目标记已曝光，不再用于未曝光阅读实验。修正后的回答不能覆盖首次记录。

评分依据在看模型输出前写好，允许合理意译；由不知道策略身份的人工核对。先导只有 Fisher 与助手时，明确记录非独立盲评的局限；LLM 可协助整理，但不能单独裁定争议理解或充当参与者。正式比较需要额外人工核对争议和预先抽定的一部分样本。无法一致裁定就保留 U，不硬凑真值。

若量尺中 U 很多、读者解释困难与英文能力无关，或题目本身有歧义，先改测量工具再冻结下一批。不能靠剔除难样本让模型变好。

## 第二关：隔离的个人匹配实验

### 首轮规模建议

先由 Fisher 自愿参加：最多 12 处校准语境 + 24 处独立诊断语境，拆成短场次，随时停止。合计最多 36 处是研究取样负担，不是产品日常流程；不承诺完成时长，先实测。

24 处诊断语境建议分层：
- 8 处：校准出现过的表达，在新的相近语境中出现；
- 8 处：校准中未出现的新词/表达，排除词形和短语变体泄漏；
- 8 处：同词新义或跨领域反例，专门检查过度泛化。

这些是刻意富集风险的挑战样本，不代表自然阅读的真实分布。各层单独报告，不将简单汇总比例推广为日常准确率。正式效果还要有按实际内容分布抽取的阅读样本。

校准保存 0、3、6、12 处证据的策略快照。未完成某个档位就记录缺失，不填补或强迫继续。诊断阶段不向模型回流标签；模型可以读取待判断的原文，不能读取该读者对此处的评价。

### 同台对照

所有策略使用相同候选、释义、密度规则、用户明确显示偏好与评估语境。策略及参数在解封诊断标签前冻结。

| 策略 | 用途 |
|---|---|
| A 现有完整策略 | 仅用于审计当前问题和整体变化 |
| B 修正无效候选后的固定阈值策略 | 隔离候选修复之外的收益 |
| C 同样候选，使用同样校准证据只调整单一词频阈值 | 检查复杂个人模型是否胜过更简单的解决方案 |
| D 待验证的个人排序策略 | 检查有限泛化是否值得增加复杂度 |

若策略维护明确反馈，C/D 使用同样的直接反馈处理，不能因其中一个独享“记住原答案”而获得优势。所有阈值选择只用校准/开发数据，不在诊断集挑最佳阈值。自然点击信号首轮关闭，先验证明确证据；以后有增量价值再加入。

不必做正式校准入口或改正式数据库，只需独立采集界面和最小可运行排序器。手工标好的理想标注可作可达性参照，不能冒充模型结果；正式效果也不能拿“全标”替代当前基线。

### 结果怎样读

对每个策略、快照、读者和分层报告：
- 明确 D 中漏标的数量；明确 N 中多标的数量；U 数量及其标注情况。
- 从 C 到 D 的逐项变化：新增帮助是否命中 D；撤掉的帮助是否原本是 N；新增错误分别是什么。
- 相近预算下的实际注释数、覆盖长度、版面占用；不强行补齐低价值注释。
- 0/3/6/12 处证据的收益变化与实际答题耗时；不把小批次当成充分样本量。
- 固定预算的比较可能沿用同一组参考标签，表示“这些选择更贴合参考需求”，不表示读者实际经历过全部策略。

同一读者的理解会因校准改变，因此离线对照使用相同时点的需求标签比较不同策略快照。这隔离模型如何利用信息，却不直接估计“提供校准”对人的完整因果效果，也不能把 0 处快照说成参与者未校准时的真实体验。

**本关决策**：明显重复出现的跨用法伤害足以阻断当前方案；若 D 不比 C 带来有意义的改善，优先保留简单方案。小样本差异不清楚则进入“证据不足”，不是默认晋级。若只对见过词有效，记录有限收益，不能宣传普遍新词泛化。

## 第三关：真实阅读交叉先导

只有第二关出现值得继续的信号，才用隔离阅读环境验证北极星。保留正式资料库与客户端不变。

### 最小场次建议

每位参与者先用 6 段全新短材料，建议每段 150–250 个英文词。分成 3 对，按体裁、长度、词频与表达难度尽量匹配；这是近似匹配，不是已经证明等难。

在每对内随机分配一段给较强的简单对照，另一段给个人排序策略；每个条件 3 段。每个人每段只读一次；策略名称隐藏，条件顺序平衡。不同参与者可交换材料条件，逐步分离内容与策略影响。第一人结果仅是个案先导。

策略快照在本场开始前冻结，试验期间产生的反馈另存，场内不互相影响。避开诊断用过的片段，并控制跨条件重复表达的教学影响；不能消除的重复暴露记录并分层分析。使用相同可用释义与性能条件，自动标注之外的工具保持一致。

### 一段材料的实际流程

1. 读者自然阅读，不做词汇前测，不要求边读边解释想法；查词、选区、保留等照常。
2. 记录实际展示了哪些注释、必要查阅动作、响应耗时和首次异常；不录入不必要的私人信息。
3. 读完后，在固定的简短核验环节回答事先写好的关键含义问题。题目不回显模型注释，保留理解答案，不在前一段讲授下一段要用的知识。
4. 简短确认查阅意图是理解需要，还是听音/深入核对；记录漏记的外部查询。意图不明不能径直当作无需帮助。
5. 可补收“哪些标注多余”的体验反馈，但只作主观诊断，不能替代独立理解评分。

关键含义题应覆盖真实句意、短语/熟词新义，而不只考文章大意；问题与通过规则在策略分配前冻结，不为某策略量身定做。不要求逐字记忆；允许按固定方式查看原文但不再追加帮助，所有条件一致。研究核验本身会干扰沉浸，故先导不是自然长期行为证据。

### 北极星的操作定义

固定阅读片段在预定关键含义核验上正确，且阅读期间没有为了理解词汇而追加查阅，才记为成功。展示的自动词注属于允许帮助。纯听音或主动深挖不当作词汇失败；意图未知单列，给出保守口径，不能偷偷从分母删掉。

主分析分母为预先纳入并分配的阅读片段；尚未开始和已经开始分别记录，不能因校准退出或阅读中止而删掉后续已分配片段。无法完成、核验缺失、技术故障和主动退出分别记录；主报告给出保守成功率和完整结果数量，完整作答子集仅作敏感性分析。参与者撤回数据使用授权时尊重其要求，并披露因此产生的分析限制。入场前发现损坏材料可按冻结规则替换，看到结果后不更换。

OCR 错误、错误释义或语法障碍导致的理解失败仍保留在整体阅读价值结果中，同时作原因分解。这样既不会替模型背所有锅，也不会为了显得准而删除真实失败。

同时报告正确理解率、必要查阅频率、阅读时间、实际注释负担、校准时间和退出情况。不把诊断标签 F1 或少点了几次词卡当成北极星本身。

## 第四关：微校准是否值得、能否跨读者成立

两个问题要拆开：
- **信息利用价值**：同一时点比较有/无额外校准证据的策略快照，检验数据能否改善选择；第二关可以先做。
- **提供校准的产品总价值**：邀请本身的负担、跳过行为、被校准教会内容及后续阅读收益；不能仅比较自愿校准者与未校准者，更不能只看同一人前后变化。

第二个问题在更多自愿参与者中，以随机的“现在提供可选校准 / 延后提供”分配，比较接下来的新阅读材料。保持基础明确反馈来源可比，记录所有跳过与退出，按最初分配报告结果；只看完成者是补充分析，不用于主胜负判断。实验结束后延后组可获得同样入口。

先导可建议招募 6–8 位不同阅读背景的自愿读者，目的仅为发现个体差异、流程负担和估计波动，不声称这能验证微小提升。未获授权不代为联系或招募。若资源只有 Fisher，只能给出单人、有限材料上的结果；不伪装成市场人群结论。

自然使用阶段再观察一段由参与者同意的日常阅读周期，不天天发题。它主要检查校准是否变成隐性必需、收益是否持续、是否产生新打扰；短期核验与长期体验证据分别报告。

## 放行规则与待冻结参数

### 现在即可约定的阻断项

- 修改正式资料、撤销失败、跨语境误写明确声明、保留注释丢失、交互新增第三层、阅读位置损坏：工程阻断。
- 使用测试标签调参、相同片段反复作为前后效果、伪造参与者判断或人工代替算法：实验无效，不能放行。
- 仅靠更多注释、较好释义或遗漏失败片段获得优势：不能归因于个人匹配。
- 明确出现策略造成的理解损害，或持续要求大量手工纠正：暂停当前候选，保留失败证据。

### 先导之后、正式比较之前冻结

先导用于估计基线和流程噪声，不能兼作最终确认样本。需填写并批准：
- 最小有意义北极星提升 Δ_min，以及读者可接受的校准操作/时间预算。
- 理解正确性允许的非劣化容忍度、实际标注负担容忍度、阅读性能门槛。
- 主比较、分析单位、样本量/停止规则、区间估计方式、缺失与多次比较处理。
- 正式材料与评分规则、策略版本、随机分配种子、已知曝光名单。

不能通过先导的标准差直接机械决定阈值：Δ_min 来自产品价值取舍，样本量才依据期望效应和波动设计。资源不够支持所需精度时，缩小结论范围或停止，不降低证据标准。

正式结论分为：
1. **可放行**：新增收益达到预定实用门槛，有足够证据排除纯噪声，并满足全部护栏；不同读者结果与适用范围透明。
2. **不可放行**：有明确伤害/工程红线，或在有足够精度的比较中未达到预定实用收益。
3. **证据不足**：区间同时包含值得做和不值得做的效果；不当作成功，也不声称零效果。

统计分析以读者为主要独立单位，考虑同一读者多个篇章及重复表达的相关性。单人不提供人群置信结论；小样本不靠把词当独立样本制造显著性。多个证据档位用于探索，正式阶段只验证事先选定的主对比，避免事后挑最好看的结果。

## 执行产物与职责

执行时新建隔离实验目录，至少保存：
- `protocol.md`：冻结版协议、版本及偏离记录。
- `materials.jsonl`：授权来源、原文锚点、分组、目标、核验依据与暴露状态。
- `allocation.json`：材料分配及可重放的随机种子。
- `evidence.jsonl`：匿名读者、语境判断、是否见释义、来源、时间、撤回与缺失。
- `predictions.jsonl`：策略/个人状态版本、候选、选择、理由、预算；在解封评价前保存。
- `reading-events.jsonl` 与 `outcomes.jsonl`：实际展示、必要查阅、核验、退出、故障、评分依据。
- `report.md`：每个读者和分层结果、首次失败、原始测量和适用范围；截图/录屏仅在同意范围内保存。
