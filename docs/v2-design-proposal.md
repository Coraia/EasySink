# V2 个人标注匹配方案（待对齐）

状态：暂缓的设计提案，尚未批准实现或得到收益验证。用户已转向 [V1.2](v1.2-scope.md)，本文件不再作为当前执行清单。未来 V2 的唯一目标与已确认边界见 [北极星契约](v2-north-star.md)；本文件不扩大范围，不替代已接受 ADR。

## 推荐结论

采用“默认直接阅读 + 阅读中顺手纠偏 + 可选微校准 + 有限泛化”的混合方案。先修候选合法性，再在相近辅助密度内按个人语境帮助需求重排；不把用户变成词表维护者，不把校准做成入场考试。

核心假设：少量高质量个人证据，能在未参与校准的后续内容中，比现有词频阈值策略更好地分配帮助。此假设必须验证；研究与竞品设计均不能替代 Wise Reader 的证据。

## 参考产品：借设计机制，不借目标

本次读取公开官网/帮助文档，没有登录体验产品，也没有测得竞品效果。LingQ 帮助页标注更新于 2020 年；Lute 手册自行提示页面略旧，因此只作为机制参考，不宣称当前所有客户端行为相同。

| 产品及公开材料 | 可参考的机制 | 本方案不照搬的部分 |
|---|---|---|
| Readlang 官网：点击词或短语翻译；所查词保存并可用于闪卡练习。[2] | 从用户正在阅读的内容出发；先解决眼前理解问题 | 不把每次查阅自动变为不认识、收藏或复习任务；V2 要进一步减少必要点击，而非仅让点击方便 |
| LingQ 帮助：阅读器可在翻页时把剩余蓝词变为 Known，也可关闭这一设置。[7] | 反馈嵌入阅读，结果用于之后的阅读 | 不将翻页、没点击或未纠错当作认识；不以 Known Words 数量作为北极星 |
| Lute 阅读手册：可设词语状态；完成页的绿色勾选会把剩余蓝色项设为 well known。[4] | 个人证据可持久使用，允许显式纠偏 | 不要求逐词维护多级学习状态，不把首次遇见直接等同于不懂 |

个体化词汇复杂度研究提出个人模型及主动学习框架。[6] 本次只核对其摘要所支持的方向，未复现论文、未引入数据集，也不据此承诺若干次点击即可准确了解一个人。

## 路线比较

| 路线 | 价值 | 对本目标的局限 | 定位 |
|---|---|---|---|
| 改进总体词频阈值/词汇量自测 | 便宜、容易解释，能获得粗起点 | 难容纳“技术词熟、日常词或特定用法生”的交错分布 | 保留作无数据先验和对照 |
| 显式个人词表 | 对纠正过的词立刻有效 | 跨用法误伤，维护成本高，不能证明新词泛化 | 作为局部证据，不作为全部方案 |
| 完全依赖自然点击 | 无额外任务 | 点击意图不明，未点击的漏标不可见，启动慢 | 弱线索，不单独承担个人判断 |
| 混合方案（推荐） | 把低负担起步、可靠纠偏和加速校准分开 | 需控制证据污染、泛化错误与测量偏差 | 先用可解释小模型验证，不先上复杂模型 |

## 用户路径

### 1. 开始阅读

- 老用户沿用已有明确设置，旧词汇量/自测结果仅作为粗先验；保留来源，不包装成语境证据。
- 新用户直接使用可工作的默认策略，无必填程度问卷。没有个人证据时承认未知，不能声称已实现个性化。
- 原工具区提供一个“调整标注”入口，非弹窗、非常驻新面板。入口解释其用途是减少多标/漏标，不输出一个新的词汇量分数。
- 现有自测保持可访问与兼容，但不新增并排的两套新手入口；是否将旧入口收进设置作为本提案的导航建议，需对齐后才改。

### 2. 正常阅读中的纠偏

- **多标**：复用词卡的“已掌握”，仍表示理解当前用法。当前自动词注可去掉，明确保留的注释不受影响；可撤销，不额外确认。
- **漏标**：点击/选词先获得解释，不以填写反馈为查阅前提。词卡可提供可选的“刚才这里需要帮助”，记录这次阅读的需求，不将解释后的理解状态反写为此前能力。
- **仅查阅**：最多形成有时效、影响受限的注意线索；首轮实验保留开关，若不能证明净收益就不用于改排名。不能写成未掌握。
- **无操作**：保持未知。收藏、保留、采用释义独立，不作为掌握标签。
- “已掌握”发生在释义可见之后，可能表示刚刚学会；因此对当前出现的显示有效，但不足以单独成为跨语境隐藏注释的强依据。证据必须记录释义是否已展示。
- 原文为第一层，词卡/校准为第二层；原因、撤销和历史在当前层展开或替换。保持最多两层，不要求管理一个独立词表后台。

### 3. 可选微校准

入口承诺“帮我把标注调得更贴合”，不承诺未经测量的秒数或效果。

推荐首轮交互原型以 **3 处为一个小批次**，这是待测的体验参数，不是达到可靠估计的样本量。每处判断即时保存，随时返回阅读；批次后“返回阅读”为主操作，“再看几处”为次操作，不无限出题。

每次展示一句简短英文语境，突出一个词/短语，先不显示释义，询问“读到这里，你需要帮助吗？”选择为“不需要 / 需要 / 拿不准”。这是自报帮助需求，不是答题成绩；“拿不准”和跳过不写成认识。

选样原则：
- 与当前材料的后续标注决策有关，并接近当前判断的不确定区域；不是随机挑最罕见单词。
- 同时覆盖可能多标和可能漏标的位置，来自完整可用候选而非仅已显示注释；保持频段和用法的多样性。
- 用无剧透、可核对的短语境，不直接拿尚未阅读的故事情节当题干；不要求用户读一本指定校准书。
- 首轮实验使用人工核对的小规模语境材料；正式方案须另验证可持续的例句供给、适用范围和许可。没有可靠语境就跳过候选，不把实时生成的句子假定为正确，也不启动无边界题库建设。
- 区分首次未见释义、已见释义、重复项目和自然阅读反馈；已学过的项目不能用于测初始能力。
- 采样以预期能改变后续决策为目的，但未验证概率模型前只使用可解释的“不确定 + 相关 + 多样”排序，不伪称计算了可靠信息增益。

结束仅说明“已记录这些判断，将用于调整后续标注”；不显示“准确率已提升”或虚构词汇量。校准可加速适应，但不应成为持续使用的隐性必需。

## 从证据到标注

### A. 内容候选：先区分词语与符号

利用已有内容类型和原文位置识别公式、代码、编号、URL 等。`Let x ...` 中的变量与英语词语分开；不能统一删除所有单字母、缩写、大写词或专名。新规则需同时检查误过滤的合法表达。

保留词语与词典短语两类候选；熟词组成的陌生短语不能被逐词“认识”挡住。无词典解释或未能识别的表达属于候选覆盖缺口，不能只靠排序解决，也不能为争取召回而自动补造释义。手动选词仍可用，缺口进入诊断。

此处只消费已有内容信息，不借机重写 PDF 转换或阅读内核。

### B. 个人证据：声明、行为和预测分开

建议个人推断模块的内部记录包含：语境出现/原文锚点、判断值及含义、来源、时间、是否见过释义、撤回状态；预测另带模型版本、依据及不确定程度。这里是设计字段，不是已存在的存储接口。

优先级按作用域处理，不简单用“最新覆盖一切”：
1. 明确保留注释是显示偏好，继续保留；不推断能力。
2. 当前语境的明确判断作用于该处；互相冲突的反馈保留变更依据与撤销语义。
3. 旧全词判断仍按兼容语义保留，不静默改成新语境声明，也不允许新预测悄悄推翻旧显式控制。若限制了效果，单独列出冲突供用户撤回旧判断，不强制迁移。
4. 只有预测层才允许有限泛化；发生新反例时收缩预测，不改写过去的声明。

### C. 有限泛化：既不能只记答案，也不能假装懂用户

| 范围 | 推荐处理 |
|---|---|
| 同一语境出现 | 明确反馈直接生效；保留注释独立 |
| 同词、可信的相近用法 | 调整后续帮助优先级，可跨书；不永久禁用该词 |
| 同词但用法不明/不同 | 保持未知，回到先验；仅同拼写、同主题或词性相同不足以认定同义 |
| 从未反馈的新词/表达 | 只有多项分散的证据才能温和调整一般需求曲线；始终是概率/排序推断，不生成“已掌握”事实 |
| 整个领域 | 不凭少量技术词判断整个领域能力；“需要加强的领域”仍是帮助偏好而非能力标签 |

首轮模型建议：词频作为先验，结合表达类型、已有可验证的用法特征与个人证据，输出需求排序；多样证据积累后对词频分段需求作有上限、向先验收缩的更新。一次反馈不整体升降词汇量，不直接传播到邻近词。具体更新方式与参数通过隔离比较选择，不在设计稿中捏造精确概率。

**用法匹配是明确技术风险**：当前代码没有可靠的通用词义识别。先在能可靠匹配的狭窄用法范围验证；不靠“附近出现了某关键词”冒充词义识别。不可靠时不迁移。若因此只能改善重复词、不能改善未反馈词，就不能宣称整体个性化假设已成立。

### D. 展示决策：密度是上限，不是能力

在用户允许的辅助密度内按个人帮助价值选择，兼顾短语/单词重叠与重复。无帮助价值的候选不为凑额度强行显示；错误变量腾出的额度也不必须填满。

“密度”控制愿意看多少，不再同时作为能力估计旋钮；个人证据决定优先帮助哪里。不确定的合法候选在预算内稍偏防漏，不产生全页探索标记。

当前页只响应用户明确纠偏；自动适应在后续内容呈现的安全时机生效，不在拖选、翻页中途插入注释或重新分页。保持原文锚点和旧记录，失败时回退到可工作的既有选择策略，明确反馈和保留偏好仍有效。

## 如何接入现有项目（已核对的事实与建议分开）

已核对：
- `src/wise_reader/profile.py:34` 保存词汇量、旧 known/unknown 和密度；`vocab_test.py:113` 已将估计描述为词频熟悉度范围，而非精确词汇量。
- `src/wise_reader/l0.py:40` 生成词典候选；`semantics.py:9` 的 contextualize 目前原样返回候选，明确不根据上下文关键词猜词义；`semantics.py:18` 提供词典短语候选。
- `src/wise_reader/l2.py:9` 以阈值、密度、旧显式判断筛选；密度也影响词频门槛，排序含罕见度和短语优先。
- `src/wise_reader/engine.py:176` 复用内容候选，再读取旧 wr_target 判断调用 L2；`web/collections-marks.js:103` 是当前语境反馈与采用解释的展示叠加路径。
- ADR-0008 保证语境出现、掌握反馈、保留注释及采用解释彼此独立；ADR-0007 要求复用阅读核心。

建议把个人证据归纳、用法匹配与需求排序收在一个深模块内，向阅读路径提供“小接口”：输入内容候选、明确显示控制和个人状态快照，返回有理由与版本的标注选择。校准和正常阅读消费同一套判断，不维护两套能力模型。具体接口与文件归属待方案批准后设计。

内容分析与个人状态分离缓存；更新个人状态只重算选择，不重跑转换/词典/生成解释。缓存身份包含内容版本、策略版本、个人状态版本；撤销使受影响预测失效。优先本机处理现有证据，不默认新增外发或逐词大模型请求；若候选模型需要新的依赖、下载、外发或许可，必须单独核验和对齐。

## 最小验证：先证明机制，再产品化

执行验证前读取 [V2 验证协议](v2-validation-protocol.md)。该协议集中定义失效方式、独立需求判断、强简单对照、个人匹配先导、真实阅读实验、校准增量价值和放行条件；不再在本文件维护第二套实验分组。

核心区分：候选修复收益不等于个人模型收益；用相同反馈调整单一阈值是必须比较的简单方案；离线选择更准不等于真实阅读更好。先在隔离先导验证量尺和机制，再进入未预先测试的新内容阅读，最后评估可选校准的负担与推广范围。

所有数字先导规模仅是设计建议，不是已验证的样本量；主指标仍由北极星契约约束。明确伤害应阻断，证据不足不当作通过，也不自动当作无效。完整产品化后才执行最终连续阅读验收，保留浏览器与真实客户端的独立证据。

## 本轮待确认的方案取舍

推荐一起对齐的方案是：混合路线；原工具区单入口、首轮 3 处微校准；自然查阅默认只作弱线索；本机可解释排序与保守泛化；先用隔离先导证明新增个人证据及校准的增量价值，再接入正式阅读。三处、候选特征和参数均可根据试验改变，但唯一北极星不变。

本稿只新增设计文档，没有实现模型、校准 UI、依赖安装或用户数据迁移，也未提交/推送/发布 Issue。后续是否保留微校准的正式推荐地位取决于实验，不把设计偏好当作结果。
