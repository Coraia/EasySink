# 阅读笔记 · 正式版

## 体验入口

- 打开书籍默认专注；点击上方展开工具，底部笔记图标打开列表。再点同一区域回到 banner。
- 在正文拖选文字，或选择一个段落，点“记一笔”：新建独立记录，编辑卡跟随原文位置。既有翻译、语法、书签和朗读入口全部保留。
- 已记录的原句有细下划线，段落外侧有笔记图标；多条笔记显示数量。点图标查看这段笔记。
- 列表支持全书/本篇、当前章以及无引用的随记。编辑卡固定引用；列表编辑不跳阅读位置。
- 修改自动保存；“完成”是收起编辑卡。空白新建不写入，清空旧笔记后关闭会保留已保存内容。
- 点引用定位原文并高亮，“回到刚才”恢复章节和原文位置。点编辑修改内容；“⋯”内删除，提示中可撤销。
- 失败显示状态与重试；草稿可从列表继续。旧版本的单草稿只在内容与已保存记录不同时迁移。浏览器存储失败时提示复制内容。

## 模块与数据

`web/plugins/notes.js` 负责读者列表、编辑卡、可见页标识和笔记总览；`notes-store.js` 负责按 client_id 串行保存、草稿与删除协调。所有事件和标识跟随 reader/panel scope 清理。插件仍由唯一 catalogue 管理；关闭不删数据，代码清退时连同 notes-store.js 删除。

`GET /api/notes` 保留全局和 doc_id 筛选，新增 book_id 筛选；章节归属返回 book_id、chapter_idx、chapter_title，不需要改写旧笔记。新增/修改沿用 POST/PUT、client_id 幂等键和 Anchor；删除先等已发出的保存完成并取消尚未发出的保存。撤销使用新的 client_id 恢复服务端记录及原文位置。

原文位置使用内容版本、block_id 与 UTF-16 起止偏移，不绑定页码。标识放在正文段落外，引用使用 CSS Highlight/词语样式，避免增加正文字符或改变分页高度。可见页重绘复用按 block_id 建立的索引。

共用面板新增可选的 onClose：编辑卡关闭可返回列表；底部同一工具点击仍回到 banner。透明 dismiss 层让正文可见；撤销提示位于工具层上方。译文“记一笔”接入选区新增动作，不能误开笔记列表。
