## What to build

用已核对的真实转换结果体验 PDF 阅读核心流程，选择一套达标主流水线，并由用户确认交互原型后才开放正式实现。

## Acceptance criteria

- [ ] 按同样本结果冻结主引擎、模型/依赖、实际本机后端与许可，保留淘汰理由；默认不部署三套完整环境。
- [ ] 冻结各类别质量、来源、资源与耗时门槛，证明代表范围及长书条件满足门槛并不干扰固定旧书；不把小范围通过当全书通过。
- [ ] 提供可交互原型：导入/状态、原版与阅读版往返、局部重新识别、原图笔记、任务/费用详情和资料管理；正常进入专注，右侧留给选区译文。
- [ ] 原型的真实转换部分与模拟生命周期/费用状态标明证据级别，手动纠错保持备选，不加入整书翻译或原版全套学习工具。
- [ ] 用户明确验收交互原型并记录结果后，本票才能作为正式实现前置条件完成；未达标停在实验阶段，正式入口保持旧行为。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
