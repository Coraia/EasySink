# 触控板可撤回收尾与手势衔接

2026-10-07，`20261007-gesture-fix`。取代上一版仅在 240ms 后播放更短动画的逻辑。[编码前约定](36-gesture-fix-contract.md)，[数值与复现](../outputs/wise-reader-gesture-fix-20261007/RESULT.md)。

## 输入生命周期

90ms 无输入开始可撤回预览，逻辑手势仍保留；240ms 内不允许提交位置。恢复输入时调用 session.resume，取消旧 RAF / 确认计时器，并保存可见进度与逻辑位移的偏移。后续输入沿当前纸张继续，逻辑累计距离和反向意图不丢失。1px 慢回滑仍累计识别。

超出 240ms 的下一手势独立处理。若旧纸仍在落页，保存压缩后的逻辑位移/意图，不保存整条事件数组，按顺序启动下一张纸。追赶每次绘制最多推进 0.06，自动收尾最多推进 0.065；确认到真正终点后才替换原文。队列上限 32，溢出取消并报告重试，不默默保留无限事件。

无动画、减少动态效果、纹理迟到也遵守确认时刻。取消、失焦、工具/词卡交互、重排、离开 Reader 会清理预览、计时器和队列。章节边界仍是确认后调用现有导航；跨章节跟手卷页未新增。

## 运动与证据

完成和回弹均使用 smoothstep，完成 160–360ms，取消按行程 180–480ms。晚帧不能跳过大段位移，实际时间可能因此延长；帧间隔检查仍独立记录，不能靠位移限制假装软件 GPU 满足帧率。

只改变触控板原因的动画策略；点击、键盘、纸边拖动保持原曲线。光影、网格、纹理精度和缓存预算不降低，没有新的可见控件或持久化表。移除 app 的触控板 import/安装调用即可停用；pagination 的可选 trackpad.cancel 钩子负责顺序衔接。

分析脚本现在按连续 settling 段计算帧间隔/位移，避免把暂停恢复后的手动位移误算成自动动画跳变；等待时间只取最终收尾段。所有中间段仍计入位移峰值，原始 Shader/RAF/input 数据完整保留。

硬件 E2E 验证了暂停恢复、过半反向取消、排队新手势和 Esc 清队列；事件内前后 RAF 快照用于检查即时位移。完整回归保留独立软件 GPU 帧率失败，最终状态见报告，不宣称全量通过或真实手指轨迹已验收。
