## 已确认的产品边界

Wise Reader 继续以 Web 沉浸式英文原文阅读为中心，辅助围绕原文按需出现。PDF 增加材料来源，保留原件，并提供原版核对与结构化阅读版；不提供整书翻译。

第一期以英文书籍和学术材料为主，覆盖数字文字 PDF 与印刷体扫描件。混入中文、希腊文、希伯来文等分别验收，不把主语言成绩外推为任意语言或手写材料的质量保证。（Q1）

## 现行决定

| 方面 | 已接受的行为 | 对应问答 |
|---|---|---|
| 阅读视图 | 阅读版为主，承担重排、查词、选区译文、语法、发音及阅读记录；原版用于查看、缩放、原页/区域定位、选择处理目标与返回阅读位置，首期不复制整套学习工具 | Q2、Q19 |
| 导入与书架 | 原件接收并校验成功后形成一个持久书架条目，不依赖点击“开始阅读”；原版、转换中、阅读版就绪范围和全书完成分别表达，可先读已转换并检查通过的范围 | Q6 |
| 重复导入 | 完全相同的 PDF 回到已有书籍并复用有效结果或任务，不因重复导入再建书或再付费；不按文件名/书名判定，也不默默合并不同原件 | Q16 |
| 默认处理 | 普通导入默认在当前电脑解析、OCR 和结构整理，未配置 AI 也应能执行本机处理；本机失败不自动转外部，已有 AI 配置不代表发送整本 PDF 的选择 | Q3 |
| 外部增强 | 首期提供主动选定页或区域的外部识别/增强，暂不提供整本付费外部转换；外部包括云端 LLM 与自己的其他服务器，同机模型接口属于本机处理 | Q3、Q14 |
| 操作授权 | 明确服务、处理目标与范围的用户操作本身完成授权，不追加授权或费用确认，不要求每个任务手填预算；任务不得自行扩大发送范围 | Q4 修订、Q13 |
| 识别回退 | 未可靠识别的公式/表格在阅读版对应位置保留局部原图，既能就地看也能定位回原页核对并返回；原图回退单独记录，不算结构识别成功 | Q7 |
| 严重错误 | 发现严重乱码、串栏或错序的正文范围不作为已就绪重排正文开放，提供原版核对和重新处理，其他合格范围可继续读；不宣称能自动发现所有错误 | Q12 |
| 阅读优先 | 转换可在后台进行，但需节流或暂停让阅读优先；既有打开速度、翻页手感、DPI/清晰度和功能作为验收基线 | Q8 |
| 安全更新 | 已有的新转换结果在安全时机自动应用，保持阅读位置；不在翻页、划选、编辑或阅读辅助操作途中偷换内容，不要求日常点击“使用新版”，原版不会自行切换为阅读版 | Q9 修订 |
| 阅读记录 | 尽量自动映射笔记、书签与续读；不确定时保留旧引用及原页位置并标明状态，不猜测位置、不丢失记录，也不阻断其他可安全更新的内容 | Q9 修订 |
| 原图笔记 | 阅读版的图片、公式或表格原图可直接记笔记，引用图像及原页区域，支持新增、编辑、删除撤销与定位，不要求先转成文字 | Q18 |
| 任务生命周期 | 切书或关浏览器不取消任务；暂停/取消停止后续工作并保留已完成内容；服务重启仅恢复原本允许执行的任务，保留原任务设置与范围，不自行续跑已取消任务 | Q15 |
| 删除与恢复 | 删书先可恢复、停止后续转换；迟到结果不能让书重新上架。恢复原件、记录与有效结果不重新付费，因删书停止的未完成本机任务保持暂停，主动“继续处理”才恢复 | Q17、Q21 |
| 结果复用 | 相同内容、范围和处理设置的有效结果可复用；本地重放利用保留响应/中间产物重新整理，不新发付费请求；重新生成可能再次付费，三个行为分清 | Q5 |
| 未知付费结果 | 已发请求超时或丢响应，先恢复已有结果或在服务支持时查询；仍未知则保留未知，不自动再次付费请求。明确未发送与已发未知区分，取消不视作退款 | Q11 |
| 费用与限额 | 任务详情记录调用、用量与可靠费用或估算，未知明确标记；首期设置可选的 PDF 新付费调用次数上限，默认不设置隐含硬限额，不承诺供应商级精确金额硬限额，也不默默阻断旧阅读 AI 功能 | Q13、Q24 |
| 达到调用上限 | 暂停新的未发请求，修改限额或明确继续就是业务操作；已发且结果未知的尝试暂计入次数，复用和本地重放不占次数，无额外授权确认 | Q24 |
| 资料保留 | 原件、用户记录、有效结果与重放资料，以及可恢复书籍，默认不按保存天数自动删除；永久释放通过明确清理操作进行 | Q10、Q17、Q21 |
| 空间不足 | 先清可本机重建的临时资源，仍不足则暂停新增转换并提供空间管理入口，不默默删除保留资料，不承诺无限容量 | Q21 |
| 转换组件 | 首期默认接入一套经相同条件样本比较选出的本机主流水线，复用开源组件并保留替换边界；不默认装入三套完整环境，一套流水线可使用必要的多个模型 | Q22 |
| 手动纠错 | 保留为备选，未自动纳入首期交付；先做好识别质量、原图核对与局部重新识别，是否引入手动入口依据真实错误样本及交互原型另行决定 | Q20 修订 |
| 交付门槛 | 先验证真实材料的转换方案，再验收交互原型；质量或既有功能/性能未达标，不进入正式版本，能导入不等于验收通过 | Q23 |
