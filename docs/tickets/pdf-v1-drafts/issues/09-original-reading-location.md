## What to build

从正在读的段落、图片或回退对象定位原页区域，放大核对后回到同一原文位置，页码和排版变化不使读者迷路。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 对象具有稳定来源关联，原页与印刷标签区分，文字和跨页对象的一个或多个区域可核对。
- [ ] 缩放/旋转和不同窗口下高亮仍在标定区域；重复引文不因首个文字匹配跳到另一处。
- [ ] 往返保存原文锚点而非阅读页码，字号变化或来源核对后仍回到对应内容。
- [ ] 原版只提供已接受的查看/定位/处理范围入口，不复制完整学习工具；未能可靠取得来源时明确提示，不能显示错页图片。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
