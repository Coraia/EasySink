## Acceptance criteria

- [ ] 回收可从书架实际操作，当前条目移出活动书架但原件、笔记、书签、续读和有效版本保留。
- [ ] 回收后迟到转换/保存结果不能重新上架或覆盖生命周期状态；恢复保持原书籍归属。
- [ ] 恢复后可立即读已有内容，不重新转换或产生费用，未完成本机任务暂停，继续处理是明确业务操作。
- [ ] 永久资料释放与回收区分；重复导入已回收原件不产生另一个相同归属，显示可恢复状态。
- [ ] 删除、迟到返回、重启和恢复的组合场景通过，不调用旧整书永久删除冒充可恢复操作。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
