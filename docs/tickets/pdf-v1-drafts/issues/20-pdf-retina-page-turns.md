## Acceptance criteria

- [ ] 静态正文、翻起纸面、背面和落页取同一表示；资源已加载、公式引用/字体/图像可复制，零缺图缺公式，不假定原版 Canvas 可直接序列化。
- [ ] 单/双页、硬件 DPR 1/2/3、软件回退及有界纹理缓存保持既有守卫，不降低硬件 DPI 掩盖负载。
- [ ] 装订位置、认可纸面形状和光影保留，处理图像/公式不能让书脊裂开、过度拉伸或露出隐藏操作。
- [ ] 鼠标/键盘/原生 phase fixture 的慢中快、回滑取消、停驻、松手、连续及交替行为验证；实际 Mac 触控板另记录真实体验与指标。
- [ ] fixture、截图、GPU/内部计时和实机手感结论分开；设备条件缺失保持待验收，不能以 fixture 成功替代。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
