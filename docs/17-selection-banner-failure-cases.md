# 段落菜单和透明覆盖层验收

修改前：选择菜单固定在视口底部；banner 覆盖按钮的 hover 被通用 button:hover 背景覆盖，实际截图中正文被不透明 surface 遮挡。before-banner.png/json 保存复现。

失败条件：

- 覆盖层 hover、active 或键盘聚焦变成不透明背景；banner 显隐改变正文位置，关闭点击落到正文产生翻页/查词。
- 整段选择菜单离触发按钮很远；跨页段落的右页入口把菜单放到左页。
- 精确拖选过程中菜单截获拖动，菜单不跟随实际选区终点。
- 靠近屏幕底部、窄窗口、内页滚动或字体重排后菜单越界、遮挡另一侧译文或停在旧坐标。
- banner 或笔记面板打开时选区菜单仍可操作；关闭后丢失原选区。
- 取消、翻页、离开路由后菜单/事件/布局观察器残留；菜单按钮无法执行原功能。
