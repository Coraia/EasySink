# Web 原型 03：沉浸阅读实现契约

本文件替代旧版关于滚动整章阅读、整章/整书翻译及阅读侧栏播放器的设计。正式后端协议仍为 0.2.0，`/health.web_revision` 为 `20261004-v3`。不使用会话原型的固定答案或音频样本冒充实际 AI 能力。

## 体验入口

启动或重启：`python3 scripts/web.py restart`；打开 `http://127.0.0.1:8766/`。首页「体验长难句」按需添加神学原句与两段补充示例，也可继续读原有书籍。

- 选择句子/段落后，统一使用翻译、语法分析、记笔记、书签、发音操作。跨段选择明确拒绝，避免使用旧选区。
- 只翻译所选原文，右侧显示可联动译文；窄屏放在原文下面。悬停对应原文高亮，点击译文定位源范围。生成期间正文可读，允许取消；不导航到后台任务。
- 语法根据选区补齐完整句子，包含主干、层级、并列、修饰及回指。首次由选区主动触发；结果在源段落下方展开。已有结果以 +/− 收放并复用，不产生新模型调用；悬停原文或树节点高亮对应结构，点击树节点可定位原文。翻译和笔记保持原选区。
- 点词先显示词典释义与单词音标，再由用户主动请求上下文 AI。多词和段落朗读不展示音标。
- 发音优先使用电脑已安装的英文音色；本版本 Mac 通过 `say` 与 `afconvert` 生成可缓存 WAV，浏览器原位播放。浏览器本机语音是离线备选；自然语音必须在设置明确选用。准备阶段可取消；停止、翻页、换选区或离开阅读器均清理音频。阅读页面无额外播放器。
- 读完或主动打开「阅读痕迹」，汇总全书各章节原始笔记、书签、查阅词义、译文和语法记录。AI 仅整理勾选的记录；回顾先是可编辑草稿，再确认保存，不改写原记录。

## 代码与插件边界

核心文件：`web/reader.js`（页面生命周期）、`web/pagination.js`（原文分页/定位）、`web/reading-interactions.js`（统一选区、模型请求与词义浮层）、`web/reading-traces.js`（全书痕迹与回顾）。

可清退模块：`web/plugins/grammar.js` + `src/wise_reader/plugins/grammar.py`；`web/plugins/translate.js` + `src/wise_reader/plugins/translate.py`；`web/plugins/tts.js` + `src/wise_reader/plugins/tts.py`。注册表 `src/wise_reader/plugins/catalog.py`，本版新增语法插件，共 16 项。关闭只隐藏对应入口/拒绝对应路由，保留数据。其他插件仍按原契约安装、卸载。

`src/wise_reader/reading_assist.py` 提供共享选区验证、结构化 AI 服务、缓存记录与回顾。迁移只增建 `wr_assist`、`wr_review` 和 schema 3 记录；旧数据不重建。开发前以 SQLite Backup API 备份原库，路径记录在 `outputs/wise-reader-web-v3-20261004/data-before.json`。

## 定位与生成契约

原文版本使用内容 SHA-256，块 ID 保持稳定。页码只属于当前布局。每个源片段包含块 ID、原文 UTF-16 start/end；所有文字完整重建原文。测量分页只测正文，分析展开不重新计算页码。改变字号、密度、源栏宽则按当前原文锚点重排。搜索检查整章，不局限当前页。目录、笔记、书签和续读均能换页定位。

AI 输入仅本次选区；上下文解释额外带附近最多约 900 个字符。翻译返回有序精确原文片段，服务端校验无遗漏、改写和错序；语法使用所给 token 编号，校验节点范围、唯一根、父子引用、循环和数量。所有模型文字用纯文本转义，不执行 HTML。模型未配置、网络失败或无效结果均不影响正文，不缓存为成功。

原文保留 PDF 连字，词典键使用 NFKC 规范化；不会把 `Inﬁnite` 拆成错误词条。旧模型注释若与新分词后的原文范围不符，不再错误显示，历史数据仍保留。

模型缓存按内容版本、范围、任务、提示版本和提供者身份区分；凭据仅用于摘要键，不回传。准备取消会中止浏览器请求并发送独立取消回执，服务端拒绝写入迟到结果；若写入与取消交错，只回滚该请求新建的记录，复用的旧缓存保留。回顾取消同样保留之前确认的内容。迟到结果不会覆盖 UI；供应商已开始的调用是否计费由供应商决定。加载阅读器及导入不自动发起整章模型调用。

新增接口：`POST /api/documents/{id}/translate-selection|grammar|context`（`{anchor, request_id}`），`GET /api/documents/{id}/assists|traces|review`，`POST .../review`（选中来源 ID 或确认草稿），`DELETE .../assists/{assist_id}`、`DELETE .../assist-requests/{request_id}`，`POST /api/speech/local`。旧手工译文表与读写 API 保留；旧整章/整书生成路由明确拒绝新任务。

## 验证与限制

开发前失败清单见 `11-reading-prototype-failure-cases.md`。开发结束执行 `.venv/bin/python scripts/e2e_acceptance.py`，报告在 `.runtime/acceptance/<UTC时间>/`，含源码 ZIP/哈希、浏览器报告、trace、截图和复现说明。测试使用临时 SQLite 与 18768 本机模型 fixture，不使用用户书架或真实模型凭据。完整结果及首个失败保留位置在交付记录中补充。

自动化验证定位、持久化、请求范围、交互与播放生命周期。模型内容 fixture 不证明真实译文、语法正确性；Mac 本地 WAV 能生成、能播放也不证明达到神经 TTS 音质。本版不下载或安装新的语音模型；真实模型质量与听感请在体验中评估。
