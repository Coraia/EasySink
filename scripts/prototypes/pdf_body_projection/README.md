# PDF 正文投影 · 评审原型

在 EasySink 根目录运行：

```sh
.venv/bin/python scripts/prototypes/pdf_body_projection/review.py
```

打开 [http://127.0.0.1:8767](http://127.0.0.1:8767/)。需要项目 Python 环境、项目词典和 `requirements-pdf-lab.txt` 中的依赖（通常安装在 `.venv-pdf-lab`）。每次启动生成五份合成 PDF，经真实本机导入；退出后清理临时数据。无真实翻译调用或个人书库写入。

- 点选原页框查看分类证据，可覆盖或恢复分类。只有该页与邻页的接缝会重新判定。
- 点选译文可在两张原页定位；请求栏显示真实旧版请求和原型送往模拟翻译器的请求。
- 「模拟下一页未就绪」暂时隐藏真实导入结果中的邻页，演示待续状态。刷新不清除会话内覆盖，重新启动会重置。

原型只评估合成的单栏数字 PDF；不包含 OCR／复杂版面验收、已有书库迁移、生产缓存变更或实际译文质量评估。
