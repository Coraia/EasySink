# V1.1：释义、语境词句收藏与再次遇见

## Problem Statement

读者需要在原文中读懂具体用法，并留下能够回到出处的词句。目前基础词典展示丢失义项；“已掌握”和“保留注释”覆盖同一全局状态；笔记不能替代不带想法的收藏。新能力不得牺牲 V1 已验收的沉浸阅读、翻页、选区、来源、性能与个人资料。

## Solution

在已有阅读器内升级词卡和按需语境解释，增加独立词语收藏、整体摘录划线、本书/全局收藏、轻量再次遇见和不改续读的来源预览。沿用插件开关；收藏、理解反馈、显式保留及个人笔记分别持久化。交付可运行 Web 与更新后的本机 macOS 客户端，代理先完整走查并修复，再交用户人工验收。

## User Stories

1. 作为读者，我希望看到多个可靠候选及词性、领域和来源，避免把通用释义误认成这里的含义。
2. 作为读者，我希望缺中文时看到已有英文或明确缺失，避免错误中文填空。
3. 作为读者，我希望固定表达整体注释，并仍能查询成员词，避免逐词误导。
4. 作为读者，我希望现有词注中的神学和技术义项不被首行截断丢掉。
5. 作为读者，我希望词卡能够收藏此处词语，不要求安装外部词典或登录。
6. 作为读者，我希望同词不同原句分别保留，并可按词归组，不被推定为相同词义。
7. 作为读者，我希望选中词的一部分或跨段原文也能留下划线。
8. 作为读者，我希望重复保存相同来源范围不产生副本。
9. 作为读者，我希望不同选区与已有重叠划线取并集，点击后立即变为删除划线。
10. 作为读者，我希望整条划线整体删除，不被局部擦除或拆分。
11. 作为读者，我希望不相邻的划线独立，只有新选区桥接时才合并。
12. 作为读者，我希望划线合并不丢掉原子范围的笔记、解释、我的释义或词语收藏。
13. 作为读者，我希望收藏不等于不懂，查阅或没有操作也不被推断为掌握。
14. 作为读者，我希望“已懂这里”只针对这次用法，且可以撤销到原先的未反馈状态。
15. 作为读者，我希望显式保留注释独立持续生效，即使我已理解或调低辅助密度。
16. 作为读者，我希望原来的全局偏好继续兼容，新反馈在此处优先，而无需清理旧数据。
17. 作为读者，我希望收藏时不自动请求 AI，且原句、上下文和来源固定保留。
18. 作为读者，我希望个人笔记和我的释义独立保存，取消收藏不删除个人想法。
19. 作为读者，我希望主动解释只取必要的句段及至多前后各一段，并能查看实际范围和截取情况。
20. 作为读者，我希望解释上下文不暗带个人笔记、画像或整章整书。
21. 作为读者，我希望已有有效解释在刷新、重开、换模型后继续可看，不自动重付费。
22. 作为读者，我希望重新解释明确使用当前模型，失败或结果未知不被自动重发。
23. 作为读者，我希望收藏解释先预览再采用，保留旧解释和来源，原文快照不被改写。
24. 作为读者，我希望 OCR 修订后旧解释不冒充新原文解释，无法可靠定位时不猜跳。
25. 作为读者，我希望阅读工具仅显示本书收藏，书架全局入口才汇总各书。
26. 作为读者，我希望回原文先预览，关闭后回入口且不改任何书的续读；明确继续读才切书。
27. 作为读者，我希望原书移走后仍可读保存的引用和来源，并知道不能定位的原因。
28. 作为读者，我希望每天在书架稳定再次遇见一条自己的收藏，阅读途中不被打断。
29. 作为读者，我希望主动换一条、暂不推荐三十天或持续关闭；取消收藏的条目立即退出。
30. 作为读者，我希望优先未见、尽量避开七天内重复，资料不足时不硬凑、不调用 AI。
31. 作为读者，我希望按书或选定记录导出可读文件和可恢复资料，含引用、语境、来源和所选个人内容。
32. 作为读者，我希望收藏、笔记、反馈与原书分别清理，永久操作明确范围，普通删除可撤销。
33. 作为读者，我希望恢复资料不会因本机编号相同而绑定到错误的书，重复恢复也不产生副本。
34. 作为读者，我希望功能关闭后数据仍在，重新开启恢复可用，而其他阅读功能不受影响。
35. 作为读者，我希望在长书、PDF、不同窗口和客户端中得到与 V1 相当的开书、翻页、选字和续读体验。

## Implementation Decisions

- 复用原文块、内容版本、UTF-16 锚点和跨段 segments；书籍归属由服务端确认，不信客户端 book_id。新增记录表与插件接口，不重写 V1 原文、旧反馈或笔记。
- 收藏快照由服务端从验证过的锚点构造，保留引用、必要上下文、书籍/篇章来源、内容身份与解释来源。相同类型同一位置幂等；词语记录不与摘录合并。
- 摘录只与同一篇章、同一可靠内容版本的真实相交范围并集；保留子引用关联。删除/合并/反馈提供有版本保护的撤销，不能覆盖后续修改或连带删除独立资料。
- 原型确认的状态机：选区与一条已存摘录完全相等 → 删除划线；其余 → 划线；保存后当前选区采用并集范围，入口切为删除。暂时调整选区不裁剪持久划线。
- 新的已懂/保留为独立的语境状态。明确保留优先，语境已懂可减少此处自动注释。旧全局 verdict 按原义兼容；不伪造旧语境。
- 基础词典保持离线可用与可替换，先修复义项丢失。词卡展示完整有结构义项与来源。可靠短语匹配优先自动成员注释，但不得吞掉显式保留。
- 主动语境解释构造当前句段和至多前后各一段，最多 6000 UTF-16 字符上下文及既有选区上限；超长段围绕选区截取并展示截取事实，包含请求实际文本。这个上限是本轮规格的有界实现参数，不改变主动使用必要上下文的体验。
- 语境解释身份绑定实际文本、上下文及解释协议；模型不是强制重算触发器。显式 regenerate 才创建新的调用。未知、重启、离线、限额与响应留存沿用原有安全语义；不得缓存错误为成功。
- 本书记录加载与画面渲染分离，不随每次翻页全量查书或重算长书；仅绘制可见原文范围。集合查询分页、索引、按书过滤；推荐在书架执行。
- 来源预览是临时对话层，允许外部点击或 Escape 关闭；不复用跨书回到刚才。可靠匹配由服务端给出，明确继续读才调用现有跳转。
- 再次遇见使用本地持久选择、展示日期和暂不推荐状态；当天稳定，尽量七天避重，三十天暂不推荐，持续关闭。只从当前仍存在的主动收藏中选取。
- 导出可读 Markdown 和版本化 JSON，导入验证结构/上限、稳定身份和来源内容匹配，不信旧数字 ID；不能定位者保留快照。清理各类记录显式独立。
- 使用现有本机访问锁与插件路由保护；不引入新账户、云同步或外部字典凭据。私有书籍和真实模型响应只留本地证据。

## Testing Decisions

- 用户已授权直接完成流程并偏好真实点击；沿用已确认的浏览器 E2E 最高入口，从书架进入阅读、选区操作、资料保存、刷新重启、导出恢复和来源往返。无需重复确认验收入口，不新增事后单元测试。
- 开发中只做必要语法/现有定向检查；最后完整直接走查，并保留步骤、截图、实际 API/请求、首失败与修复复验。模拟供应商/故障证据与真实模型质量分开。
- 日常英文、神学和技术各至少十个固定真实词句，核对正文词注、词卡与实际配置 AI；覆盖熟词偏义、短语、中文缺失。确定误导须修复或退回候选/未知，译法合理争议标明而非让模型自判通过。
- 在同一环境对照 V1 固定版本与候选：开书可读时间、连续翻页帧间隔/收尾、选区响应、往返后的内存和离线。沿用原预算，增量操作不得破坏阅读记录；V1 已接受延期项继续明示，不把它们变成新通过。
- 新记录验收零错绑、零意外丢失；换书/预览/刷新无多余付费；集合增加与关闭不降低纸面 DPI。用户库升级前备份，更新客户端后核对源文件摘要与实际窗口走查。

## Out of Scope

欧路同步、外部词库管理、云端账号/同步、整书翻译、自动生成金句、复杂背词计划、V2 精准能力模型、重新实现纸张翻页与 OCR 引擎、公开签名公证分发。既有能力只进行兼容和回归修复。

## Further Notes

依据 Q1–Q24 的全部接受与用户明确指令“直接走 to-spec to-tickets implement…完成走查，有问题就修复”。因此任务粒度和具体工程细节由开发主控决定并留痕，不再增加一轮确认。公开票不含本机私有路径、资料或凭据。最终交付仍是待用户人工验收的 V1.1 成品候选，而不是宣称用户已经验收。
