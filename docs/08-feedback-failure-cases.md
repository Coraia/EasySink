# 2026-10-04：阅读反馈问题的失败场景与 E2E 验收设计

开发前记录。仅新增端到端场景；开发中运行目标场景，完整套件只在最终验收运行。

1. 注释保留：当自动注释达到预算时新增一个互不重叠的保留词，不应挤掉已有注释；重复点击不得重复计数；刷新、改变密度后仍有效；撤销应恢复此前熟悉度，而不是抹掉原有反馈；同一位置的词组与单词发生重叠时只保留一个行内解释。
2. 密度：当前用户的示例文章（485 词，词频门槛 4500）在 4/8 档均为 16 处。数量上限改变而固定候选范围不变导致体验无变化。更多辅助应适当放宽普通词候选，同时仍过滤功能词、专名、已掌握词。候选已耗尽时必须说明，不为了凑数重复标注。原文档位只保留显式要求保留的词。
3. 书签：同一段落反复点击应增/删切换；正文显示可键盘操作的书签标识；刷新、密度改变、排版改变和禁用续读后，标识与定位仍正常；双击不得制造重复记录；删除清理关联锚点；历史重复书签不得导致“撤销后还有一个”。
4. AI 配置：页面提供语言模型、语音各自的地址/模型/key/启用状态。key 仅写服务端受限文件，不进入浏览器草稿、URL、接口返回、日志或验收附件。空 key 保留已存凭据；显式清除凭据后功能失效。坏地址、401、超时、空响应、畸形 JSON 不得声称连接成功或破坏正文。热更新必须同时影响 profile、注释、翻译与后台任务，不需重启；页面重开后配置仍在。语言模型有凭据不代表支持语音。
5. 朗读：本机模式可选英文声音，不能总选第一个。自然语音使用可配置的兼容 speech 服务，仅传原文，标示 AI 语音；提供试听、语速、暂停/继续、停止、加载与错误状态。分段限长；停止/离开页面时中止请求、释放音频 URL，迟到响应不能继续播放；已生成分段按文本/模型/声音/配置隔离缓存；无凭据不能偷偷退回本机语音。

复现原则：使用 Playwright 的真实浏览器＋真实 FastAPI＋临时 SQLite。AI 供应商使用本地 HTTP 测试服务，验证完整请求/返回/持久化/后台任务链路；明确不把测试服务的固定译文或 WAV 提示音当作真实模型质量验收。真实供应商音质需要用户输入自己的 key 后试听。

最终证据：保存 HTML 报告、逐场景 trace、截图、JSON 结果和运行环境/源码摘要；由可重复执行的脚本生成独立目录与校验清单，不覆盖上一轮证据。

真实内置浏览器发现的升级失败场景：2026-10-04 首轮完整 23 条通过后，重启真实服务并普通刷新，HTML 的 AI 菜单已出现，但旧 app.js 仍在浏览器缓存中，新路由进入“功能已关闭”。补充资源版本契约：入口模块、样式及动态插件必须使用同一个内容摘要前缀；旧 `/static` 请求不能让新页面继续引用旧插件。再次验收需同时验证真实内置浏览器刷新后的入口。
