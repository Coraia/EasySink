## What to build

在真实复杂 PDF 的实验阅读版中看到公式、表格、图片和说明，可靠结构或对应局部原图保留其意义，并能核对来源。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 固定复杂数字 PDF 样本包含行内/块级公式、特殊符号、图片说明及复杂/跨页表格，从同一导入阅读路径呈现。
- [ ] 结构内容直接进入阅读表示，不通过会丢图或压平单元格关系的普通文字通路二次破坏。
- [ ] 每个选定必需对象都能对照原件核对；无法可靠识别的公式/表格就地保留忠实局部原图和原页关联，零静默丢失。
- [ ] 回退与结构识别成功分别计数，记录错符号、表头关系、跨页漏项和模型资源问题；图像可见不算结构成功。
- [ ] 本票验证复杂数字 PDF；扫描复杂结构的最终覆盖在方案冻结前结合扫描实验结果核对，不外推为全部扫描件通过。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
