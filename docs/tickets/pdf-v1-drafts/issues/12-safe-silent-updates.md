## What to build

主动重新识别局部内容后，系统在安全时机应用已有的新结果，保持当前交互、阅读位置及记录，不让读者日常管理版本。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 从明确页/区域发起本机重新识别，得到新范围版本；局部结果不覆盖范围外内容，旧原件和有效结果可回溯。
- [ ] 翻页停驻、文字划选、笔记输入及理解辅助操作途中固定当前表示；安全时机自动应用，不要求点击使用新版，也不切换原版视图。
- [ ] 可可靠对应的记录自动迁移；无法对应保留旧引用与原页位置并标明状态，不猜测或阻断其他安全更新。
- [ ] 依赖旧文字的辅助缓存区别版本，已有结果应用不自动新发 AI 请求；范围外有效结果继续可复用。
- [ ] 过时代次、迟到结果和切书后回调不能覆盖新版本或当前书；保留版本修订前后的目标 E2E 与截图。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
