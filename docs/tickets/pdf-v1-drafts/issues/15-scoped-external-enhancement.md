## What to build

读者主动选定服务和页/区域进行外部增强，结果进入原有阅读与版本流程，相同有效结果再次使用时不重复调用。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 入口清楚表达服务/模型、选定范围和必要上下文，文本模型不被假定有图像能力，能力不支持时发送前给出可操作状态。
- [ ] 一次业务操作完成授权，不加授权/费用确认或强制预算输入；本机失败/已有配置不自动外发，不支持整本付费外部转换。
- [ ] 响应经结构和来源检查后形成局部结果，按安全更新流程应用；界面离开不丢任务，迟到响应校验任务/书籍状态再发布。
- [ ] 业务意图、有效结果及在途处理去重；相同内容/范围/设置匹配有效结果时零新请求，保存原响应和必要重放资料。
- [ ] 派发意图、尝试和响应持久记录，未知结果不自动重发；任务详情显示请求、实际用量及可靠/估算/未知费用，不泄露凭据。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
