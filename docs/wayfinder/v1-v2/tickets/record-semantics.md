## Question

已确定收藏、掌握反馈和保留注释相互独立；它们分别作用于词形、词义、一次语境出现还是一段原文，如何归并和保留来源？

本票需明确：
- 同一个词在两本书中词义不同、一个短语包含熟词、同段收藏多句时，哪些记录合并，哪些必须分开。
- 无法可靠辨认义项时如何保存，避免伪造确定词义；收藏是否允许不附笔记，以及取消与撤销的含义。
- 书籍回收、永久清理、重新导入、OCR 修订后，哪些原文快照与定位仍可用，何时明确提示来源不可恢复。
- 旧版“保留注释→unknown”和覆盖式掌握记录如何迁移并保留不确定性，避免把历史操作解释成独立能力证据。
- 与笔记、书签、阅读痕迹的边界及统一导出/清除时的关系。

收口依据：用户确认的场景表、领域关系与迁移原则，供原型和后续规格使用；本票不执行数据库迁移。
