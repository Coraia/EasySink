# 正式版笔记验收约定

范围：接入已通过的 notes 原型；保留真实的选区翻译、语法、朗读和书签。笔记逻辑仍在 notes 插件内，关闭插件不删除记录。

修改前的失败条件：

- 底部入口打开列表；选区入口创建独立的新笔记，不能载入旧记录或共享草稿。
- 原文标记不增加正文字符、不破坏 UTF-16 位置或改变分页高度；只处理可见页，翻页重绘。
- 引用及位置在编辑时固定；空白编辑不能覆盖已保存内容；多次输入、关闭、重开不能串写。
- 保存以服务端确认作为成功依据；每条草稿独立持久化。失败明确说明可重试；浏览器保存失败不能声称草稿已保留。
- 删除须等待已发出的保存，阻止未发出的保存；撤销恢复引用和位置；图标数量、列表及原文标记同步。
- 点击引用定位并高亮，能回到刚才；跨章定位、当前章筛选与全书随记语义明确。
- 编辑卡靠近原文，列表编辑不翻页；窄屏不越界，滚动不穿透；原文始终可见。
- 原来的单草稿迁移只保留真正未提交的内容，不能把已保存笔记重复创建。
- 工具栏连续点击区域和层级保持；同一区域回切到 banner。进度使用已通过的进度线图标。

验收只使用独立数据库、公开合成文本和本地 AI fixture。测试服务允许以文件控制写入失败/延迟，用于验证错误状态、队列和草稿恢复；故障控制不进入产品代码。先记录首次失败，再修复与复测。开发时不运行全套 E2E，不新增单元测试。结束时交付针对性生产浏览器 E2E 的观察值、截图、源代码快照和可复现步骤。
