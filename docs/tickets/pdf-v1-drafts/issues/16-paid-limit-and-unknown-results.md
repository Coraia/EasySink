## What to build

设置可选的 PDF 调用次数上限，在并发和请求不确定时仍可控；超时、重启及明确新尝试不会隐含重复付费。

## Acceptance criteria

- [ ] 默认没有隐藏硬限额或每任务预算步骤，设置可选调用次数上限；两个同时操作的预留保证未发新请求不突破已设上限。
- [ ] 已发或可能已发、结果未知的尝试保留占用；只有确定未发可释放，不把未知费用当零或失败免费。
- [ ] 响应已收到而提交失败可从已有响应恢复，服务支持时查询已有结果；无查询能力保持未知，重启不会盲目重发。
- [ ] 主动重新请求建立新尝试且可能计费；达到上限暂停新请求，修改/继续是直接业务操作，不弹第二次授权。
- [ ] PDF 限额不默默阻断旧选区翻译/解释；模拟收件证明范围和次数，真实供应商查询/用量能力单独核对，不承诺准确账单或退款。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
