## 可能失败的路径

- 回归入口：专注态隐藏工具；更多功能需二级入口；笔记入口只展示列表，选区记一笔才新建；进度滑块按源比例而非旧页码 select；单/双页翻页步长不同；底部工具面板关闭后 banner 保留。迁移不得通过虚构旧 DOM 或直接调用 Reader 内部方法绕过 UI。
- 导入：准备阶段仍持有 Store 锁；鉴权同步等待锁阻塞事件循环；移动事务外的分析失去缓存/原子性；同时导入交叉写入；错误章落半本书；CPU 阶段长时间占用 GIL；快速打开漏分析；上传断开仍落半本书。
- EPUB：blockquote/p 和 li/p 继承错误；嵌套列表丢段或合并；单元格分隔符变成单独段落；pre/code 缩进丢失；head/script/style 泄漏；空单元格/无 p 的表格；多段引用；不完整 HTML；修复误改既有版本和锚点。
- AI：相同 identity 重复请求；不同 request_id 共享任务时一人取消影响其他人；同 request_id 重复消费者取消；已取消结果落库；缓存命中被取消误删；独占新结果取消未撤销；失败/超时任务无法重试；配置变更共享错模型；客户端断连未释放任务；服务退出残留任务；回顾接口未接入取消。

## 验证计划

使用一次性数据库和本机模型夹具的 HTTP / 浏览器 E2E；代码完成后才运行全套。保留首失败和最终修复结果、trace、截图、JSON。重点：并发 provider 调用数、共享消费者取消、独占取消延迟、重试；导入期间 API 响应与失败无残留；嵌套 EPUB 导入→API→浏览器渲染；当前工具栏/选区/笔记 CRUD/抓页/进度回退、源锚点重排与重开、登录与插件开关。性能数字区分一次样本、缓存、浏览器冷启动和真实模型质量。

取消仅能保证本地 HTTP 任务及结果管理；不保证远端服务已停止计算或停止计费。完整 EPUB 表格原书布局/脚注并不在本次范围：保留行与单元格语义，提供稳定可读文本。
