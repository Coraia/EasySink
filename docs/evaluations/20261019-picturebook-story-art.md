# 情节插画实现与验收 · 2026-10-19

后续全书制作已完成，见 [27 章 / 60 幅关键情节全书记录](20261019-picturebook-full.md)。本页保留十八句改写示例与通用生成接口的历史验收边界。

目标：在当前《小王子》原创短篇的六幕十八句之间悬浮、点击和按键时，显示对应事件的不同分镜；保持人物与画风一致。通用材料的运行时生成由独立的插画服务配置支持，不能将 Codex 内置 image_gen 工具冒充为应用运行时 API。

## 实现前列出的失败方式

后续将用隔离服务的浏览器 E2E 核对请求与恢复行为；这些证据与真实 image_gen 成图分别记录。

- 分镜不对应句意、同幕三句仍复用同一个画面、角色漂移、分镜格位置错误。
- 快速悬浮导致迟到图片覆盖当前句；图片加载失败、刷新未缓存、资源 URL 失效。
- 内容已修改、同句不同语境或同名书误用旧图；缺失锚点仍发出请求。
- 服务未配置、密钥无效、限流、失败、畸形或超大响应、不支持的图片格式。
- 超时、断连、服务重启造成结果未知；自动重试重复收费；并发点击重复提交。
- 生成期间离开页面、切换版本或刷新丢失状态；部分完成被全部丢弃；重试覆盖首次失败证据。
- 插画配置复用文本模型凭据、密钥被回填前端、服务地址变化误带旧凭据。
- 翻页、中文提示、续读、普通版与小屏排版回归。

## 约定

《小王子》用内置 image_gen 真实生成十八个语义分镜，保存为六张 2×2 本地分镜图集，前三格依次对应三句，第四格作封面。每句按原文精确匹配取格，不以放大或平移模拟新事件。

通用运行时生成调用用户单独设置的 Images API 兼容服务，用户点击「生成本幕插画」授权当前三句与必要上下文；完成后悬浮只读本地缓存。没有服务时明确显示设置入口。失败或结果未知不自动重试，明确的「重新请求」才发起新请求，保留各次尝试。

接口参考：[OpenAI 官方 Create image 文档](https://developers.openai.com/api/reference/resources/images/methods/generate?site_locale=en)，本次采用 `POST /images/generations` 的 `model`、`prompt`、`n`、`size` 与 `data[].b64_json`，模型名称由配置指定，不继承文本模型。

## 最终证据

运行时协议走查已完成：独立插画配置保存且密钥不回填；一次生成当前三句；刷新读缓存；断连、畸形响应、401、生成中进程退出后的结果未知；明确重试；已有图片与未知请求分开；离开阅读页后完成结果仍可读取。使用本机协议供应商模拟，不作为该供应商真实生成质量的证据。

协议证据位于 `outputs/picturebook-story-art-20261019/`：`runtime-walkthrough.json`、`protocol-observations.json`、`config-observations.json`、`final-cache-check.json`、`provider-requests.json`、`attempt-history.json`。11 次供应商调用与 11 条尝试记录一一对应，其中保留 3 次 unknown 和 1 次 failed。无效原文锚点返回 409，供应商调用增加 0；重启后读取与重复提交已有 ready 结果，供应商调用增加 0。返回的原始图片材料在隔离数据目录 `picturebook-art/*.response.json` 中保留，未暴露为公共接口。

既有定向 E2E 为 5 passed / 0 failed：粘贴导入、偏好持久化、AI 配置与翻译、凭据验证、手机宽度设置页。trace 与截图在 `regressions/`。未新增事后单元测试，未运行全产品完整 E2E 套件。

《小王子》的六张分镜图集已由内置 image_gen 真实生成，十八句全部通过浏览器真实鼠标悬浮核对。`sentence-hover-walkthrough.json` 逐句记录英文、中文画面描述、实际 frameKey、背景格位置与事件到画面就绪的自动化观测时间。`frame-01.png` 至 `frame-18.png` 为实际应用的画面区域截图，RGB 像素 SHA-256 全部不同，证明切换了不同画面，而非只移动或缩放。语义对应另经六张实际生成原图逐格目视核对，不能仅由哈希差异推出。

`pixel-verification.json` 保留十八幅截图的像素校验与时间原始值；`scene-1-verified.png` 至 `scene-6-verified.png` 为六幕实际完整窗口；`rose-1-verified.png` 至 `rose-3-verified.png` 为玫瑰绽放、浇水、保护的完整窗口。先前区域截图与 fullPage 抓取均保留；完整界面以 verified 文件为准。`final-ui-checks.json` 记录快速来回悬浮、键盘跨幕前后、刷新续读、版本切换、390 px 宽布局，无控制台错误。手机宽度仅为浏览器模拟，不是手机实机验收。

当前预览：[直接体验逐句情节插画](http://127.0.0.1:18805/#/picturebook/1)。独立数据仍在 `.runtime/picturebook-preview-20261019/`，没有覆盖个人书库或已安装客户端。示例读取本地真实生成资源，预览库的运行时付费 API 尝试记录为 0。通用生成接口与真实外部供应商的计费、模型质量和角色一致性尚未实测；协议验收使用隔离供应商，不能与内置 image_gen 的真实成图证据混写。

## 交付文件与复现

- 前端交互：`web/picturebook-art.js`，接入 `web/picturebook.js`，逐句按锚点匹配；图片加载设置递增序号，迟到结果不得覆盖新句子。没有插画或载入失败时明确显示氛围背景，英文仍可继续阅读。
- 生成与状态：`src/wise_reader/picturebook.py`。独立配置位于 `AI 与语音 → 故事插画服务`。一次最多授权三句及必要上下文，成功、失败、结果未知和每次尝试均保留在当前用户库；收到的原始材料先存盘再解析。文件只经当前本机 API 读取，不直接下载供应商返回的任意 URL。
- 本地成图：`web/assets/picturebook/chapter-01-story-v2.webp` 至 `chapter-06-story-v2.webp`；十八句映射在 `story-manifest.json`，六次内置 image_gen 的完整提示词及来源记录在 `story-generation.json`，没有切换 CLI 或外部 API 来生成示例。
- 后台运行与复现预览的命令见 [首版记录](20261019-picturebook.md)。重新打开体验页，选择第二幕，依次停在三句英文上，应显示绽放、浇水、盖玻璃罩三个动作。
- 通用运行时复现：设置独立图像服务，导入自己的短篇英文，切换少儿版后点击「生成本幕插画」。配置保存仅说明保存成功，实际服务可用性由生成结果确认；后续悬浮及刷新只读取已有本地图片。
