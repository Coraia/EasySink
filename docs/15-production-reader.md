# 正式阅读器分页与工具层

2026-10-05。将已验收原型合入正式 web；未更改用户书库/AI 配置。

## 交互与入口

打开文章、书架书籍或导入完成后的开始阅读，默认进入专注。书籍入口恢复上次章节。顶部 64px 区域呼出顶部 banner 与底部工具层；工具层盖住阅读区并使其 inert，关闭点击被消耗。空白左/右区域翻页；文字、选区、卡片和面板操作不触发翻页。

底部六个图标分别是目录、笔记、进度、样式、字体、更多。更多保留书签、选区翻译、朗读、搜索、阅读痕迹、辅助密度、归档/读完、设置及章节入口。目录与笔记独立。面板采用固定覆盖，避免正文宽度或页数随工具显隐变化。取消插件时移除入口，记录仍保留。

## 模块边界

| 模块 | 职责 |
|---|---|
| reader-chrome.js | 阅读壳、点击区域、工具覆盖层、核心图标与进度/样式/更多 |
| pagination.js | UTF-16 原文锚点、自适应单双页、测量与分片、后台分页、按需页 DOM |
| page-curl-renderer.js | 单一 GPU 上下文、卷曲网格、纹理预热及有界缓存、光照/阴影、降级与释放 |
| reading-interactions.js | 原文选择、查词、原位语法、右侧译文、请求取消、可见错误/操作提示 |
| plugins/* | 各功能入口与持久化；保留插件管理开关 |

阅读 scope 拥有事件和资源，离开路由释放 GPU、监听器和后台工作。长段落书签和语法入口按 fragment 的原文 start/end 找落点，不能只按 block_id 匹配第一片段。分页/笔记/书签/搜索都使用源文本锚点，不持久化版式页码。

## 性能策略

首屏先渲染，剩余分页按约 5ms 时间片执行并让出事件循环，翻页期间暂停测量。仅当前一屏正文进入 DOM。预热相邻页图片，固定网格 64×16，单 reader 复用上下文/程序/缓冲。纹理缓存最多六叶、总 1600 万像素、单边 2048，纹理 DPR 上限 1.5。每帧只更新 GPU 参数，不重建整页 DOM、不读取全树样式。正常卷页 760ms；减少动态效果/关闭动画即时翻页，GPU 或栅格化失败回退。

首次原文、可操作、后台分页耗时和每次 RAF 帧间隔通过 DOM data-* 记录，仅作诊断。相同本机环境原型与正式版均约 16.67ms 平均帧间隔，未证明 FPS 提升；已验证资源复用和稳定帧间隔。真实 54,789 词书此次可操作 174.8ms（已有后端分析缓存），不能推广为百万词冷启动结果。
