# 阅读原型落地：开发前失败清单与验收契约

确认范围：原型变为现有 Web 产品。右侧只显示所选文字译文；语法由选区主动触发并在原段落下方展开，准备时可取消，已有结果用 +/− 重用；发音就地播放/停止，无底部播放器。默认词典，主动请求 AI 上下文。分页、笔记、书签和续读共同使用原文 UTF-16 偏移。读完保留原始痕迹，AI 回顾需主动请求并确认。

## 可能失败的方式（修改前列出）

- 长章/超长单段仍整体渲染，首屏阻塞；分页截断、丢字、重复、拆散词语或注释。
- 页码被当成数据位置；字体、密度、窗口或译文宽度变化导致续读、书签、笔记错位；补充平面字符与连字偏移错误。
- 原文选择混入中文词注、书签、按钮、解析；跨段选择悄悄缩短；分析扩展整句后误扩大翻译和笔记选区。
- 翻译整章/整书或导航后台任务；结果突然跳页；原文/译文高亮错位；重复句定位错误；AI 改写原文仍被接收。
- 语法先加载就调用模型；右侧被语法占用；取消后出现迟到结果；+ 再次收费；代词、形式 it、同位语、主干和嵌套结构被混淆。
- AI 未配置、超时、坏 JSON、循环树、非法引用、HTML、过期内容等引发正文不可读或无提示；凭据或整本书进入请求/日志。
- 词典发音音标丢失；多个词误展示音标；自动调用远程语音；本地不可用而静默把原文传到远端；点击停止仍延迟播放或叠播。
- 播放控件在重绘后丢状态；切页/离开时声音无入口可停止；额外播放器挤动正文；隐藏音频资源/临时文件不清理。
- 搜索只查当前页；目录、笔记跳转不能换页；翻页不保存进度；关闭插件影响核心阅读或删除已有记录。
- 原有笔记草稿和反馈丢失；回顾改写/删除原始记录；没有明确 AI 来源；保存失败被写成成功。
- 手机上的选择、菜单、译文和语法溢出；浅色/深色不可读；旧路由的请求覆盖新页面。

## 交付与验证

维持原生 ES modules/FastAPI/SQLite。分页为核心模块，语法、翻译、朗读、笔记、回顾接口按生命周期隔离；关闭可选能力仅隐藏入口，保留数据。不改用户原文。迁移为增量建表，先备份用户库。

开发完成后运行整套浏览器 E2E；仅使用临时库和本机确定性模型/音频 fixture。保留源码 ZIP、哈希、首个失败、trace、截图、报告与复现说明。浏览器音频生命周期/原文 payload 检查不等于音质验收；实际模型译文和语法准确性需用户体验确认。

## EPUB 书架聚合补充（2026-10-05）

用户指出此前导入的一本 EPUB 在书架变成多个条目。可能失败方式：插件得到的是新对象而非核心渲染状态；加载完成未重绘；异步加载时章节先闪现；计数仍按章节数；搜索或刷新后重复章节卡片；旧同名导入被误当同一版本而破坏笔记。修复仅使同一本书的章节聚合展示，不按标题自动删除或合并历史重复导入。旧整书翻译入口也不应继续出现。验证用实际浏览器完成导入→书架→章节→刷新→搜索，且观察加载过程从未渲染该书章节卡片。

## 单词卡片滚动补充（2026-10-05，修改前）

可能失败：卡片不够长时触控板滚动传给背景；卡片到顶部/底部后滚动串到文章；音标、AI入口或异步解释增加高度后沿用旧坐标而被屏幕截断；调整窗口或移动端视觉视口后越界；取消/关闭后监听器残留，正文无法恢复滚动。期望卡片内滚动仅影响卡片，背景仍可在卡片外自然滚动；异步内容和窗口变化后重新约束位置；保留原有关闭、词汇反馈及就地发音。浏览器验证用真实 wheel 输入，不以 CSS 属性检查替代滚动行为；长解释使用本机模型 fixture，不调用用户配置的供应商。
