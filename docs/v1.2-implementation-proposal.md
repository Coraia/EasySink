### 建议最小修复

- 在“有原行几何的阅读文本整理”边界修复，不改词典、不过滤全部短词，不在全局 tokenizer 正则里吃掉任意连字符；本轮真实 engine 为 omarchy，首先覆盖其保留行重放路径。
- 原始 OCR 行/原件/raw_text/bbox 不动。按同页同段同栏、上一行末/下一行首、正文而非代码/公式/列表、拼接词与保留连字符词的词典歧义进行保守判定；词典只提供候选证据，不能独自决定删横线。无足够证据保持原样并可诊断，不猜跨页/跨栏。
- 产出新的转换/阅读版本及确定的旧→新偏移映射，包含被移除的行末连字符、连接空格和每段来源行范围；记录 normalization_version 与规则理由。原锚点坐标采用既有 UTF-16/segments，转换内部 codepoint 偏移显式转换，覆盖代理对/连字，不混用本轮2202数字为UI偏移。
- 沿用 `wr_pdf_revision` 保留旧阅读版、`wr_pdf_anchor_status` 与安全静默更新。新版本使内容分析/分页缓存按实际版本失效；未改区域可精确迁移，任何含断词变化的引用需比对映射及quote，不用“同块ID”自动搬用语义。
- 旧收藏/采用/掌握快照不改写。尤其旧 `dis` 的采用不能自动成为完整 `discipleship` 的解释。无法可靠映射则留旧版本可读引用和原页来源，明确不可直接返回新文；同词其他出现不变。选区/翻页/笔记输入期间不换当前版本。
- 先用保留行本地重放，不默认再请求远端 OCR。旧版也可用，不静默重写现有用户库；正式升级须单独备份/迁移授权与回滚证据。

### 最小用户终点及接口方向（推荐，未实施）

在现有导入对话层增加“网络链接”，粘贴→一次导入→显示标题/来源与明确结果→进入现有独立文章 Document 阅读路径；不把文章虚构成多章书。保持两层交互，不新建常驻抓取服务。复用 `Engine.prepare_import/persist_import` 的分析/事务边界和现有内容块/续读/收藏能力；URL内容、来源元数据、资产和去重登记必须原子提交。现有纯文字 `/api/documents` 不能单独承担结构快照。

推荐新增受既有本机访问锁/插件保护的单URL导入接口（如 POST `/api/import/url`）与独立来源记录；命名与既有鉴权确认后随G2规格冻结，而非本轮写死为已批准API。失败不留下成功书架项；提交结果未知时按稳定请求ID查询，不能再发一轮抓取/落库造成副本。

保存：原始/最终URL、抓取时间、HTTP类型/状态、可用标题/作者/发布时间及其提取来源、响应内容hash、提取器版本、清理后的结构快照和本地必要图片资产。原HTML可作为不可执行的有界重放资料（不挂在可执行同源页面下）；重新阅读只消费清理快照，不执行网站脚本、不后台刷新。

- 正文提取：先语义 article/main 和可验证正文候选；多候选歧义、空壳、登录墙或关键结构缺失明确失败/不完整，不用最短“HTTP成功”标准。指定页逐段核对首尾、所有小标题、两处图表及说明；标题/日期不是正文第一段。代码保留空白，列表保留层级，引用/表格与来源链接保留必要结构；解析器输出缺字段时不能默默宣称全保留。
- 图片：推荐纳入正文必需图片/图表并保存本地，最多10张、单张5MiB、总资源20MiB（含HTML）、解码像素上限16MP；仅安全静态栅格，SVG/动画/复杂嵌入先提示不支持，不拉追踪像素/字体/媒体。每个图片及重定向也走网络安全门；失败列明缺哪一图。若产品选择纯文本版，须由 Fisher 接受指定案例图表缺失，不能悄悄降级。本轮不下载这些图片或引入依赖。
- 来源与去重：保守URL规范化仅去fragment、规范主机/默认端口，不任意删query。最终URL＋内容身份用于同源快照；客户端operation_id消重。相同URL相同内容复用已有文章及续读；同URL内容变化保留旧快照，明确提示创建新快照，绝不覆盖阅读记录。不同URL即使同文字也保留来源区别；canonical标签只作线索不当授权重定向。
- SSRF：仅 HTTP(S)，建议默认仅80/443，无用户信息段；拒绝本机/私网/环回/link-local/组播/保留范围及IPv4映射IPv6、非标准地址写法。每跳解析所有A/AAAA并确认公共地址；固定已验证连接目标并保留Host/TLS校验，处理DNS rebinding，不能只在连接前做一次 `is_private`。不继承环境代理/本机cookie/Authorization，不允许file/ftp/gopher。若当前HTTP栈无法可靠固定IP，先限制来源或阻塞实现选择，不凭字符串检查宣布安全。
- 重定向最多3跳，逐跳校验scheme/地址/端口，HTTPS不降级；大小对解压后正文也计数，不信Content-Length，连接10秒/总30秒，HTML上限5MiB、抽取正文上限50万字符（沿旧单篇边界）、并发1，用户取消停止未提交操作。超额明确返回原因，无半成品成功。
- HTML净化：先去script/style/iframe/form/active SVG/事件属性等，转到受控语义数据再由现有转义渲染；不通过innerHTML执行远端标记。资源名服务器生成；不保存网页cookie/表单输入，不将读者原文/笔记发送给网站或模型。
- 首版不支持URL直接指PDF，按实际Content-Type拒绝并指向现有文件导入；不静默选择外部OCR。动态壳/付费墙/需登录页面明确不支持，不启无头浏览器绕过。

## 5. 本机证据最小契约（提案）

### 收什么、不收什么

自然操作：查词/表达；解释发起/完成/失败/取消/结果未知/缓存命中；掌握声明的设置/清除；保留注释设置/取消；采用/撤销及并发拒绝；收藏/取消（不是掌握）；辅助密度改变；篇章打开/续读保存；有界可见范围与活动片段。不得按事件名将收藏或查词解释成不会，不把服务端候选当已展示，不回填旧历史。

可见范围只在阅读页稳定呈现、内容/标注/密度/采用发生变化时形成去重的 presentation；不采逐帧轨迹、全局键盘/剪贴板、鼠标坐标流、其他应用信息或笔记编辑内容。活动只记可见且本应用有近期活动的片段，明确“活动不等于读懂”；睡眠/失焦/后台暂停。

### 身份与重放

建议加新前缀表/插件，不让 stats/collections 表承载新的含混语义：

- event：schema_version、本机library随机身份、session_id、event_id、operation_id、session_seq、client_time、received_time、event_type、phase/status、cause/undo_of、资源revision前后值与错误码；不靠时钟先后或word拼写去重。没有账号/跨设备合并。清空采集后更新 collection_epoch，旧离线队列不得复活。
- occurrence：Document稳定身份＋source_identity/fingerprint＋内容/转换version＋Anchor(UTF-16、segments、quote、必要prefix/suffix)；PDF另带原页/区域/原件hash，不用阅读页码当锚点。
- presentation：实际可见原文范围、实际显示的自动/保留/采用注释及内容、词典/策略/设置版本、密度与必要布局状态。用内容hash关联去重快照，而不是每次复制整章。保存当时的结果，不在回放时用今天词典/模型重算；无操作的未显示内容仍未知。
- 有限原文快照用于重放：当前可见范围及操作所在句/必要上下文；解释直接引用既有实际上下文/截断信息，不因采集另发模型请求。不录全书或个人笔记；单快照建议32KiB，超额显式标截断、重放不完整，不能假称完整屏幕证据。只存hash没有可解引用内容不算可回放。
- 撤销是一条引用原操作和业务revision的事实，不删原事件。失败撤销/并发冲突不记作成功；业务撤销仍由既有 revision/undo 防护完成，采集层不能替代业务逻辑。

### 持久化、开关和容量

- 业务已有写事务时可同事务追加轻量采集outbox，避免“保存失败但记完成”，不增加每次操作独立同步落盘。纯展示/活动采样采用有界内存队列、异步批量持久化/发送（建议2秒或32事件），不逐帧/逐次同步写盘。每批≤64事件/256KiB，服务端幂等插入，确认前重试不变ID；读取/导出分页。新outbox应在本机而非远端。
- 崩溃前尚未持久化的短尾允许缺失但需标记session未正常结束、关联操作unknown/gap，不凭空补成功；已接受的事务事件重启可恢复。批量队列与业务成功不能靠“尽力发POST”假装可靠。拥塞/空间不足暂停采集而不阻断阅读，显示可发现的状态；需实测避免证据写失败回滚用户业务操作。
- 关闭采集立即停止新增/丢弃未确认队列，服务端同步拒收旧epoch；不删除已保存采集，不影响收藏/采用/掌握与原有续读。开关名称是“本机阅读证据”，清楚说明原有阅读统计独立，不承诺关闭该项等于关闭全产品所有业务记录。
- 导出版本化JSONL＋去重上下文清单＋可读索引，用户明确导出才产生文件，不自动上传；导出前提示含原文和阅读行为。导出保留事实/声明标签、未知/失败/截断。
- “清除阅读证据”只删新增事件、presentation/context和采集outbox，重置epoch；不删书/原件/收藏/笔记/采用历史/旧统计。要有取消/范围说明，不为删除采集加隐式业务撤销。用户已导出的文件无法远程撤回，透明说明。
- 建议容量256MiB，连续采集90天作为整理检查点，先到为界；统计占用包含去重上下文/队列/索引，磁盘压力留保守余量。推荐首版到界暂停并提示导出/清除，已采证据保留至用户明确清除，不把“90天后停采”写成“90天后自动删除”。用户若接受90天滚动保留，才实施TTL与引用计数GC、到期删除旧证据。期满/暂停必须可发现，不当作“继续积累中”。这是待批准产品取舍，非当前设置。
- 上述保留策略仅针对新采集资料，不得混到 ADR-0003 的原件、有效转换、付费重放、用户记录保留；这些不自动过期。
