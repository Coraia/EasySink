## What to build

在 PDF 阅读版像读现有书籍一样查词、按需解释/翻译、分析句子和发音，理解辅助与当前有效原文交互。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 基础词注、辅助密度和保留注释按原有规则工作；上下文解释仅由主动操作触发，单个新注释不覆盖其他保留注释。
- [ ] 选区文字及连字对应正确，译文仍与原文联动、右侧给译文，语法在原段落按需展开，不提供整书翻译。
- [ ] 单词带音标、段落播放从原入口操作，本机发音偏好保留，不出现重复的正文下播放卡片。
- [ ] 当前表示版本进入已有辅助结果身份；相关旧译文/语法不当新文字的有效结果，失效不自动产生付费请求。
- [ ] 阅读痕迹/AI 回顾沿用既有记录边界，生成整理不改写原始笔记；原版不扩建这些工具。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
