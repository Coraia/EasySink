## What to build

在可安装客户端内，用真实 Mac 触控板控制现有纸张翻页：移动跟手、接触停驻保持、回滑取消、松手及时收尾，连续及前后交替不锁住；纸面在新承载里保持清晰、装订形状和光影。接入原生事件与渲染适配沿一次真实翻页端到端完成，不重新开发阅读器。

本票以固定 EPUB 和已有阅读内容验证客户端输入/渲染，PDF 引擎质量及 Web 本身的 PDF 高清验收仍由原票承担。证据交给 [客户端原型决策](https://github.com/Coraia/EasySink/issues/34)，不把 phase fixture 当作用户已经接受手感。

## Acceptance criteria

- [ ] 安装产物内包含所需原生接入能力，不要求用户现场编译 Swift 或安装开发工具；新客户端真实接收开始、移动、接触停驻、结束与惯性阶段，不能靠超时猜测抬手。
- [ ] 输入只作用于正确的客户端阅读窗口；切换应用、工具层、选区菜单、笔记输入和缩放不误翻页。断开/恢复后保持可操作，不重复订阅造成一次手势翻多页。
- [ ] 单/双页下实际覆盖慢、中、快翻页、半途保持、反向取消、连续翻页、前后交替；取消保持原文位置，松手后迅速完成已决定的动作，不增加尾段输入锁。
- [ ] 静态、翻起、背面、落页使用一致正文与资源；已接受的装订形状、书脊约束和光影不回退。DPR1/2/3 的可验证渲染路径及真实设备高清证据分列，不能靠降低清晰度换速度。
- [ ] 适用场景的 P95 帧间隔/输入调度小于34ms、原生收尾小于240ms，保持不超过6张/24M缓存像素等现有守卫；覆盖整个输入与收尾序列，报告P50/P95/max和首失败，不删除卡顿尾段。
- [ ] 真人触控板、原生事件记录、程序生成phase、截图及浏览器内部计时分开描述；未取得真人设备证据保持待验收。
- [ ] 不修改已冻结的阅读记录/数据语义；需要改共享阅读核心时与现有阅读任务协调，保留旧浏览器对应路径的定向回归，不因客户端修复破坏原体验。
- [ ] 交付同一候选安装产物和可复现走查证据，用户可直接体验上述动作；新增绝对包体/启动/内存预算仍由原型决策统一确认。
