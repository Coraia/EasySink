# 产品方案

## 一、要解决的问题

读英文材料时，真正拖垮效率的不是"看不懂某个词"，而是**查词这个动作本身打断了阅读流**。

一次查词的完整代价：视线离开正文 → 切换应用或长按选词 → 等待结果 → 读释义 → 找回原来读到哪 → 重建上下文。单次十几秒，但**注意力的重建成本远高于时间成本**。一篇文章查十次，就是十次思路断裂，读完只剩疲惫，谈不上任何吸收。

现有工具都在优化"查得更快"（点击即译、悬停翻译）。**但更快的中断仍然是中断。**

正确的解法不是加速查词，而是**让查词这个动作根本不需要发生**：在读者遇到障碍之前，注释已经在那里了。

## 二、产品定义

> **一个把英文原文加工成"对我个人恰好可读"的阅读工具。**
>
> 输入你自己的英文材料，它根据你的词汇量和知识背景，自动决定哪些词、句式、习语、文化梗需要中文注释，并把注释以最不打扰的方式嵌进正文。

一句话卖点：**读之前就已经标好了，你的眼睛不需要离开正文。**

## 三、目标用户

**V1 只服务一个人：作者本人。** 这不是谦虚，是范围控制——一个用户能被完整满足的产品，才有资格谈第二个用户。

用户特征（决定了功能优先级）：

- 英文阅读量大，材料杂：技术文档、外刊、神学著作、求职相关英文内容
- 词汇量估计在 8000–12000 区间，远超四六级词表覆盖，通用词表对他毫无意义
- **知识背景极不均衡**：神学、数据工程领域的专业词汇和典故完全不需要注释，而美国政治、体育、流行文化的梗则完全陌生
- 正在备考雅思，且目标是海外远程工作，阅读是刚需不是兴趣
- 技术能力足够，能自建服务、自己部署

第三条特征是本产品存在的根本理由：**任何基于通用词表或统一难度分级的产品，对他都是错的**。圣经典故对他是噪音，对普通读者是刚需；橄榄球术语对他是刚需，对美国读者是常识。这种不均衡只能靠个人化模型解决。

## 四、核心体验原则

这五条是**验收的最高依据**。任何功能与它们冲突时，砍功能。

### 原则 1：沉浸优先于完备 —— 宁可漏标，不可滥标

漏标一个生词，代价是读者手动查一次（小遗憾）。
滥标一批不需要的词，代价是**满屏灰字、版面破碎、沉浸感彻底丧失**（产品失败）。

两者代价不对等，因此所有模糊判断一律偏向"不标"。

### 原则 2：注释密度有硬上限

设置**每百词最多 N 处注释**（默认 N=4，可调）。超出预算时，只保留最生僻的那些。

这条是沉浸感的总闸门。词频阈值决定"谁有资格被标"，密度上限决定"实际标几个"。**没有上限的个性化标注，在读者遇到超纲文章时会退化成满屏注释。**

### 原则 3：同一个词，一篇文章内只标第一次

同一个生词标五遍，第二遍开始就是纯噪音。LingQ 的全文高亮吃过这个亏。

（可配置为重复标注，但默认关闭。）

### 原则 4：注释不打断版面

行内灰色小字紧跟在词后：`ubiquitous(无所不在的)`。

不用上标（振假名式）——视觉上更沉浸，但会破坏文本自动换行与行高，在移动端尤其糟糕。不用侧边栏或脚注——那等于把中断从"查词"换成了"移动视线"。

### 原则 5：反馈成本必须是一次点击

读者点一下注释即可标记"这个我认识"（以后别标）或"这个我不认识"（以后一定标）。**不弹窗、不跳页、不需要确认。**

反馈成本高一分，数据质量降一半。而个人词表的质量，正是这个产品长期价值的全部来源。

## 五、北极星指标

> **一篇 800 词的文章，读完全程主动查词次数 = 0，且注释密度 ≤ 5%。**

两个条件必须同时成立：

- 只满足前者：说明标注过度（全标了当然不用查）
- 只满足后者：说明标注不足（干净但读不懂）

这个指标可以在每次阅读后由读者一键记录，作为系统调参的真实反馈。

## 六、功能范围

### V1 — 自用可跑通（第一优先级）

| 功能 | 说明 |
| --- | --- |
| 文本导入 | 粘贴纯文本。**不做 URL 抓取**（版权与解析复杂度都在 V1 之外） |
| L0 词汇标注 | 基于个人词汇量模型，词典驱动，零模型调用 |
| 行内注释渲染 | 灰色小字紧跟词后 |
| 一键反馈 | 点击注释 → 认识 / 不认识，即时写入个人词表 |
| 词汇量冷启动 | 自适应频带测试，20–25 题，10 分钟内 |
| 密度调节 | 一个滑块，实时调整注释密度，无需重新加工 |
| 阅读历史 | 存文章标题、时间、标注数、反馈数 |

**V1 完成的标志：作者本人开始每天用它读英文，而不是回去用原来的方式。**

### V2 — 覆盖词汇之外的三层

| 功能 | 说明 |
| --- | --- |
| L1 习语与搭配 | `take it with a grain of salt` 这类整体含义 ≠ 字面含义的组合 |
| L1 语法句式 | 倒装、虚拟语气、复杂从句嵌套的结构提示 |
| L1 文化背景 | 梗、典故、需要背景知识才能 get 到的表达 |
| 知识领域标签 | 勾选熟悉领域，命中的背景注释自动隐藏 |
| 生词本导出 | 导出为 Anki / CSV，不自建 SRS |

### V3 — 分发与变现（条件触发，非时间触发）

- 浏览器扩展（真正的沉浸：在原网页上直接加工）
- Stripe 订阅，面向英语非母语的欧美移民/留学生群体
- 微信小程序（**前提：已注册个体工商户**，见可行性档案第二节）

### 明确不做（非目标）

| 不做 | 原因 |
| --- | --- |
| 内置文章库 | 版权 + 需要出版资质，且用户自带材料才是真实场景 |
| 自建 SRS 背单词 | 赛道已饱和（Anki / 墨墨 / 扇贝），且与"沉浸阅读"是两件事 |
| 全文翻译 | 提供全文翻译 = 放弃阅读英文。这是产品价值的反面 |
| 社交 / 排行榜 / 打卡 | 与"专注读完一篇"直接冲突 |
| 听力 / 口语 / 写作 | 范围爆炸。先把阅读一件事做到极致 |
| 对话式 AI 助手 | 不仅偏离定位，还可能触发小程序算法备案要求 |

## 七、关键产品决策与理由

### 决策 1：注释密度是滑块，不是开关

读者的状态是流动的——精读论文和泛读新闻需要的密度完全不同。密度必须能**实时调节且立即生效**，不能重新加工文章。

这要求架构上把"生成全量候选"和"决定显示哪些"分开（见开发文档 L1/L2 分离）。

### 决策 2：词汇量测试是入口，不是关卡

冷启动测试提供的只是**先验**。真正让系统变准的是阅读中的持续反馈（后验）。

因此：

- 测试必须能**跳过**，直接用考纲自评（"我过了六级" → 初始值 6000）
- 测试结果永远可以手动覆盖
- 不做"复测"提醒，不把词汇量做成需要维护的数字

**不要在冷启动测试上过度设计。** 它只需要把初始值送进正确的量级。

### 决策 3：知识背景靠显式勾选，不靠推断

词汇有客观词频，文化背景没有。没有任何统计方法能知道"这个人熟不熟悉圣经典故"。

因此提供 12 个领域标签供勾选（科技/商业金融/政治时事/宗教神学/体育/流行文化/自然科学/医学健康/法律/历史文学/军事/俚语）。勾选即代表"该领域的背景注释对我是噪音"。

未来可以从阅读历史反推，但**V2 不做**——显式勾选的准确率远高于任何推断，成本还低。

### 决策 4：不存原文，只存标注

服务端缓存以**文本内容哈希**为键，只存标注结果（token 区间 + 注释文本），不存全文。

三重收益：远离复制权争议、大幅降低存储、模型层结果可跨用户复用。

### 决策 5：专有名词不进词汇层

人名、地名、机构名标个中文音译毫无价值，反而是最典型的滥标。它们要么不需要注释，要么需要的是**背景说明**（属于 L1 文化层），不是词典释义。

## 八、词汇量测量的产品形态

三条并行路径，读者选任一条即可开始：

1. **考纲自评（最快，默认推荐）**
   点选已通过的最高等级，直接映射为初始词汇量。

   | 自评项 | 初始词汇量估值 |
   | --- | --- |
   | 高考 | 3500 |
   | 四级 | 4500 |
   | 六级 | 6000 |
   | 考研 | 6500 |
   | 雅思 / 托福 | 8000 |
   | GRE | 12000 |
   | 无法判断 | 走测试 |

   > 上述映射为经验估值，用于确定量级，不是权威数据。系统会在阅读反馈中自行校正。

2. **自适应频带测试（10 分钟）**
   基于 COCA 词频分带二分逼近，20–25 题收敛。详见开发文档。

3. **直接输入数字**
   给知道自己词汇量的读者留的后门。

三条路径的产物都只是一个初始数字。**此后由反馈接管。**

## 九、反馈闭环

```
阅读  →  遇到标注  →  点击  →  认识 / 不认识
                                    │
                                    ↓
                        写入个人白名单 / 黑名单
                                    │
                                    ↓
                    下一篇文章的标注决策立即改变
```

白名单和黑名单的优先级**高于任何词频统计**。这是系统从"通用估计"走向"真正认识你"的唯一通道。

预期效果：约 2–3 周日常使用后，个人词表规模达到数百条，后验开始主导标注决策，词频阈值退化为对未见词的兜底。
