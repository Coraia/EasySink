## 验收信号

1. 从实际选择/提交源文件开始计时，包括登记、传输、模型初始化、OCR、规范化、资源返回、阅读器持久发布；566 原页全部可用时停止计时。门槛 ≤180 秒。另报暖服务、冷任务及已有结果重放，不能混为一次测量。
2. 使用独立于待测引擎的公开扫描样本标准答案，并对实际书籍固定区域人工转录核对。分别报告字符错误率（CER）、词错误率（适合英文时）、漏行和阅读顺序；繁简转换、标点或空白归一化必须明确，不能隐性提高成绩。
3. 暂定字符准确率目标 ≥98%，这是实施方提出的质检门槛，非用户提供的精确数值。有限样本不能证明全书准确率；必须同时列样本数量、字符数、覆盖与局限。
4. 重试次数、故障页、原图回退页必须真实可见；整本有不可读页或用全页原图代替 OCR 时，不宣布完整识别目标通过。
5. 同书去重、成功页缓存复用、暂停/取消/恢复、断网及结果校验保留原有数据；不得把旧引擎结果假报为新引擎完整处理。

## 实验前的失败清单

独立测量脚本和候选程序编写前先记录以下失败方式：

- SSH 不通、认证/主机指纹错误、连接中断、传输不完整、远端磁盘满。
- 服务假就绪、CUDA/驱动或模型不兼容、显存被占满、GPU 实际回退 CPU、重复模型初始化、模型未固定。
- PDF 不可解析、页面过大/旋转/裁剪异常、源文件变化、文本层污染识别、扫描页为空或识别零字。
- OCR 挂起、单页超时、进程异常退出、临时失败、永久失败、无限重试、重试后丢页/重复页/错序。
- 坐标非有限值、微小浮点越界、真正越界、图像/公式/表格丢失、错误阅读顺序。
- 产物路径穿越、JSON 过大、产物缺失/校验和不符、引擎或配置变化后误复用旧缓存。
- 暂停/取消后迟到结果覆盖、恢复重复付出计算、旧笔记与新文本失配、一个坏页阻断后续页。
- 测量遗漏文件上传/传输/启动/入库、复用热缓存冒充冷导入、用吞吐外推代替全书实测。
- ground truth 来自待测引擎、标准答案转录错、只选易样本、裁剪区域不对应、归一化抹掉错误、把回退当识别正确。
- OCR 产出变快但阅读器逐页重复整理导致积压；重负载使旧书打开/翻页或 API 响应明显退步。

## 本轮所有权

- 转换会话：独占远端服务/GPU、候选引擎实验、新 `scripts/omarchy_ocr_*` 和 `adapters/omarchy.py`；不同时跑竞争 GPU 的实验。
- 后端会话：`conversion.py`、`adapters/docling.py` 及必要 `worker.py`/`storage.py` 容错；主控接入新引擎前交接。
- 走查会话：独立标准答案、选样、准确率计算及证据；不操作浏览器或 GPU。
- 主控：正式读者桥接、公共契约、交互整合和最终浏览器走查。

沿用已记录的累计预算：最多三个候选、最多四小时主动实验、最多 20 GiB 新下载、零付费请求。两个连续无进展实验停止该支路，改用有依据的替代方案；未达到门槛如实记录，不能用界面完成掩盖。

## 排查顺序

1. 逐页 OCR/版面分析吞吐：若主要耗时在识别，GPU 批量 det+rec 应显著降低每页均摊时间。
2. 页面渲染、初始化与材料返回：若这些占主导，单独加速模型不会接近 180 秒；记录各阶段和冷/暖区别。
3. 阅读器发布：若产出快于消费，队列与全书阅读版就绪时间会落后引擎结束；测真实发布，不只看 OCR 页数。

## 两项容错修复的定向证据

- 远端模型进程由独立监督进程管理。单页 15 秒硬截止，最多两次尝试；超时后先回收进程，再创建替代进程。页码、尝试次数、进程代次及模型配置均核对，过期输出不能覆盖当前结果。
- 对真实第 46 页的模型进程做两次 `SIGSTOP` 故障注入，均在截止后被回收（退出 -9）；第 46 页明确记作一个失败页、两次超时，保留原图；第 100/300 页继续实际识别。证据：`engine/hard-timeout-sigstop-first/summary.json`。正常三页最终回归 3.575 秒；两路 CUDA 进程已启动后的取消耗时 189 毫秒，无残留模型进程。这些是特定故障验证，不是“所有断网/故障均通过”。
- 暂停/恢复、转换结束时会从已发布页索引补齐阅读范围；排队时保留补齐请求，过期代次失效，旧请求不能删除后到的新请求。62 页合成 PDF、真实本地转换和 HTTP API 同路径复现：修复前转换 62 页但阅读版只有 54 页（漏 9–16）；修复后 62/62，恢复复用 24 页，只新增处理 38 页。证据：`bridge-resume-api/{red,green}/summary.json`、`bridge-resume-fix/handoff.json`。该项使用显式时序注入，不替代真实浏览器走查。
