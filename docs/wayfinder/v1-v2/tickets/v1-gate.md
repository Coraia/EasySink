## Question

如何把现有 V1 与 PDF 验收要求收敛成可执行的放行标准，明确阻断项、可带入后续版本的问题和各自所需证据？

本票需明确：
- 代表材料、旧格式与扫描 PDF 的支持边界，以及正常、失败、恢复、后台转换同时阅读的必经路径。
- 打开、翻页、跨阅读版就绪范围、导入、记录恢复的实测基线；数字来自当前设备和实际证据，不以新目标代替旧承诺。
- 数据损坏、错误外发/重复付费、阅读阻断和明显性能退步的处置优先级。
- 既有报告可复用的范围与需要重新走查的缺口，特别区分真实触控板、真实 OCR 与模拟故障。

收口依据：用户认可的验收矩阵与阻断清单，可交给现有验收工作执行。本决策关闭不等于产品通过验收。
