# 阅读工具栏区域与面板切换

2026-10-05，修改前真实页面复现：图标间空白点击关闭 banner；点击目录展开后 banner 和底部栏隐藏，无法在同一入口切回。before.json/png 记录实际状态。

失败条件：

- 六个图标的两侧、区域边缘或区域交界处存在空洞，误关闭工具/翻页；窄窗口或关闭插件后留下空白槽位。
- 面板展开覆盖工具栏或被透明覆盖层挡住，用户无法点菜单控件或同一入口。
- 同项再次点击没有回到 banner；切换另一项同时触发旧项；选中/展开属性与实际面板不符。
- 关闭按钮、点击正文或 Escape 丢失层级：面板收起应保留 banner，再次收起才回到专注。
- 面板内文字编辑/拖动进度被关闭逻辑截获，保存内容丢失；More 反复切换后次级工具丢失或重复。
- banner 悬停重新遮挡正文，正文几何变动、查词或误翻页；非工具栏打开的选区笔记无法正常关闭。

最终采用隔离数据库的 CUA E2E，保留首次复现、最终截图、逐步状态、冻结源代码和复现步骤。没有单元测试；不运行旧界面的完整测试套件。
