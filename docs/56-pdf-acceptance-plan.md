日期：2026-10-08。配套 [规格](54-pdf-spec.md) 和 [开发契约](55-pdf-development-contract.md)。用户已确认沿用现有浏览器 E2E seam，模拟故障与真实转换/设备证据分开。本文件保留设计阶段计划，执行记录见 [主控记录](59-pdf-development-control.md) 和各并行会话状态；不要将原计划当作当前执行结果。

## 最新执行更新（2026-10-08）

用户最新授权：尽量并行，尽量少写测试，最终直接点击走查。本文件早期 Playwright/完整套件措辞不再作为必须新增测试代码或运行全套的要求；既有业务入口、真实材料、性能指标和证据分层保留。执行以浏览器人工操作式端到端走查为主，按需复用已有测量工具。当前实现与证据见 [主控记录](59-pdf-development-control.md)。

## 1. 主验收 seam

唯一主要验收入口为现有 Playwright 浏览器业务路径：选择文件导入 → 书架 → 原版/阅读版 → 翻页、理解辅助与记录 → 任务、重启、回收恢复和资料管理。使用独立本地服务和临时用户库；测试数据、访问锁、模型设置和供应商配置均与个人阅读实例隔离。

真实引擎和故障 Adapter 位于同一 PDF Module Interface 后面，不让测试绕过正式导入去直接调用解析私有函数。公开 HTTP 可用于准备隔离数据、读取业务状态和核对持久化；私有数据库行存在不作为用户功能通过的依据。

现有先例：导入坏包/重开、渐进分页下选区稳定、字号/窗口变化后原文锚点恢复、模型收件记录与异常结果、高清纸面与缓存守卫、原生 phase fixture 的停驻/取消/连续及交替翻页。继续沿用现有 HTML/JSON、trace、截图和首次失败保留机制，不改换成单位测试体系。

## 2. 证据层级

| 层级 | 能证明的部分 | 不能替代 |
|---|---|---|
| 文档与官方核对 | 产品决定、候选组件能力声明、版本/许可线索 | 实际安装、OCR 质量、资源占用 |
| 确定性故障 Adapter 的浏览器 E2E | 状态、范围、限额、取消/重启/迟到结果等应用行为 | 真实扫描件识别、供应商计费或设备手感 |
| 真实本机引擎的浏览器 E2E | 固定材料上的实际转换、来源与渲染/记录闭环 | 任意材料质量、所有设备表现 |
| 真实供应商受限试用 | 已验证输入/输出、请求范围、响应/用量能力 | 未验证的供应商幂等、退款或精确账单保证 |
| Mac 实机体验及性能 | 指定环境下的真实手势、视觉与资源干扰 | 其他机器或仅由 fixture 推断的物理触控体验 |

必要证据缺失时对应结论保持待验收，不用模拟通过、skip 或成功启动服务补齐结论。

## 3. 转换实验的失败方式（实验程序之前记录）

| 失败类别 | 观察与反证 | 判定 |
|---|---|---|
| 字符/语言失真 | 与独立参考逐段比较，单列专名、数字、希腊文/希伯来文及连字 | 不用英文总体分掩盖局部重要错误 |
| 阅读顺序失真 | 用人工标定段落顺序核对多栏、脚注、跨页正文 | 被发现的严重错序不能作为就绪正文 |
| 结构或资料丢失 | 对选定公式、表格、图像与说明建立来源清单 | 每个必需对象必须可靠呈现或忠实原图回退 |
| 伪造结构识别成功 | 对照渲染与原图，检查符号、表头、跨页与单位关系 | 回退分开统计，不计入结构识别成功率 |
| 来源错绑 | 核对页/区域，缩放/旋转、重复引文和版本改字再定位 | 不能靠近似阅读页码或首个相同词通过 |
| 渐进能力假象 | 记录实际单元完成、发布与可读时间 | 不把全书结束后逐页展示伪装成提前可读 |
| 模型/平台不可用 | 记录固定版本、输入、运行后端与原始错误 | 官方支持声明不等于本机通过 |
| 不可停止或资源竞争 | 转换中读旧书，测暂停响应、RSS、GPU/内存压力与帧耗时 | 换清晰度或禁用功能才能通过即为失败 |
| 空间不足/产物不完整 | 受限空间中观察接收、响应写入、结果提交及恢复 | 不能写满后仍显示成功或删除保留资料 |
| 付费或响应不确定 | 独立供应商收件记录、派发意图、响应和重启历史 | 不能把未知当未发、免费或可自动重试 |

比较优先经同一浏览器导入路径执行。如确需单独运行引擎实验，先完成本表及样本/预算清单，结果只作为引擎实验，不称作产品 E2E 通过。

## 4. 样本矩阵及参考资料

| 类别 | 必须覆盖的代表情况 | 核对对象 |
|---|---|---|
| 数字英文 PDF | 正常文字层、连字、标题/列表/代码、长书 | 原文完整性、顺序、首屏和范围读取 |
| 印刷体扫描 | 清晰扫描、倾斜/低清、带错误或重复文字层 | OCR 字符误差、是否采用错误文字层、严重错误处理 |
| 学术排版 | 双/多栏、页眉页脚、脚注、跨页段落 | 阅读顺序、脚注归属、主文连续性 |
| 公式 | 行内/块级、上下标、分式、特殊符号 | 符号/结构忠实、原图回退、静态与翻页纹理 |
| 表格与图像 | 合并表头、复杂/跨页表格、图片与说明 | 单元格关系、表头/单位、完整裁图与来源 |
| 混合语言 | 英文含中文、希腊文、希伯来文等 | 按语言分别统计和人工核对，不外推质量 |
| 导入异常 | 假扩展名、不可读/受限文件、重复导入、同名不同文件 | 错误分类、无假成功、去重与任务归属 |
| 版本与记录 | 重复引文、重新识别改字、图像变化、部分迟到 | 笔记/书签/续读、原页定位及歧义保留 |
| 大书与后台负载 | 长数字书和扫描书；同时继续读固定旧 EPUB | 内存、范围加载、首屏、持续翻页和调度 |

用户实际 PDF 样本尚未指定，本计划不把之前 EPUB 样本当成 PDF 验收。执行前记录来源、使用范围、文件摘要、原页数、尺寸、主/混合语言、扫描分辨率、目录及参考区域；私有文件路径、原件和完整文本不发布到公开 tracker。

参考文字、段落顺序、对象和来源区域由人工或可独立核对的原件建立，不能由待测引擎提供参考答案。字符比较的 Unicode/换行/软连字符规范化规则先固定，同时保留原始差异；不能删数字、否定、特殊符号等来提高分数。

## 5. 比较条件和预算

比较 Docling、MinerU、PaddleOCR 候选时固定机器、样本及范围、版本、模型、后端、解析设置和独立质量规则。每个候选用相同材料；无法支持有界渐进处理、来源或资源约束的候选记录原因，不追加隐藏的另一套流水线凑结果。

先比较代表范围，再对候选主流水线执行完整长书与真实浏览器闭环；小范围通过不代表全书或复杂版面通过。主引擎选取顺序为：必需质量/来源/资源条件达标 → 旧阅读不退步 → 同类材料下转换时间/峰值和维护成本比较，不能只选输出最快者。

实验初始预算提议为最多三个候选、累计四小时主动实验、累计 20 GiB 模型及依赖下载、默认零付费调用；执行前将预算与可用磁盘条件写入实验清单。这是工程实验预算，不是产品每任务的强制预算输入，也不是本轮启动实验的授权。达到预算或连续两次没有进展时停止，保存原始失败、已有证据和下一步选项，不通过更换阶段名称重置预算。

若后续主动验证真实外部增强，另外明确测试页/区域、服务和累计调用上限；只执行已选范围，不上传整本材料。原件未指明、版本未固定或预算清单缺失时先完成准备，不启动大规模转换。

## 6. 指标定义和冻结规则

### 已有回归守卫

这些数值来自当前基线的既有特定场景，适用范围不能扩大为任意机器或物理延迟承诺：

- 既有合成长 EPUB 场景首个正文小于 2,000 ms，且先于全书分页完成；后台分页不得改变已选原文或恢复位置。
- 既有翻页场景的浏览器内部 P95 帧间隔/输入调度小于 34 ms；保留相应场景与软件/硬件路径，不以一次平均值替代。
- 有界缓存守卫为不超过六张纸面、24M 缓存像素，DPR 1/2/3 及硬件清晰度保持；装订、曲面和拉伸等既有守卫继续执行。

基线文档中的历史通过值不是本轮重新测量结果。完整回归也须覆盖旧导入、词卡、辅助密度/保留注释、译文联动、语法、TTS、笔记、书签、续读、阅读痕迹及插件开关。

### 配对性能比较

以固定基线提交和候选实现分别运行同一个旧书场景，使用同一台 Mac、浏览器/渲染后端、窗口、DPR、阅读设置和固定样本。先完成两个基线批次，冻结自然波动容差；再比较候选空闲与候选后台转换条件。独立服务不共用个人资料库，避免隐藏的旧缓存帮助某一方。

每条件至少十次配对打开/操作；冷启动和暖重开分别记录，翻页至少覆盖慢/中/快速度、成功、回滑取消、接触停驻、连续及前后交替。记录 P50/P95、最大值和原始序列；帧样本覆盖完整手势及收尾，不能删除释放阶段的卡顿。

新条件 P95 不超过固定基线 P95 加预先冻结的噪声容差，同时仍满足既有硬守卫；功能/清晰度不能以容差抵消。容差只由基线重复批次计算并写明方法，不能由候选失败反推。异常系统负载需记录，不能只挑最好的一次。

### 新增 PDF 指标

| 指标 | 起止与统计 | 发布前要求 |
|---|---|---|
| 接收/书架时间 | 开始上传、接收校验、持久登记分别计时 | 成功登记不等全书 OCR；收件响应丢失也可恢复原归属 |
| 模型准备时间 | 本机无模型 → 固定模型可运行 | 与上传/外发分清，单列下载和冷加载，不从首范围时间中隐瞒 |
| 原版首屏 | 原版请求 → 来源页实际可见且工具可操作 | 单列首次/重开、页尺寸与文件条件；标题或 Canvas 标签出现不算显示完成 |
| 首阅读范围时间 | 提交转换 → 首个已检查正文可见、可选择 | 须早于全书完成的场景有实际单元证据；不能以原版可见代替 |
| 已转换 PDF 重开 | 打开书籍 → 原位阅读可操作 | 不重新 OCR，不取全书重新分析；与固定类似长度阅读基线比较 |
| 全书转换 | 固定任务开始 → 所有工作单元结束及质量汇总 | 完成、可读、回退和拒绝分别统计；不可读页存在时不能显示全书就绪 |
| 文字/顺序质量 | 独立参考的字符误差、顺序正确性、重要术语/数字/符号 | 按材料类别冻结门槛；严重失效范围不发布为就绪，混合语言分别判定 |
| 结构质量 | 参考公式/表格/图像清单的覆盖、正确性及回退 | 所有选定必需对象都有可靠表示或忠实回退，零静默丢失；回退不计识别成功 |
| 来源与记录 | 已标定原页区域、记录和修订后的对应 | 必需验证用例零错绑/丢失；歧义明确保留而非猜测 |
| 资源 | RSS/峰值、内存压力、换页、GPU、磁盘预留、模型驻留 | 同时测旧书，不降清晰度，不以系统换页/长期卡顿换转换速度 |
| 付费行为 | 业务意图、供应商收件/响应、预留、用量与费用类别 | 测试内零隐含扩大范围、零自动重发未知付费请求；估算不作准确账单 |

新增转换的质量数值与绝对耗时/资源上限没有既有 PDF 基线，不能编造“已可两秒 OCR”等承诺。实施前的小范围比较必须产出按样本类别的阈值清单、精确计时定义和资源限额；清单未冻结时仅允许实验，不可进入正式验收或发布。冻结后失败就是失败，改门槛需保留旧失败并说明新范围，而不是静默标绿。

## 7. 必须通过的 E2E 场景

| 编号 | 业务路径 | 必需证据 |
|---|---|---|
| PDF-01 | 未配置 AI → 导入 → 不点开始阅读 → 刷新书架 → 打开原版 | 一个持久书籍条目、零文档外发、原版真实可读 |
| PDF-02 | 同文件同时/重复导入，同名不同原件 | 相同归属和任务不重复；不同原件不误合并 |
| PDF-03 | 真实数字 PDF → 已就绪范围 → 完整阅读版 | 原文/结构/顺序、首范围与全书时间、无假渐进 |
| PDF-04 | 真实扫描/复杂内容 → 原图回退/严重错误 → 局部重新识别 | 独立质量核对、就地原图与来源、未就绪范围和后续结果 |
| PDF-05 | 段落/图像 → 原版定位 → 缩放/旋转 → 返回 | 正确区域、可见高亮、原位恢复而非阅读页码近似 |
| PDF-06 | 翻页/选区/笔记输入时迟到版本 → 安全静默更新 | 当前交互保持、锚点恢复、歧义记录保留 |
| PDF-07 | 文字和原图笔记新增/编辑/删除撤销；书签与续读重排/重开 | 保存状态、正文标识、列表入口、原来源及完整生命周期 |
| PDF-08 | 切书/关浏览器 → 任务继续；暂停/取消 → 重启 | 检查点、配置/范围不变、取消不复活、新书不受迟到 UI 更新 |
| PDF-09 | 回收 → 迟到响应 → 恢复 → 主动继续 | 不重新上架、原记录与结果保留、恢复后任务暂停、无重新付费 |
| PDF-10 | 主动局部外部增强 → 复用/重放/重新生成 | 独立收件记录证明范围/次数；本地重放无外部付费调用 |
| PDF-11 | 两个同时操作、次数限额、无查询供应商、已发超时与重启 | 原子预留、未知占用、零盲重试、清晰费用类别与直接继续操作 |
| PDF-12 | 接收/响应/结果提交阶段空间不足 → 清理 → 恢复 | 无假成功、重要资料无丢失、临时与保留清理语义可核对 |
| PDF-13 | 本机转换活跃时读固定旧书及已转换 PDF | 配对打开/帧/收尾/内存证据、原功能与硬件 DPI 保留 |
| PDF-14 | 单/双页、DPR 1/2/3、静态/翻起/背面/落页 | 图像/公式/表格一致不缺失，装订和既有缓存守卫保持 |
| PDF-15 | 关闭 PDF 处理后读旧格式、检查已存 PDF 资料 | 无新增处理/隐含外发，数据保留，旧格式照常工作 |
| PDF-16 | 实机慢/中/快、半途接触停驻、释放、取消、连续/交替 | 原生手势与视觉/性能记录，fixture 与实机结论分开 |

开发阶段只运行正在完成的纵向路径及必要的目标回归。最后才运行完整 E2E；必要 PDF 样本或实机条件缺失则对应验收未通过，不能靠 skip 宣称全部完成。

## 8. 验收产物和发布判定

每次验收使用新的证据目录，保存运行身份、源码提交/修改摘要、固定依赖与模型、浏览器/设备/渲染路径、窗口/DPR、样本及设置摘要、预算和门槛清单、首失败、原始指标、HTML/JSON、trace/截图、转换质量及来源标注、调用收件与响应凭据、复现步骤。凭据与私有文档不进入公开报告；公开摘要引用校验摘要及证据范围。

正式发布要求：真实主流水线覆盖必需材料；一期必需 E2E 和旧格式完整回归通过；来源/记录无错绑丢失；静态和翻页资源一致；后台负载下功能、性能和清晰度守卫通过；用户已验收交互原型与真实体验；供应商能力在实际采用的范围验证或对应能力不宣称可用。

任一必要门槛未通过，结论为未达到发布条件，报告阻断项和下一步；不降低未达标项的证据级别冒充完成，不因已配置环境或已导入一本书就结束验收。
