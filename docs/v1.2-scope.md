# V1.2 转向与范围

状态：用户决定暂缓 V2，转向 V1.2；本文件记录方向及建议边界，不表示具体方案已批准或功能已实现。

## 转向理由与目标

用户认为尚不具备推出 V2 的条件，需要先积累一段时间的真实使用。V1.2 聚焦：让真实内容更可靠地进入阅读、减少当前阅读错误，并在不增加阅读负担的前提下积累可用于后续判断的本机证据。

V2 的个人标注匹配北极星不取消，但方案实施、微校准和真人验证实验暂停。历史设计见 [V2 北极星](v2-north-star.md)、[方案](v2-design-proposal.md)、[验证协议](v2-validation-protocol.md)，均不再作为当前执行清单。

## 用户明确提出的三条主线

### 1. 积累用户操作与使用习惯的证据

为 V2 提供依据，当前不实现个人能力推断或自动适应。

建议边界：
- 记录与阅读目标有关的自然操作：查词/查表达、请求解释、掌握反馈、保留/取消注释、采用/撤销、辅助密度改变、必要的续读与活动片段。
- 除“点了什么”外，保留“当时可见的原文和自动帮助是什么”：原文锚点、内容版本、已呈现标注、策略/个人设置版本。呈现不等于确实读过，没有操作仍然未知。
- 区分发起、完成、失败和撤销；事件具有稳定身份，重复上报不重复计数，断点重启可恢复关联。
- 将操作事实、读者明确声明与未来推断分开；“查词”不等于“不认识”，“翻页”不等于“认识”，停留不等于认真阅读。
- 不改写现有收藏/掌握/采用的语义，不从过去没有记录的行为反推历史事实，不把旧记录包装成新采样。
- 默认本机保存，范围透明，可关闭采集、导出与清除采集数据；清除采集数据不连带删书、收藏或笔记。具体保留周期和容量在方案阶段定。
- 不采集全局键盘、剪贴板、其他应用或与目标无关的高频轨迹；不默认上传或构建商业分析后台。
- 能回放一处“多标/漏标/内容错误”的当时状态，比记录更多点击总数重要。采集不得造成逐次同步写盘或阅读性能退步。

### 2. 修复 V1.1 真实使用暴露的问题

用户案例：PDF 原文跨行的 `dis - cipleship` 被拆开，`dis` 被作为独立生词，显示“狄斯(阴间的神),阴间,冥府”。

当前证据：用户报告，尚未完成真实原文重现和根因定位；不能宣称已修复。

修复方向建议：先沿原版、转换结果、阅读文本、分词/候选和显示路径定位断词发生处。处理跨行断词与真实连字符词的区别，不把 `dis` 加黑名单或全局删短词来掩盖问题；兼顾跨页/分栏等反例。原件、原文来源、收藏与采用解释的锚点必须保持或明确迁移，不直接改原文字符串导致历史记录错位。

修复范围由可复现案例与真实阅读影响驱动，不借 V1.2 做普遍视觉重设计或阅读内核重写。样例修好不代表所有 PDF 断词问题已解决。

### 3. 网络链接导入

用户指定验收例：

https://www.anthropic.com/research/distillation-defenses

该 URL 已用普通 HTTP 获取检查：响应 200，原 URL 未改变，页面标题为 “Strengthening our defenses against distillation attacks”，存在 article 与正文内容。这只证明页面可访问，不证明 Wise Reader 已具备导入或内容保真能力。通用网页提取工具曾报地址限制，直接获取可用；不把通用工具报错等同于网站不可导入。

建议首版边界：
- 公开、无需登录的 HTML 文章；单个 URL 导入，不爬全站、不定时同步、不绕付费墙、不接管登录。
- 提取正文，保留标题、可用作者/日期、原始与最终来源 URL，保存可重读的本地内容快照，进入现有文章阅读路径。
- 保留有意义的段落、标题、列表、引用、代码与图片说明等结构；不能把导航和页脚当正文，也不能默认静默丢掉关键结构。
- 提取不完整、正文为空、登录墙或不支持的复杂页面应明确失败/提示，不以抓到网页外壳当导入成功。复杂网页与 URL 指向 PDF 的分流能力在方案阶段明确，不承诺任意网址。
- 清理不可信 HTML，不执行页面脚本；限制下载大小、超时和重定向，并对重定向后目标继续做网络安全校验，防止本机/内网地址滥用。
- 来源变化不静默覆盖已读快照和阅读记录；重复导入行为需明确定义。

## 建议推进顺序与验收

先对齐最小采集契约与修复案例，避免继续丢失必要证据；同时先消除已知会污染证据的内容错误。交付一版能稳定采集、能读现有材料和指定网页的 V1.2，之后进行自然使用，不强迫额外校准或逐页批改。

验收分别看：
- **采集**：真实阅读操作能还原当时状态；成功/失败/撤销区分正确；关闭、清除和隐私边界有效，阅读性能不退步。
- **修复**：真实 `dis - cipleship` 案例重现后修复，正常连字符词不误合并，原文定位与已有记录未损坏。
- **URL**：指定 Anthropic 页面从粘贴 URL 到进入阅读完整走通，正文/结构/来源核对合格，重启可续读；失败页不给假成功。

V2 重启不按经过多少天或积累多少点击机械触发。建议在已有一批可回放的真实多标/漏标案例，能够区分内容错误与个人帮助需求问题，并愿意做少量独立验证时再讨论。自然使用数据有选择偏差，不能独自证明词汇掌握或全部漏标。

本轮仅记录转向、只读核查及 URL 可访问性，没有实现采集、修复 PDF、导入文章、启动实验或修改用户资料。
