## 实际行为

- 词卡读取既有解释后，一次点击“解释这里的意思”直接调用现有生成入口，不再让用户查看计划或选择前后段。打开词卡仍仅调用读取接口，不自动调用模型。
- 删除范围预览、邻段 checkbox、实际发送内容、字符/UTF-16 计数及范围说明；当前结果、旧协议结果和解释历史均不再展示这些技术内容。取消例行“将使用哪个模型”的展示，结果来源仍保留。
- 预览与生成共用固定 `{context_previous:false, context_next:false}`。仅发送现有 anchor 与请求控制字段；后台继续按当前选中句段生成有界上下文，单词默认所在段，长段按既有限额围绕原词截取。没有发送篇章/全书对象，也没有自动加邻段。
- 缓存、旧解释历史、请求 ID、明确 regenerate、取消、迟到响应隔离、离线有效缓存校验继续使用现有链路。非成功 attempt 仍阻止普通生成入口，pending 禁止重新解释；unknown/failed 可读取已保存结果，只有明确点击“重新解释”才重新生成。按钮旁保留“可能再次计费”提示。
- 状态仅显示正在解释、结果未知、额度/繁忙或简短恢复指引，不回显后台范围/协议错误文本。后台原始错误及收据未被改动。读取失败不覆盖此前取消/未知结果提示。
- 未配置文本 AI 时继续通过 `offerAISetup` 打开阅读内设置；设置恢复不自动重试付费请求。
- 保留 `pop.contextRecord`、`reader.contextRecord` 和 `context-record` 事件。解释取得后只形成候选；已有收藏仍经“预览并采用解释”进入原对话框，未新增自动采用。
- 词卡初始态、选中态和保存反馈均使用“已掌握”。帮助文字为“只记录这一次用法；收藏、掌握反馈和保留注释各自独立。”`understood: true/null`、anchor、撤销及 retained 写入逻辑不变。

## 主控可复走入口

在主控隔离验收实例打开任一英文原文，点正文带注释的词，或选中词语后查词，进入同一词卡。保留该实例 URL、原文与 anchor、截图和网络记录，首次失败另存。

| 场景与操作 | 应观察到的结果 |
| --- | --- |
| 无已有解释：打开词卡，点击“解释这里的意思” | 没有范围、字符数、计划或邻段勾选；初次读取仅 `/context/preview`；点击后一次 `/context`，两个邻段字段都为 false，无额外确认步骤。模型结果质量需主控按独立授权验收。 |
| 无 AI 配置且无缓存：点击解释，收起设置，再返回 | 设置在阅读内打开，原文位置保留，不跳离阅读；恢复后不自动发起解释。 |
| 已缓存：关卡重开，查看历史 | 直接显示保存的结果；历史有来源/日期/解释，无范围面板；不新增生成调用。 |
| 有结果且已收藏：查看新解释、打开采用预览，先取消后采用 | 生成或读取本身不写收藏解释；取消不覆盖；明确采用才更新，旧解释历史和我的释义保留。 |
| 进行中点击取消；随后结果未知，关闭重开／点击重新查看 | 只取消和读取结果，不自动补发 `/context`；pending 禁止再生成；unknown 保留简短提示，重新解释旁提示可能再次计费。 |
| 离线重开或读取失败 | 可用且严格匹配的已载入解释仍可显示；无可核对状态时禁止生成，提供重新查看入口；不展示后台技术范围错误，也不将 unknown 称为免费失败。 |
| 同拼写不同原文位置；先收藏且保留注释，再点“已掌握” | 仅本次 occurrence 的反馈改变；收藏及保留注释不变，另一处不被判为掌握。再次点击回到未反馈；撤销恢复该操作前状态。 |
| 窄窗、长释义、旧历史 | 简化后词卡仍可读、操作可达；布局与真实设备结果由主控留图确认。 |

不得为完成上述步骤而直接在正式库注入状态或自动开启付费配置。故障/缓存资料如由隔离实例注入，须标明为状态验证；它们不证明真实供应商行为。
