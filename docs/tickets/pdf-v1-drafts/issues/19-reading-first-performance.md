## What to build

在真实本机转换活跃时连续阅读旧书和已转换 PDF，转换可节流/暂停，打开与交互速度不因新能力退步。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 固定基线/候选空闲/候选转换负载，在同机器浏览器、DPR、样本及设置下配对比较，基线波动容差在候选测量前冻结。
- [ ] 旧书首屏、帧/输入 P95、收尾/连续翻页、选区稳定、模型/RSS/GPU/磁盘压力分别记录，不只报平均或最好一次。
- [ ] 阅读活跃或超守卫时控制新推理单元与进程资源，必要时可恢复暂停/卸载；不假定低优先级线程就解决 GPU 竞争。
- [ ] 不降硬件清晰度、放宽既有守卫、禁用理解辅助或延长翻页锁换性能；已有守卫和配对非退步条件都通过。
- [ ] 重开已转换 PDF 不 OCR、不读取全书重分析，首范围/模型准备/全书结束分开计时；保存首次失败与全部原始序列。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
