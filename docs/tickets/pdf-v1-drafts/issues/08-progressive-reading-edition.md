## What to build

读者先读实际转换并检查通过的范围，剩余工作继续处理；图片、公式和表格可靠呈现或就地回退，未就绪部分不冒充完整书籍。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 使用冻结的真实主流水线在独立任务中转换，已完成范围提交后可读；实际首范围可用时刻与全书结束有证据。
- [ ] 阅读版默认专注，沿用单/双页、字号和排版偏好，按当前位置和邻近范围加载，不每次返回全书重新分析。
- [ ] 可靠结构、局部原图回退和严重正文拒绝分别显示与计数；回退含完整必要区域和原页来源，部分失败不覆盖已有有效内容。
- [ ] 阅读表示与来源版本一致，保留原件和旧有效结果；局部就绪/全书处理结束/全书可读分清。
- [ ] 未处理范围显示真实状态和原版入口，原版不自动切阅读版；静态显示目标 E2E 通过，高清翻页纹理另有后续验收。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
