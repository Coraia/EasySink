# 《小王子》其余 25 章：独立手绘角色

2026-10-19。本轮延续已认可的狐狸与玫瑰画风。入口仍是 `#/living-book/2`，可从章节目录访问全书；重点查看第 14 章（`/15`）、第 22 章（`/23`）、第 25 章（`/26`）。

## 实现

除第 8、21 章继续使用原有专门引擎外，其余 25 章的 53 个关键情节改为独立绘制的人物、道具与空场景组合。全书共 73 个情节段。角色支持姿势切换、头部与手臂回应、围巾与花叶运动；列车、鸟、水桶、井绳、滑轮、日落、灯光与回声有各自的运动。拥抱、抱睡中的小王子采用专门的双人姿势图。仍为 2.5D 手绘角色动画，不是可自由旋转的完整三维骨骼模型，也不是每一句生成一张新插画。

原文驱动开灯/熄灯、第二列车反向行驶、提桶/喝水、站立/鼓掌/挥手/哭泣/躺下等关键变化。原文和重点词选择动作；按场景筛选可交互词，远方玫瑰、想象中的小羊、泉水与结尾的回忆使用明确标注的小画框。第 18 章保持三瓣小花，第 27 章末尾保持空沙漠。每章提供原插画对比，暂停、逐句方向键、章节导航、自动阅读和续读沿用现有交互。

新增 `web/picturebook-cast-catalog.js`、`picturebook-cast-chapter.js`、`picturebook-cast-scene.js`，接入共享控制器 `picturebook-fox-reading.js` 与样式。完整英文、版本归属、中文提示的性质、数据库正文均未改写。没有修改狐狸或玫瑰专门引擎。

采用内置 ImageGen 生成并保存 15 张素材（透明图集、单体角色/道具及空场景），原生成文件保留。素材和全部采用的提示词在 `web/assets/picturebook-cast/` 与 `generation.json`。详细生成尝试在证据目录的 `generated-*.json`；未采用的飞行员改图和一次输出阶段拒绝均有记录，没有使用 CLI/API 替代生成路径。图集裁切发生在渲染器 UV 中，不修改源图。

1. 打开全书入口，从章节目录切到第 14 章，进度条选第 19 句；悬浮同页第 21 句，再回第 19 句，观察灯光。
2. 第 22 章第 11 句点击 express，观察第二列车朝相反方向驶过；暂停后画面固定。

4. 第 23 章末段的泉水有“想象”标记；第 27 章末段没有已经归来的小王子。
5. 设置 390px 视口逐句翻页，开启情节提示，确认当前句仍可见；恢复桌面视口。
6. 仓库根运行 `node outputs/picturebook-cast-20261019/verify-source.mjs`，重新核对保存的真实浏览器观察与 API 快照。结果在 `source-verification.json`，交互状态在 `browser-checks.json`。
