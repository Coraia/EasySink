2026-10-09。对应 [V1 收口：哪些证据足以进入下一阶段](https://github.com/Coraia/EasySink/issues/24)。**验收标准已对齐：Q2–Q9及Q11–Q12已确认；Q10按用户最终修改替换扫描书并加入指定论文。产品尚未按本矩阵验收。**

本文件整合已确认决定与执行矩阵，不替代 [PDF总体验收](https://github.com/Coraia/EasySink/issues/22)，也不自动关闭既有开发票。原有 [PDF验收计划](56-pdf-acceptance-plan.md) 的必需场景保留，最终直接点击走查，不要求新增测试套件。

已据此发布 [V1收口补充规格](https://github.com/Coraia/EasySink/issues/35)，本地全文见 [规格快照](70-v1-closeout-spec.md)。规格发布不代表本矩阵已执行。

## 已确认范围

- V1保留既有阅读功能及PDF要求；词句收藏／再遇见和个性化需求评估归后续阶段。
- V1增加最小macOS客户端原型，保留Web阅读核心，系统WebView优先验证；正式对外分发和最终框架尚未决定。依据 [ADR-0007](adr/0007-desktop-prototype-reuses-reading-core.md)。
- 必需运行时不由用户安装开发工具补齐；资源总成本分应用、词库、OCR和语音统计。首次基础阅读／词注须可用，重模型不阻塞每次打开书。
- 公式、复杂表格等可以忠实局部原图回退并回原页核对；普通正文的可选字和理解辅助能力单独验收，不能只凭任务完成、原图可见或总耗时判通过。
- 代理先完整走查并保留原始证据，用户随后重点体验约15–20分钟；时间不是自动放行条件。真实触控板手感不由phase fixture替代。

## 固定材料与计分规则

复用两类现有真实EPUB、固定合成长EPUB、TXT/Markdown代表文件、数字英文PDF；扫描书主样本改为用户指定英文书《Pastoring Men》（196页），新增 [arXiv:2609.36322v1](https://arxiv.org/abs/2609.36322v1)《Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression》（65页）。再补足真实复杂表格／希腊文或希伯来文混排等未覆盖的必需类别；一份材料可覆盖多个类别。缺材料时由代理查找可用公开样本，不把自制fixture当真实OCR材料；假扩展名、坏包、重复引用等状态故障另用fixture。

首轮正文独立参考至少30段、5000个计分字符，随机样本与已知难点都纳入；这是最低取证工作量，不是全书统计保证，类别不足仍补样。抽中的普通正文须有可选文字且顺序正确。新扫描书所有无可选正文页逐页分类：普通正文未恢复的范围不通过，正常封面/空白/插图另列。旧566页及其13页无可选正文的首失败资料保留，但不作为这轮主样本重复验收任务；不得把旧13页数套到新书。

论文按原PDF页序建立选区走查：摘要/引言的核心术语与限定词、图1及图注附近说明（第3页）、理论与公式附近说明（第8页），再补全文实际含有的表格、脚注与跨页段。检查行尾连字、引用编号、变量/上下标、否定和数量关系是否保真；原文选区与中文对应高亮可区分，关闭译文不改阅读位置，重新打开复用有效结果。保留实际输入范围、供应商/模型、译文与用量证据，并分别归因内容提取、翻译和展示问题。只翻译用户选定范围，不自动翻译整篇/整书，也不把准备案例写成已完成翻译。

私有书籍、路径、原文、密钥和原始响应留本机。样本登记记录原件SHA、来源／使用范围、类别、页／段区域和独立参考；比较前冻结，不因失败临时换书或删除坏页。准确率只覆盖核验范围。暂不把有限样本称为全书校对。

## 当前证据缺口，不是本轮新实测

- 历史566页155.167秒和97.9145%来自已记录限定环境，保留历史失败；已被新英文扫描书替换为主验收样本，新样本尚无本轮速度、质量或覆盖成绩。
- 最新跨范围／服务状态修复有定向证据，但未完成当前源码下的最终全链走查和真人手势。
- 历史纸张与PDF源码清单已有部分文件不同；先按变更影响判定复用边界，再补证。完整空闲／后台配对分布尚缺。
- 客户端仅有分发资料研究，没有安装包或运行测量。
- 当前源码明确关闭外部图像增强并拒绝区域输入；Omarchy只支持整书处理。选区译文／语法是文本AI，不能替代这项一期能力。真实页／区域增强及复用／重放、付费恢复须沿用既有开发票补齐，尚无本轮运行验收。
- 已核对非空文件存在的公开材料包括数字英文指南、历史扫描书、复杂学术PDF及若干中文／鸟类扫描图；只核对元数据不证明公式、混合语言和跨页表格完整覆盖。新扫描书抽查5页均有扫描图像和不可见文字层，不能将普通导入速度当OCR速度；另需记录明确忽略已有文字层的真实图像识别路径。新增论文已固定v1并记录原件SHA；实际计分段落、独立参考和缺项补样须在执行前冻结。

## 判定与交接

数据／费用错误、核心阅读阻断、明显沉浸体验断裂、性能／清晰度守卫失败，或必要证据缺失，都阻断相应能力放行。纯美观且不影响理解、操作、定位的轻微问题可以明确登记到后续优化。关闭本决策票只表示标准对齐；正式V1验收仍由已有PDF总体验收入口及用户真实体验决定。

用户已批准一张客户端原型决策票：依赖本次V1收口标准对齐，并成为阶段交接的新增前置；其他独立分支继续并行。原型发布不等于开始正式产品开发，实际框架、预算及体验结论由原型取证和用户体验决定。
