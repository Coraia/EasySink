## Acceptance criteria

- [ ] 任务独立于当前面板和旧文本 AI 队列，切书/浏览器关闭不取消，当前其他书不接受旧页面迟到更新。
- [ ] 暂停、继续、取消在实际任务 UI 生效，完成范围可读；取消的任务重启后不会续跑。
- [ ] 恢复只使用原配置/范围和检查点，不因全局设置变化换服务，也不把本机任务推到外部。
- [ ] 有界工作单元、进程退出和检查点提交异常可复现，确定未开始与进行中状态分清；不会丢已有结果或显示假完成。
- [ ] 已有旧书/AI 操作不被长转换占住；付费未知请求的详细恢复另由付费任务验收覆盖。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
