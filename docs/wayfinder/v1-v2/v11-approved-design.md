# V1.1 已确认设计与原型范围

2026-10-11。状态：Q1–Q24 已接受，产品目标与概念对齐完成。用户随后明确授权直接完成 to-spec → to-tickets → implement、走查修复与客户端更新，已进入正式实现；最终交付由用户人工验收。原答与修订保存在 [对齐记录](tickets/record-semantics.md)，领域词汇在根 GLOSSARY.md，记录独立性的取舍在 ADR 0008。

## 目标与范围

优先让正文词注、词卡与主动语境解释可靠易读，再连通收藏、再次遇见和回原文的最小闭环。欧路同步、外部词库管理、复杂复习、整书翻译、自动生成金句和 V2 能力推断不纳入 V1.1。保留 V1 的阅读、来源、费用和性能边界。

## 已确认的行为

| 阅读场景 | 约定 | 来源 |
| --- | --- | --- |
| 点开词卡 | 基础释义是候选，展开词性、领域与来源；可靠短语整体释义优先，仍能单独查词 | Q1、16、19、20 |
| 保存一个词/表达 | 词卡“收藏词语”；每次语境独立，可按词归组；不要求笔记，不推断不认识 | Q2、5、11 |
| 选择文字 | 允许词的一部分、单词、句子和跨段连续原文，不按长度强行分类 | Q5、11 |
| 划线 | 相同范围显示“删除划线”；不同范围先显示“划线”，点击与重叠取并集，再切为删除；不局部擦除/拆分 | Q6、12 |
| 理解并留下记录 | 收藏、已懂这里、保留注释独立。已懂不取消显式保留，也不改变其他语境 | Q3、4、8、14 |
| 写笔记/我的释义 | 个人内容与不可改写的原文快照、词典/AI 结果独立；取消收藏不删笔记 | Q7、13 |
| 主动解释 | 当前句段，必要时前后各一段；可查实际范围，长段有界且告知截取；不发送整章、笔记或画像 | Q21 |
| 已有解释 | 有效的同内容同语境结果复用；换模型不自动重算；明确重新解释才用当前模型；收藏解释主动采用并保留旧版 | Q13、22 |
| 来源变了 | 保存时的引用不随 OCR 改写；不能可靠定位则呈现快照与不可定位说明，不能假跳 | Q9、22 |
| 再次遇见 | 仅书架/全局入口；当天稳定一条，优先未展示，尽量避开七天内；换一条、暂不推荐三十天、持续关闭可用 | Q17、23 |
| 回原文 | 阅读工具仅本书收藏；全局入口汇总各书；先预览，关闭回入口且不改续读，明确继续读才进入对应书 | Q18 |
| 撤销与资料管理 | 撤销只恢复本次状态，无旧反馈回到未反馈；导出/清理按范围独立，原书不隐式联删；旧记录不伪造语境 | Q10、14、15 |

## 本轮可体验原型

入口：[V1.1 阅读闭环](../../../web/prototypes/v11-reading-loop/index.html)。保留原有 [操作对照](../../../web/prototypes/v11-actions/show-me-reading-actions.html) 供比较。

采用独立演示资料，不读写正式书架、笔记、词汇反馈或 AI 配置。浏览器仅保存该原型自己的资料。示例正文与释义是预设内容，AI 解释展示状态与范围，不调用模型。原型允许真实鼠标选区、部分单词和跨段选择，演示划线合并、词卡三种独立操作、自动保存笔记、收藏筛选、解释采用历史、书架再遇见和原文预览。

用户主要验收：新增动作是否自然、菜单容量是否合适、划线合并与删除是否清晰、词卡状态是否易懂、阅读内与全局收藏是否分明、返回路径是否保持阅读现场。原型不重做已发布的纸张翻页、PDF、语音或 AI 引擎；旧功能入口保留位置说明，不将占位服务当作新能力完成。

## 后续规格必须落实

- 来源身份、版本变更与迁移；保留旧数据的不确定性；解释子范围在划线合并后的归属。
- 有界上下文的具体上限、缓存身份、结果未知/离线/费用限额与本地重放；不可仅以词形或模型名作为复用依据。
- 可读导出与迁移资料的真实格式、恢复校验及独立清理契约。
- 日常英文、神学、技术各至少十个真实词句，覆盖歧义、短语、中文缺失；核对词注、词卡、真实 AI，争议译法交用户判断。
- V1 与候选在同环境下的开书、翻页、选区、内存、离线对照；门槛据既有预算和基线确定，不编造准确率或性能通过结论。

推进顺序：**to-spec → to-tickets → 实现 → 真实走查 → 用户人工验收**。规格已发布为 [#39](https://github.com/Coraia/EasySink/issues/39)，子任务 #40–45；详见 [开发控制](../../73-v11-development-control.md)。已接受的目标无需再问；只有新的实质取舍才回到对齐。
