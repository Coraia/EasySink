## Question

为了支持已确定的 V2 评价，在 V1.1 中最少应保留哪些明确操作事实和语境，如何控制采集负担与误推断？

本票需明确：
- 明确掌握反馈、查阅、主动校准、收藏、取消等事件需要的最小时间、来源、版本和帮助可见状态；哪些行为不采集。
- 事实、读者声明和系统推断的区别；重复点击、缓存命中、结果失败与跨设备时钟等如何避免重复或错误证据。
- 旧记录缺字段时的未知状态，如何允许撤回、清除与导出；规则升级后推断能否重算。
- 默认本地保留的范围、保留周期/容量与清理关系，以及可选校准的触发边界。
- 原文、缓存、付费响应与学习依据的联系，避免为记录事实重新调用 AI。

收口依据：最小事件契约与具体正反例；能支持评价而不推断“没点就是会”，不强制首次测试或中途答题。
