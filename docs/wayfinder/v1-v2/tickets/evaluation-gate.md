## Question

在相近辅助密度、释义质量与运行条件下，如何证明新的辅助选择更准确且没有破坏沉浸体验？

本票需明确：
- “需要帮助”的操作定义、独立判断依据、不确定或无效样本的处理，及词语/表达/具体语境的评价单位。
- 需要而漏标、不需要而标出、释义不合语境的区分；手动保留注释与自动辅助的统计边界。
- 当前系统基线，正负样本和未标注位置抽样，跨书籍/领域/时间的分离及防泄漏方式。
- Precision、Recall、F1、释义质量、打断、响应和翻页性能如何一起决定放行；小样本的不确定性如何报告。
- 当前用户实测与未来推广结论的边界，不先承诺任意用户上的绝对准确率。

收口依据：可复现的评价协议、样本收集规则与预先约定的通过/阻断标准。记录缺少实测基线的指标，不以模拟结果补齐。
