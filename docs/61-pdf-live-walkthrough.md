## PDF-UX-01：原文选区与译句定位的高亮无法区分

- 优先级：P1。
- 状态：用户确认；2026-10-08 已修复并完成范围内浏览器复验，待用户体验。
- 用户补充：原文已经被选中一个区域时，点选中文的一段，原文无法区分颜色，可以考虑增加一种颜色。
- 复现：选择原页9的第一段 → 翻译所选文字 → 点击第三句中文译文。原文整段选区持续着色，对应英文句子的定位状态不够可辨认。窄窗口和宽窗口截图均保留。
- 影响：读者知道哪一段被翻译，却难以在段内立即找出当前中文译句对应的英文范围。
- 候选方案：保留选区浅绿色，将当前对应英文句设为另一种强调色（例如浅琥珀）；辅以边线等非颜色标识。译句与对应英文使用同一套定位提示。具体色值、明暗主题和与其他高亮的叠加规则尚未确认，不能视作已批准的视觉方案。
- 后续人工验收：整段选区与当前对应句能同时辨认；切换译句时仅移动当前句提示；原选区及笔记标识不丢失；取消选区、收起译文后无残留；浅色/深色主题均可区分。先排除定位范围错误，再验证配色，不能仅加颜色掩盖错误的原文范围。
- 证据：`outputs/pdf-live-demo-20261008/24-translation-linked.jpg`、`27-wide-translation.jpg`。

## 本次实际完成的路径

1. 专注阅读 → 下一页 → 上一页 → 本地词卡与音标。
2. 选择第一段 → 记一笔 → 自动保存 → 正文笔记标识 → 编辑 → 自动保存。
3. 选区加书签 → 正文出现可移除的书签标识。
4. 核对原版 → 原PDF第9页实际高亮 → 125%放大、90°旋转 → 回到原阅读位置。
5. 顶部/底部工具层 → 字号22→23→22 → 再次点击同一图标回到工具层。
6. 拖动阅读进度至50.5%并松手 → 跳转 → 回到刚才。
7. 底部笔记列表 → 删除临时笔记 → 撤销恢复。
8. 查看目录与PDF处理面板：真实118/118原页处理完成。
9. 回书架 → 实际文件选择器重新导入同一公开PDF → 提示复用同一本书 → 关闭、留在书架 → 继续阅读。
