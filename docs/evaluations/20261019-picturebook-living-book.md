# 《小王子》全书动态绘本

日期：2026-10-19。全书入口：<http://127.0.0.1:18805/#/living-book/2>；体验玫瑰：<http://127.0.0.1:18805/#/living-book/9>。旧狐狸入口 `#/fox-story/22` 继续可用。

## 已实现

27 章保留当前书库的完整英文，1582 句、562 个阅读页。沿用认可的手绘色彩与人物；第 21 章保留独立角色、站坐姿、靠近、花园和玫瑰动画，其余 26 章复用已有全书插画，为 55 幅关键画面逐幅标定人物与物件的动作区域。连同狐狸章 10 个情节段，共 65 个动态情节段。

鼠标悬浮句子、点击、方向键或进度条选择原句；到关键情节时交叉淡入新画面，同一构图内由句中词语选择局部回应。重点词支持悬浮、点击、键盘 Enter，显示词义并强调约 3.2 秒的动作，例如花瓣轻摆、围巾飘动、灯光明暗与手部回应、滑轮转动、水桶提起、蛇身轻动、列车局部移动和星光闪烁。词语提及的物件尚未出现在当前画面时，由画中人物回应，随后恢复当前句的动作。

这是手绘纹理上的 2.5D 局部网格形变和光效；其他章节没有逐一拆成狐狸章那样的独立角色骨骼，也没有自由旋转的完整三维模型。同一关键情节内共用画面，不是每句新增一张插画或一个动作镜头。本轮没有生成或替换插画资产。

章节目录、上一章/下一章、逐句阅读的跨章前进和后退、每章独立续读均已接通。自动阅读到章末停止；手动操作中断自动阅读。原阅读页提供动态绘本入口，首页“阅读《小王子》全书”直接进入动态版本。保留原文来源、译者与 CC BY-NC 3.0 归属、原书献词；中文内容明确为情节提示。

## 实现位置

- `web/picturebook-living-rigs.js`：55 幅画面中具体角色、物件的归一化坐标和运动方式。
- `web/picturebook-living-chapter.js`：当前正文的分句、原文锚点、情节段、分页和全书词语映射。
- `web/picturebook-living-scene.js`：Three.js 局部形变着色器、图集裁切、交叉淡入、暂停/离屏停止、资源清理和静态回退。
- `web/picturebook-fox-reading.js` / `.css`：共享全书阅读界面，狐狸章仍选原角色引擎，其他章节选择新引擎。
- `web/picturebook.js`：全书路由、首页及原阅读器入口。

正文每次通过当前文档 API 读取，并要求后端匹配完整版本的 `story_plan`。阅读位置按文档版本、块 ID、字符偏移保存，不覆盖原阅读器位置。没有改写数据库正文、提交或推送，也没有触碰其他未完成的项目改动。

## 实际浏览器验收

证据目录：[outputs/picturebook-living-book-20261019](../../outputs/picturebook-living-book-20261019/)。实际 IAB 与 WebGL，桌面 1171 CSS px；窄屏为实测 390 × 843 CSS px。不是实体手机或原生客户端验证。

从第 1 章连续走到第 27 章末页，先逐句，后按页点击末句再点击下一句。保存 651 次页面观察，每次采集全部可见页的原文、块 ID、字符偏移、当前情节、画布数量及溢出状态。562 页全部经过，1582/1582 句逐字符和锚点匹配，各章正文哈希一致；65 个情节段全部经过，画布均为一个，没有横向溢出。

每章另选一个原文重点词实际点击，27/27 词语交互通过。部分早期词语是回忆中的物件，明确记录了由当前人物回应的目标；例如第 4 章早期的 astronomer 尚未切到天文学家画面。额外验证了悬浮句子、悬浮 lamp、键盘 pulley、bucket 提桶、词语效果恢复、暂停切换情节、正反向跨章、全书末章重读、自动阅读到末句停止、手动打断、刷新后恢复第 8 章第 18 句、390px 点词和翻页、来源不匹配的友好提示，以及返回原文后画布清理到零。

实际画面采样：点灯场景两次截图在固定插画区域中有 10592 个像素变化超过 3/255；固定视口暂停后的两次截图差异为零，frames/time 也相同。该结果证明画面变化和停止，不是视觉品质打分或帧率基准。初次暂停截图因取样时机与滚动位置变化而不可直接对比，原样保留并记录原因。

窄屏首次发现“开启情节提示后当前句被固定插画挡住”，已修复为重新定位当前句；复测插画底部 y=310，当前句顶部 y=325.13。第一张失败截图和修复后截图均保留。完整正文走查之后仅补充了 crate 词条、提示定位和词语临时动作复位；这些改动进行了对应的浏览器复测，不影响正文内容和分句。

浏览器控制台最终无 warning/error。语法、格式与 `git diff --check` 通过。未新增单元测试，未运行无关的全项目测试套件。静态回退代码已实现，但本轮没有强制 WebGL 故障注入；没有物理设备性能或音频验证。

## 复查

1. 打开首页，点击“阅读《小王子》全书”。从第一章逐页点击当前页末句，再点下一句，直到第 27 章末尾。用章节目录可单独复查。
2. 第 14 章第 3 句悬浮 lamp；第 25 章第 10 句点击 pulley/bucket；第 8 章第 23 句点击 petals。切换情节、暂停再翻页、恢复动画。
3. 第 27 章进度条选第 32 句，启动自动阅读，最终停在第 33 句。第一句点上一句应进入第 26 章末句。
4. 将视口设为实际 390px，点下一句和情节提示，当前句应出现在固定插画下方。刷新后应恢复所选句子。
5. 在仓库根目录运行 `node outputs/picturebook-living-book-20261019/verify-source.mjs`，对保存的真实浏览器记录和 API 正文快照重新逐字核验。`source-verification.json` 提供逐章哈希和结果，`word-actions.json`、`browser-checks.json` 保留实际交互状态，PNG 保留实际画面。
