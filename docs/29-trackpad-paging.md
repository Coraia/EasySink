# 触控板翻页

> 历史方案。最新已改为[跟手卷页与回滑撤销](31-trackpad-follow.md)，不再使用 80px 立即提交规则。

正文中双指横向滑动，累计超过 80 CSS 像素后翻一页；双页布局前进/后退一跨页。浏览器 deltaX 正向为下一页，负向为上一页，实际手指方向跟随系统“自然滚动”设置。

沿用当前纸张弯曲、光影动画；减少动态效果或关闭动画时直接换页。小幅抖动、纵向滚动、比例不足的斜滑不触发翻页。一次连续手势只翻一次，停顿超过 240ms 后重新判定，动画结束不会提前解锁惯性。

选区、词卡、翻译、工具层和输入控件保留自己的交互。跨章节加载时同一个输入流持续锁定，不在新章节多翻一页。事件处理不改变正文 DOM，不进行测量重排，不创建轮询或定时器。

`web/reading-trackpad.js` 只负责识别与隔离，调用现有 `ReadingPages.adjacent`，不复制分页/锚点/动画。`web/app.js` 安装一次应用生命周期监听器；每次事件取当前 Reader，无旧章节对象被常驻引用。删除该 import 与安装调用即可清退，现有点击/按键/纸边拖拽继续可用。模块返回卸载函数供未来应用容器销毁使用。

实现前的失败清单：[28-trackpad-failure-cases.md](28-trackpad-failure-cases.md)。验证产物和复现步骤：[RESULT.md](../outputs/wise-reader-trackpad-20261007/RESULT.md)。浏览器事件 E2E 不等于真实 Mac 触控板各速度、惯性及系统设置均已人工验收。
