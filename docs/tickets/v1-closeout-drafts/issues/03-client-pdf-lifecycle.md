## What to build

在客户端导入并阅读 PDF，按需核对原版、留下记录，在后台转换、休眠唤醒、退出重开和任务恢复后保持书籍、位置与处理范围。复用已经具备明确行为的 PDF 记录和任务控制；本票解决客户端承载与生命周期的完整使用路径，不重新建设 PDF 引擎、记录或任务系统。

同时测量应用、词库、OCR/语音资源和整棵进程树的成本，为 [客户端原型决策](https://github.com/Coraia/EasySink/issues/34) 提供基线。可与客户端真实手势适配并行；最终原型的预算必须按合并后的候选复核，不能把未包含原生接入的早期测量当最终结果。

## Acceptance criteria

- [ ] 从客户端实际文件入口导入固定数字 PDF，保存原件与书籍归属，已就绪后打开阅读版；可从正文/原图定位原版并回原位，不将原版可见算成阅读版完成。
- [ ] 文字/原图笔记、书签、续读及来源在重排、核对原版、休眠唤醒和退出重开后经 UI 回读正确；沿用原记录模块，遇到其缺陷回原票协同修复，不建立另一份客户端记录。
- [ ] 使用真实可用且已授权的转换路径，在任务未结束时切书、关闭窗口、退出重开，按既定任务策略恢复允许的工作；取消不复活、范围/服务不偷换、已完成结果不丢，未知付费请求不自动重发。明确区分关窗口与退出进程，后台驻留方式保留给原型体验判断。
- [ ] 在隔离资料下覆盖重复启动、服务异常退出、端口占用和休眠后的连接恢复；只管理自有进程，不干扰正式阅读实例或其他模型服务，不输出凭据。
- [ ] 冷启动、暖重开、原版首屏、首阅读范围、全书转换分别计时；已有文字层提取与真实图像 OCR 分列，不将新扫描书的普通导入速度冒充 OCR 速度。
- [ ] 应用包/安装后资源、必要词库、可选 OCR/语音下载和所有子进程的内存/CPU分项报告；测量空闲阅读及真实后台转换时的实际体验，不以模型停用、降DPI或禁用辅助获得假轻量结论。
- [ ] 使用真实引擎和明确范围；没有模型/设备条件时如实报告未验收，不以假进度、模拟OCR或框架官方声明代替。若已有任务/记录合同尚未可用，先由其原票补齐，客户端准备不等于本票可以放行。
- [ ] 交付可安装候选、固定环境与来源摘要、完整重开/恢复步骤、原始资源序列及首失败。与手势切片汇合后，在原型决策内补齐受变更影响的成本测量，再由用户确认方向和预算；本票不自行宣称正式发行。
