# 固定书脊：修改前约束与失败模式

用户确认：装订书的内侧整条边必须一直连接中缝，不能像散页一样被拖离；只改形变与相关光影，保留已验收手势、停驻、结束、回滑、队列和高清绘制。

- 原形变允许斜向圆柱折线跨过内侧边，并对整张纸执行中缝宽度平移，造成内侧角点悬空。仅画遮罩或加阴影不能解决真实网格脱离。
- 必须在纸张局部坐标约束整条 x=0 材料边：所有高度的 x、y、z 都固定于原来的装订边，不能只固定一个点。
- 远端抓取点继续沿已有可达范围模型，单/双页、前后翻、上下折角都适用。禁止用停止动画、屏蔽纵向或回滚触控板规则规避形变。
- 斜折时的过渡必须连续；法线要来自约束后的曲面，避免光照还表现为悬空纸页。透视投影不能再次移动固定书脊。
- 不能因为装订约束引入整页在结束前跳动；现有中缝补偿改为仅作用于远端，装订边不能整体漂移。
- 验证不能只读自报坐标：E2E 在实际 WebGL 网格绘制时标记内侧材料边，检查屏幕像素位置；同时保存未加标记的角点截图供视觉复核。
- 深色、高清、取消及左右不同方向检查，保留既有帧率/缓存守卫。诊断标记只在明确 debug 开关启用，正常阅读没有标线。
- 只运行 E2E，不写单元测试；开发结束再跑完整回归，保留首轮失败和可复现报告。真实触控板手感仍由用户复验。
