# EasySink 产品定位与行为验收

## 产品定位

EasySink 是面向中文读者的本地英文书籍与长文阅读工具。目标不是把页面堆满 AI 功能，而是在尽量稳定的阅读位置上提供可追溯的查词、正文词注、个人笔记和选区翻译，并把数据保存在本机。

主流程：添加 EPUB/PDF/TXT/Markdown → 进入书架 → 打开章节 → 阅读/翻页 → 按需查词、加注、记笔记或翻译 → 自动保存阅读锚点 → 离开并续读。AI、远程 TTS 和外部 OCR 都是显式启用的可选能力。

## 四类内容不能混淆

| 内容 | 用户意图 | 持久化/定位要求 |
| --- | --- | --- |
| 查词 | 临时理解当前词 | 可不保存；无可靠释义时必须明确告知 |
| 正文词注 | 在这一次出现处保留提示 | 按 source anchor 绑定，不得串到同词另一处 |
| 个人笔记 | 记录用户自己的文字 | 与词典释义分开，有独立入口与生命周期 |
| 选区翻译 | 理解一段连续原文 | 绑定完整源片段；显式点击译句必须翻回对应原文 |

页码是排版结果，不是稳定身份。持久化必须使用文档版本、block/segment 和原文范围；Web 字符偏移统一为 UTF-16 code units，不能与 Python code points 混用。重复词句必须携带具体 source 定位。

## 核心行为合同

### 操作与安全时机

- 用户直接操作的目标立即更新，例如当前词注、当前笔记、当前 scope 和 feedback。
- 若模型/反馈会间接改变已读前文，当前展开页保持稳定。数据可先保存，但 presentation 只在真正离开展开页并再次返回等安全时机刷新。
- 关闭卡片不是安全时机。API 成功、数据刷新成功和页面 presentation 完成必须分别记录。
- 固定输入后前后往返必须确定：不丢字、不重字、不累积漂移。
- A 操作后立刻点 B、立刻翻页、立刻回书架是三条不同竞态；旧异步结果不得覆盖较新的用户意图。

### 词注与笔记

- 添加词注后应马上能再次点选；减注后空格、换行和原文选择范围恢复正常。
- 无可靠词义时禁用无效的“保留词注”操作，并提供清晰的主动解释入口；不能自动调用 AI 假装已有释义。
- 词义入口和笔记入口都可发现；同一个表面词在不同 source 位置互不串联。
- 已采用释义、用户自写义和历史释义要能区分，撤回只撤对应操作。

### 翻译与跨页定位

- 跨页连续选区可以生成翻译，但必须保留各 segment 的 source anchor。
- hover、回选区或“原句仍在屏幕里”不能替代显式点击验收。用户点译句时，应翻到与该句对应的原文位置并高亮/呈现。
- 译文关闭按钮不得与顶部 banner 重叠；关闭后原阅读位置不漂移。

### 翻页、排版与续读

- 卡片打开时，页级触控板翻页与卡片内部滚动必须区分；鼠标模拟事件不能证明物理触控板通过。
- 字号、窗口宽度、单双页切换和冷启动后，恢复的是准确原文锚点，不是旧页码，也不是“目标句大致还可见”。
- 改变排版会重新分页，但笔记、书签、词注、翻译和进度仍落在原 source。

## 八项产品验收清单

以下是要求，不代表当前全部通过。位置 001/002 使用可再生的 source 定位替代用户原书；用户原书不得进入 Git。

1. **001 缺释义**：`life-on-life` 无可靠词典释义时，操作不可制造空注释；主动解释入口可用。
2. **002 首次加注**：`Comprehensive` 首次加注立即出现且仅作用于该 occurrence；减注不留空白，能再次选择，空格正常。
3. **双入口**：词义与笔记入口均可发现，保存/撤回互不污染。
4. **右页尾与往返**：页尾加减注、前后翻页、延迟更新不导致丢字、重字、前文跳动或累计漂移。
5. **卡片手势**：卡片打开时，物理触控板能区分页级翻页与卡内滚动。
6. **书架性能**：返回书架不长时间停在 loading；真实大库另测，合成小库不能代替。
7. **排版与续读**：字号/窗口/单双页/正常退出冷启后，首句和 source anchor 准确恢复。
8. **跨页翻译**：打开原文保持位置；显式点译句能定位对应 source，译文面板可关闭。

用户已认可的是当时版本的翻页视觉、画质/动作、一次主观连续流畅感和跨页整段可选；这不等于上述功能、性能或发布门全部通过。

## 范围边界

- 本地优先，不承诺云端账号、多用户隔离或跨设备同步。
- EPUB 以可读结构为主，不承诺原书高保真分页、DRM 解锁和完整脚注/图片还原。
- PDF 转换完成不等于公式、图表、复杂版面或 OCR 质量通过；不可可靠重排的区域保留原图。
- 未经用户显式动作，不进行整章/整书 AI 调用、付费增强或远程模型重试。
- macOS 原生包当前是候选形态；签名、公证、分发和干净设备安装不是已完成能力。
