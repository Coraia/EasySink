## What to build

读者在空间不足时保持书籍和记录安全，按明确类别释放资料；关闭 PDF 处理保留内容并让旧阅读正常工作。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 原件、记录、有效版本、重放资料及可恢复书籍默认不按天删除，普通清理只释放可本机重建的临时资源。
- [ ] 空间不足先清临时资源，仍不足暂停新增转换；上传、付费响应写入和结果提交阶段都不写满后假报成功。
- [ ] 明确清理显示类别、范围和已释放/仍保留结果，不增加授权弹窗；仍被版本或笔记引用的资料不能被误释放。
- [ ] 回收/恢复、本地重放及普通缓存清理组合场景保留资料与调用计数，重放材料的专门清除有明确业务操作。
- [ ] 关闭处理后入口/后续工作受控、原件和记录保留，已有已转换内容与 EPUB/TXT/Markdown 仍可读，零隐藏外发或重新付费。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
