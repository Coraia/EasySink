# PDF 默认本机处理，外部处理需要明确选择范围

2026-10-08，用户接受澄清后的 Q3：普通 PDF 导入默认在当前电脑处理，本机失败不自动转用外部服务；只有用户明确选择外部处理的目标服务与文件、页或区域范围，才发送相应内容，外部包括云端 LLM API 和读者自己的其他服务器，不包括本机模型接口。Q4 明确含义清楚的用户处理操作本身完成授权，不另外增加授权或费用确认步骤；已有文本模型配置不视为整本 PDF 的处理授权，这一取舍保留读者对内容外发和付费调用的控制，并避免重复确认破坏阅读体验。Q14 确定第一期提供主动选定页或区域的外部增强，暂不提供整本付费外部转换；复用/重放、资料保留及未知结果处理分别遵循 Q5、Q10、Q11 和对应 ADR，具体服务、计量和空间策略仍需设计与验证。
