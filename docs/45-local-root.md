# 贴靠书体的局部根部修正

正式版本：20261008-local-root。以用户认可的20261007-bound-spine为基线，仅修改 `web/page-fold.js` 的局部顶点曲面与解析法线。其他六处生产改动只是导入查询串和服务版本更新。

## 曲面与改动边界

材料横向坐标 x 小于页宽12%，且折线跨过该高度的书脊时才启用修正。根部仍固定在原来的装订线上。用 `(1-x/span)^8` 的紧支撑修正，使根部切线贴靠书体；12%接续边界的修正和一阶导数都为零。法线使用包含所有修正项的解析切向量，不做重复曲面采样。

当原曲面的根部切线已朝向书体另一侧，直接减切线可能将高度压入书体，改用正高度三次接触弧：根部水平，接续点及切线等于旧曲面。两条局部路径按根部切线平滑混合，y切向量同时包含混合权重的导数。折线刚触及书脊高度时亦平滑启用，防止法线接缝。

这不是全页凸性模型，也不是物理布料求解器。浅斜拖时旧曲面已有自然拐点，在固定旧接续点及切线的前提下不能要求所有截面严格凸。修复目标为贴靠装订线、局部平滑且不增加明显凹口；旧12%带外位置及法线保持不变。

`foldForPointer`、片元光影着色器、五个输入/手势模块、渲染器DPI/网格/缓存策略均保持原样。正式服务的书籍和用户数据不用于自动化写入；E2E使用18767临时数据库和原生阶段fixture。

## 验收与复现

`reader-root.spec.js` 使用真实浏览器页面、鼠标按住斜拖及生产WebGL程序；读取实际 uniforms，GPU输出97×25材料位置和法线。旧shader固定在 `tests/browser/fixtures/bound-spine-reference.vert`，同一uniforms计算旧形态，避免另写CPU模型作为证明。覆盖单/双页、前/后翻、上下角、34%/60%纵向位移、15%至99.5%行程，共16场景128姿态。

检查根部倾角≤0.08rad、非负纸面高度、12%以外位置/法线保持旧版、实际投影抓取点误差<1CSSpx；局部反向转角守卫记录并对照旧同姿态的自然拐点。原有书脊截图坐标检查、DPR1/2/3、软件GPU、原生停驻/反向/连续翻页、帧间隔和输入延迟34ms守卫保留。新增深斜拖阶段fixture性能检查，覆盖12次往返与深折持续输入。

复现：

```sh
WR_E2E_EVIDENCE=outputs/local-root-reproduce npx playwright test
```

证据目录为 `outputs/wise-reader-local-root-20261007/`（任务开始于10月7日，完成跨至10月8日）。`root-red`是真实旧版根部抬起失败；`red`是首轮诊断shader精度不匹配的测试工具失败，不能混淆。`deep-validation`保留三次曲面采样候选的接续和性能失败，`baseline-performance`保存旧shader同场景性能对照，`analytic-check`保存早期解析方案深折失败。通过的最终源码和验收结果在RESULT.md中记录。浏览器验证及原生阶段fixture不能代替用户真实触控板手感验收。
