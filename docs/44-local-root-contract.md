# 仅修书脊局部凹口：改动前约束

用户否决整页凸曲面版本，已恢复旧整体卷曲。此次只修根部局部过渡，不能重新限制全页折线斜率，不能移动原有抓取点或改变根部之外的曲面。

失败模式：

- 固定装订坐标但根部法线大幅倾斜，像整片根部跟着外缘撑开。
- 把局部凹口修复扩大成整页凸性，再次改变认可的纸面形态。
- 局部接续产生负高度、尖点、反向弯折、纹理拉扯或边界光照缝。
- 根部补丁影响远端、抓取点或横向/纵向跟手位置。
- 在书脊被卷曲线扫过的高度边界，补丁突然启用造成撕口。
- 斜拖方向、浅折/深折、单/双页、反向、终点表现不一致。
- GPU 法线不匹配曲面；软件 GPU 或高 DPI 渲染耗时增加。

先建立真实页面鼠标斜拖 E2E：读取已链接生产 GPU shader，编码根部法线和曲面位置，检查根部倾角 ≤0.08 rad、非负纸面高度、局部截面没有超过 0.035 rad 的反向转角。以本轮旧 shader、同一组实际 uniforms 在诊断 GPU 求参考曲面，根部 12% 材料宽度以外位置与法线必须保持旧版（量化容差），抓取点投影差 ≤1 CSS px。全页切平面凸性不是验收条件。

保留首轮失败、旧版源文件、正常/诊断截图与原始 GPU 数据。仅用 E2E；完整回归在开发结束运行。原有固定书脊像素、帧/输入 34ms、DPR/缓存守卫不放宽。每种局部模型最多两次没有进展的尝试；如仍失败，停下报告，不能改回全页模型。原生阶段 fixture 不代替用户真实触控板验收。

## 扩展浅斜折后的验收纠正

15% 行程 + 60% 高度的浅斜拖暴露了原验收指标误把整页截面凸性当作局部要求。旧版带外本来就有 -0.20 rad 的反向转角且新旧完全相同；带内旧型也有自然拐点。固定接续端点和端点切线时，如果平均斜率大于端点斜率，从水平根部接过去必然有拐点，无法同时要求全部凸又保留旧外形。不能为了该指标再次改整个曲面。

修正为只检查根部12%带及接续边界：旧曲面该带没有明显反弯时仍用原 -0.035 rad 限制；已有自然拐点时不能比旧同一姿态的局部最小转角再负0.003 rad。带外位置/法线、根部倾角、非负高度、抓取点和原有性能阈值全部不变。两种结果均输出原始 GPU 点和旧曲面参考，不能隐藏失败。

第一候选三次曲面采样法线在浅斜折新增弯折并导致性能守卫失败；同一真实页面场景换回旧 shader，两个性能场景均通过。因此替换为复用旧曲面已有的解析切向量、仅根部使用紧支撑 q^8 修正，避免额外曲面采样。

解析根部切线修正通过浅斜折与性能，但极深折的旧根部已转向背面，单纯减切线可能产生负高度。最终仅在该根部方向平滑切换到解析三次接触弧：同一旧接续点及切线，正高度控制点；所有法线均解析计算，不再做多次曲面采样。包含切换导数，保留最外12%边界与旧曲面的精确接续。
