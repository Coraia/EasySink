## 体验方式

运行 `python3 scripts/web.py start`，打开 [本机阅读空间](http://127.0.0.1:8766/) 。`status` 查看状态，`restart` 重启，`stop` 停止。服务独立于终端会话运行；日志在 `.runtime/web.log`，只监听本机回环地址。电脑重启后需要再次启动服务。

建议体验路线：

1. 点击「体验一篇示例」。首次使用不强制测词汇量，也不强制登录。
2. 点击一条中文解释，标记「已掌握」，回到书架再打开，检查反馈是否仍生效。
3. 在一段英文内选中文字，打开「笔记」，输入想法；等到「已自动保存」。切换辅助密度或页面再返回，检查笔记。
4. 点击「书签」，改变字号后从书签页回来。进入「专注」模式，再使用可见的「退出专注」返回。
5. 点击「添加阅读」，导入自己的 EPUB。弹窗也提供原创示例 EPUB，可下载后导入。
6. 在阅读偏好里连续选两个领域，观察「保存中」变为「已自动保存」，刷新验证。
7. 在功能管理关闭笔记或续读，观察入口变化；再次开启，原数据仍在。

## 本轮设计选择

主要页面为书架、阅读器、笔记与设置。首页统一展示书籍和独立文章，书籍进入章节目录；历史章节不会重复铺满书架。中文解释紧邻英文，展开解释时注明「词典释义」「本句语境规则」「常用表达」或「AI 注释」。

设置、笔记与手工译文都明确显示保存状态。笔记、译文与导入文本的未完成草稿保存在当前浏览器；服务不可用时保留草稿，并在网络恢复或后续编辑时重试。草稿不是跨设备同步。输入框为空时不会删除已经保存的笔记或译文。

「辅助密度」是软预算。用户明确要求保留的注释优先，可能超过预算；界面会告知数量。选择原文时也会保留这些明确要求的注释。未知词的查阅不再自动把它标成不会，只有明确反馈才修改个人档案。

个人熟悉度仍是词频启发式，不是准确能力评估。短测试核对当前题目、重复回答幂等，以当前抽样频带而非第一道题任意词频调整范围。结果表述为参考范围，不再声称精确测出词汇量。

## 内容与数据

继续使用 FastAPI、SQLite 和本地词典。没有为了界面重写引入新的线上服务或数据库。

- `content.py` 拥有书籍、章节、内容块、版本和共享锚点。原 `wr_book` / `wr_chapter` 表名与数据保留，导入器不再导入书架插件。
- 文本块包含 `id / type / text / start / end`。版本为原文 SHA-256；块 ID 来自类型、内容摘要和重复序号。
- EPUB 保留标题、段落、列表项、代码、引用及图片替代文字。先规范化相对路径，再按 spine 顺序读取。上限是 20 MB 上传、100 MB 解压、8 MB 单资源、5000 个 ZIP 条目、500 章；单章最多 50 万字符，整书最多 500 万字符；超限明确拒绝，没有静默截断。
- EPUB 的原书分页、字体、图片原件、复杂表格布局、脚注交叉链接和 DRM 内容尚未完整支持。本版本不能作为高保真 EPUB 排版引擎。
- 一次导入在 SQLite 事务中完成；解析失败时整次回滚。CPU 工作在线程池执行；大量章节的写事务仍会短暂串行占用用户库，导入暂不支持中途取消。
- 旧纯文本内容首次读取时惰性生成块；旧笔记保留引文，旧进度保留比例，可作为定位回退。旧 EPUB 已经丢失的排版不能凭空恢复，要重新导入原文件。
- 锚点含 `version / block_id / start / end / quote / prefix / suffix / ratio`。前端偏移使用 JavaScript UTF-16 字符偏移；先定位块，再按原句回退，最终才使用比例。不是完整的 W3C Annotation 实现。
- SQLite 单连接由可重入锁串行访问，并提供完整读改写事务。核心 schema 版本记录在 `wr_schema`，已有表使用增量建表；不重建用户库。
- UI 的「归档」只记录归档状态，可还原，保留关联笔记。旧版永久删除 API 仍用于兼容，不在新版 UI 暴露。

用户数据位于 `data/user.db`。本轮开始前已通过 SQLite Backup API 创建 `data/backups/user-20260911-153503.db`。代码基线为 Git 提交 `4a7da10`。备份、运行日志、API key 和词典大文件不进入 Git。

恢复旧库前先停止服务，并另行备份当前用户库；用 SQLite Backup API 把所选备份写入用户库，再启动。不要在运行期间直接覆盖数据库或只拷贝 WAL 模式下的单个主文件。

## 插件开发契约

前端采用原生 ES modules，不需要生产构建步骤。

- 注册表：`src/wise_reader/plugins/catalog.py`。一个功能对应一个 ID、描述和可选后端模块。
- 前端：`web/plugins/<id>.js` 导出 `install(ctx)`，返回卸载函数。用 `ctx.hook(slot, callback)` 与 `ctx.route(name, handler)` 注册能力，并在卸载时移除。
- `Scope` 是页面与侧栏生命周期。事件用 `scope.on`，定时器用 `scope.interval`，其他资源用 `scope.cleanup`。关闭页面或模块时注销，不允许无归属的滚动监听、计时或语音。
- `PluginHost.sync` 只安装启用模块。切换即时生效；每次路由重新读取开关，因此其他标签页改动不会让旧插件错误覆盖正文。单一辅助模块失败时保留核心阅读。
- 后端提供 `migrate(store)` 和 `register(app, ctx)`。路由通过 `require_plugin(id)` 检查开关。关闭模块不 DROP TABLE。
- `content-v2` 与 `route-scope` 是当前核心能力，不是可卸载插件。书签不要求续读，导入不要求书架；插件间通过核心服务协作。
- 清退代码：删除注册项，再删除对应前后端模块。保留历史表与数据；若确实需要删除数据，应另写明确的数据迁移。物理移除书架注册项后的导入已加入回归测试。

前端核心划分为 `app.js`（路由与页面）、`reader.js`（正文与定位）、`core.js`（请求、生命周期、浏览器草稿）、`plugin-host.js`。每个请求携带路由 AbortSignal；过期路由响应无法覆盖新页。密度或反馈只刷新 article，不重建笔记侧栏。

笔记写入有客户端稳定标识和服务端幂等表，并按文档串行保存。快速关闭、重开侧栏时不会重复创建笔记；迟到响应不会用旧草稿覆盖当前草稿。单浏览器操作有此保证，两个设备/浏览器同时编辑的版本冲突尚未实现。

## 注释与 AI

词典是默认可用的基础层。额外离线规则覆盖少量常用表达和可审查的选义案例，例如选举语境下的 redistricting、河岸语境下的 bank。这是有限规则库，不代表通用语境理解已经解决。

词组与词汇统一参与最终重叠选择，避免未被选中的词汇候选提前屏蔽词组。普通词反馈以 lemma 为目标，表达、语法与文化以类型加标准化表达作为目标。它们仍不是完整的多义词词义 ID 或跨不同表述的概念图谱。

模型输入保留原句标点及 token 编号。模型异常、无效结构或全部不合法注释不会缓存为成功；缓存键包含模型与提示词版本。导入后可以立即读基础注释；配置 AI 时，长度符合限制的章节在后台补充增强注释。超长章节的增强注释暂限 20,000 字符，需拆章。

AI 翻译和注释任务保存在 `wr_job`。翻译按不超过 1400 字符的片段调用，逐片保存结果；只有一章完整后才替换该章译文。取消在当前服务请求返回后停止，不会撤销已完成的章节。失败可重试，重启后从检查点继续。整书任务按章节顺序处理。

当前机器没有启用 LLM 凭据。界面显示未配置状态，词典、规则、笔记和手工译文可用。启用方式：复制 `.env.example` 为 `.env`，填写兼容接口的 URL、模型和 key，将 `WR_LLM_ENABLED=true`，重启服务。密钥仅在服务端；原文只在主动启用 AI 后发往该供应商。需自行确认所选服务的费用及数据处理方式。

## 验收与边界

后端回归：`uv run --no-sync python -m pytest -q`。

浏览器回归：`npm ci`，`npx playwright install chromium`，`npm run test:e2e`。测试通过 `scripts/test_server.py` 启动临时 SQLite 库，使用端口 18767，不修改真实书架。失败留下 trace、截图与 HTML 报告。主应用继续使用 8766。

本轮结果：48 项 Python 测试通过；15 条真实浏览器流程通过；JavaScript/CSS 格式检查与 Python Ruff 静态检查通过。另针对最终字词注释排版补跑手机与夜间场景。Python 测试有一条上游 Starlette/httpx 弃用提示，不影响本轮测试结果。

数据核对：原库 5 篇文章、5 项词汇反馈、1 条笔记、1 个书签、1 份个人档案、1 本书和 1 章均完整保留。回归测试全部使用隔离数据库。

自动化覆盖包含：81 章与 `../` 路径 EPUB、损坏文件、事务回滚、移除书架插件、失败缓存重试、恶意 HTML、题目校验、重复反馈、共享锚点、任务断点、页面竞态、自动保存、插件开关、黑夜样式、手机宽度、实际上传与本机锁。

朗读测试验证传给浏览器的是英文原文、分段与退出清理；无头浏览器不能证明系统扬声器的实际音质。AI 调用使用确定性测试客户端验证失败和恢复，不声称已经用真实模型验过翻译质量。

人工体验仍需判断注释是否恰当、阅读是否更连贯；自动测试通过不等于已证明理解率提高。尚未提供云同步、多用户隔离、跨设备合并、完整 EPUB 排版、通用文化知识推断或生产环境账号恢复。
