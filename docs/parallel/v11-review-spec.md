Reviewed `git diff 023936a1d9df72715fc6794dbe64e3c38352eacb...e97f552d83f61d181fd3b29b40e73e2e2ca31d1c`; single commit `e97f552` (#39), including existing R1–R4 fixes. Authority: docs 72/73, accepted ADR 0008 and Q1–Q24. Static, read-only review; no tests, browser, provider or personal-data access.

1. **[P1] Missing integration: deleting an original still deletes independent notes.** Spec `docs/72-v11-reading-loop-spec.md:44`: “收藏、笔记、反馈与原书分别清理，永久操作明确范围，普通删除可撤销。” Trigger: create a note in an EPUB/TXT book, then delete only that book through `DELETE /api/library/books/{book_id}`. The unchanged `src/wise_reader/plugins/library.py:92–100` calls `Store.delete_document`; `src/wise_reader/store.py:195–214` permanently deletes `wr_note` alongside the document, without an independent notes choice or undo. The new scoped cleanup does not intercept this path. This is an unimplemented V1.1 requirement, not a newly introduced deletion regression.

2. **[P2] Reimporting an identical original cannot restore existing collection navigation.** Accepted Q9, `docs/wayfinder/v1-v2/tickets/record-semantics.md:83`: “重新导入或 OCR 修订只在来源可可靠对应时恢复定位，不覆盖收藏时的引用。” Trigger: save an EPUB collection, delete its original book, then reimport the identical EPUB. `src/wise_reader/collections_source.py:213` checks only the non-null saved document ID; when that deleted ID fails, it never searches the fingerprint candidates. The new import has different IDs, so source preview incorrectly remains unavailable despite an exact, unique original. Fall back to verified stable-source resolution after a stale local ID fails.

3. **[P2] Deferred source restoration leaves valid AI adoption unusable.** Spec `docs/72-v11-reading-loop-spec.md:35`: “收藏解释先预览再采用，保留旧解释和来源，原文快照不被改写。” Trigger: restore collection JSON before importing its unchanged original; subsequently import the book and generate an explanation for the exact saved range. Source preview now resolves successfully (`collections.py:358–366`), and the detail dialog offers that explanation, but PATCH passes the still-null stored document ID (`collections.py:262`) to `adopt`, which rejects it at lines 165–166. Reimporting the same JSON also skips rebinding (`collections_transfer.py:340–351`). Adoption needs verified current source binding while preserving the saved snapshot.

No unasked scope identified. Feedback independence, offline dictionary/cache paths and visible-range rendering appear structurally aligned. Ongoing UI/performance and human acceptance are not counted as code defects.
