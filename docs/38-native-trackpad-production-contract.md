# 本机触控板与高清翻页：实现前约束

2026-10-07 用户通过独立原型并授权接入正式阅读器，额外要求优化翻页中文字模糊。

## 保持已验收行为

同一鼠标抓取几何，横向与纵向位移都跟手；手指仍接触、没有新移动时不能计时释放。原生 ended/cancelled 或明确进入 momentum 后才收尾；不累加惯性。释放后沿原型 100–180ms 目标完成/回弹，队列按实际手势顺序接续。无 90% 强制终点、无静默猜抬手。

## 失败模式与处理边界

- 浏览器 wheel 没有接触生命周期：macOS 本机阶段接入才提供该体验。其他平台保留现有兼容输入；本机接入断开时清理半翻页，不把静默兼容机制冒充原生能力。
- 启动未编译、端口被占用、辅助服务退出、临时令牌轮换、阶段丢失或队列溢出：限定本机来源、明确状态、停止旧手势；有限重连，不无限重试。辅助服务不安装登录启动项。
- 最初悬停/聚焦门控尚未打开：正文区域与纸边都能激活，不增加覆盖正文选词的透明层；键盘输入、缩放、弹窗、工具栏、笔记和译文不能翻页。
- 连续手势在前一页落地期间到达：压缩保存位移/意图，在 DOM 提交后才开始；切换文档/字号/布局/失焦/Esc 时清除队列，禁止晚提交。
- 书首/书尾/跨章：给出边界反馈，跨章后旧惯性不能作用于新章；边界手势反向撤回时不切章。
- 每条惯性日志覆盖真实失败且序列化影响性能：保留按手势汇总的首次响应、拒绝原因、释放与落页记录，惯性仅计数；不记录正文、键盘或其他应用活动，不写系统输入日志到磁盘。
- 高 DPI 画布或纹理过小：硬件 GPU 按实际 DPR（最多 3）绘制，纹理与画布分别测量；纹理边长受 GPU 上限约束，缓存最多 6 页、24M 像素。大窗口像素上限和软件 GPU 降级需显式记录，不改变静态 DOM 正文清晰度。
- 高清显存上涨/上下文丢失：缓存有界、避免销毁正在使用的纹理；失去 GPU 时恢复 DOM，可完成导航。预热只做相邻页，不截图整本书。
- 浏览器缩放/屏幕 DPR 变化：重新生成纹理，不复用低分辨率缓存。高清不是物理触控板验收，也不意味着曲面文字与静态 DOM 完全同样锐利。

## 验证与交付

不写单元测试。开发结束后运行正式完整 E2E（含既有兼容输入）及新增生产原生阶段 E2E：单/双页、停驻、真实结束信号 fixture、回滑、连续/交替、门控、跨章、取消/断连/路由与 DPR 1/2/3 画布和纹理。fixture 明确标记，不替代用户物理手感验收。保留首轮失败、最终 HTML/JSON、高清动画截图、运行环境与复现命令；不输出或归档本机连接令牌。
