# 分页体验反馈修复验收

修改前记录（2026-10-05）：

- 双页间距为 20px，页内左右各 36px，并有 24px 语法入口槽位；中间文字留白叠加。
- 卷页栅格化保留了 paragraph-actions；静止页克隆可触发 hover，隐藏操作在动画中泄漏。翻页后旧鼠标位置可能继续触发新页 hover。
- 选择整段只写入逻辑 anchor，移除了浏览器选区，没有绘制持久选中状态。

验收失败条件：

1. 收窄后正文/语法入口/书签被裁切，单双页测量不一致，翻页前后排版跳动。
2. 点击或键盘翻页时动画截图出现段落操作；翻页结束未移动鼠标也显示操作。
3. 鼠标实际移动/键盘聚焦后操作无法使用，控制进入隐藏状态仍能被点击。
4. 整段选中未着色、只高亮一页片段、带进中文注释，或不包含标点。
5. 选择另一段、取消选择、翻页、退出路由后残留旧高亮；字号重排丢失逻辑选区。
6. 精确拖选、查词、翻译与语法颜色被本次选区状态覆盖，或后台 AI 被误触发。

终验用隔离数据和本地 AI 模拟器完成交互与截图，保留首次失败、原始位置、重组原文及复现步骤；真实书籍只检查本机显示，不发起外部 AI。
