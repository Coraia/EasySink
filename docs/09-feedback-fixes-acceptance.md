# 2026-10-04：阅读反馈修复与验收

范围：现有 Web 原型，修复用户报告的五项问题，保留 15 个插件和真实用户数据。开发前的失败场景记录在 [08](08-feedback-failure-cases.md)。

## 行为变更

1. **保留注释不占自动预算**。原算法先排显式保留词，再以总条数截断，造成保留 B 时自动注释 A 被挤掉。现在分别计数；非重叠注释保持。同一位置的词组/单词仍只显示一个解释。撤销恢复此前 known/unknown/reset，而非统一删除原反馈。原文档位仍显示明确保留词。
2. **“多”扩大候选词范围**。原来只提高数量上限，词频门槛未变，示例已用完候选。现在密度大于 4 时按比例放宽词频门槛，仍排除功能词、已掌握词和被压制词；不为凑数重复注释。页尾说明保留词数量和候选不足。
3. **正文书签可撤销**。工具栏显示当前段落“书签 / 已加书签”，点击切换；段落左边显示可点击和键盘操作的标记。删除同时清理共享锚点；同段添加幂等、切换事务原子执行，删除同段历史重复记录。重绘、重开、禁用续读均保留定位。
4. **AI 与语音设置**。侧栏、阅读偏好、译文面板可进入 `#/ai`。文本模型支持 Chat Completions 兼容 API，提供地址、模型、凭据、启用、保存与连接测试。保存即时影响注释、翻译和后台任务，不需重启。连接测试验证接口可用，不评估解释或翻译质量。服务异常显示可读错误。
5. **可选自然语音**。接入兼容 `/audio/speech` 且支持 WAV 输出的服务，独立配置、试听、音色、语速、暂停/继续、停止。离开阅读器或侧栏时中止客户端请求并释放音频；迟到响应不能继续播放。缓存按原文、服务、模型、凭据、音色隔离，磁盘上限约 100MB；单段 1200 字符，单响应上限 8MB。服务错误明确显示，不自动切回本机。本机模式提供英文音色选择。

## 配置与开发接口

- `ai.py` 属于核心配置服务；`web/ai-settings.js` 属于设置页。`/api/ai/config` GET/PUT、`/api/ai/test` POST 继承本机访问锁。JSON 返回仅含 `has_api_key`，设置读取响应禁止缓存；配置校验不回显提交的凭据。
- 凭据保存在与用户库同目录的 `ai-settings.json`，原子写入、0600 权限；是本机受限文件，不是加密保管库。空 key 保留现有值；显式“移除凭据并关闭”清空。忽略于 Git。`WR_USER_DB` 隔离测试配置、音频缓存与真实数据；`.env` 仅作为默认值，保存 UI 配置后以 UI 为准。
- `tts` 仍为同一个可开关插件，新后端位于 `plugins/tts.py`，关闭返回 404。移除 `catalog.py` 注册项及前后端 tts 模块即可清退朗读，核心配置页不依赖启用此插件。
- `bookmarks` 同段事务切换接口为 `/api/bookmarks/toggle`；旧 POST 添加保留并变为同段幂等。前端通过 `draw` hook 恢复正文标记；标记不加入划词引文和朗读源文本。
- L1 缓存键新增服务地址，避免相同模型名跨供应商复用；模型注释标明来源。关闭文本 AI 后，待处理任务在分段检查点失败并可重新启用重试。已经发送的供应商请求可能完成，停止不会撤回已经发生的费用。

体验：打开 [原型](http://127.0.0.1:8766/)，侧栏进入 [AI 与语音](http://127.0.0.1:8766/#/ai)，分别填写服务信息、保存，执行“测试连接”或“试听自然语音”，再回文章生成注释/译文或朗读。

语音初始值为 OpenAI `gpt-4o-mini-tts`、`marin`。官方建议 `marin` / `cedar` 用于最佳质量；英文效果优先，也支持朗读指令，来源：[官方语音指南](https://developers.openai.com/api/docs/guides/text-to-speech)。其他兼容服务需自行填写实际支持的模型与音色；这里不声称已实现 Azure 专用接口、离线神经语音或实时逐词跟随。
