## What to build

从正式添加阅读入口导入 PDF，即刻形成可恢复的一个书籍归属，查看实际原版；重复文件、异常接收和重开行为都有明确结果。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 原件接收校验与书架/任务登记可恢复后返回，不等待全书 OCR；不点击开始阅读、刷新或响应丢失后仍找到同一书籍。
- [ ] 两个同时或重复的相同文件导入只有一个归属和任务，同名不同内容不误合并；原页不拆成多本书。
- [ ] 原版支持按需原页查看、缩放及标签；可用状态表示实际渲染，模型未就绪与文件不可读分别提示。
- [ ] 上传、资源读取和原版首屏有界，不把全书反复复制到内存；PDF 限额与旧格式原有限额/响应分离。
- [ ] 普通导入未配置 AI 也能执行，本机失败不外发；接收失败不留下假就绪书籍，旧格式目标回归保持。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
