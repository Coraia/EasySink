# 薄纸曲面修复原型

打开 `http://127.0.0.1:8766/static/prototypes/paper-shape/index.html`。

- 默认专注模式。鼠标按住右纸边向左拖，分别向上/下斜拖；左侧反向体验。
- 两指横向滑动仍使用既有本机接入：手仍贴着触控板时停住保持，回滑取消，抬手收尾。断开时显示“本机接入未就绪”，鼠标可用。
- 顶部展开工具层，点击“薄纸曲面原型”，可停在“常见斜翻”或“大幅斜翻”示例，按Esc或“返回阅读”退出。
- 工具层的样式图标可切换单页/双页；宽度不足时自动单页。双页纸面共用连续中缝。
- 重点观察：书脊保持连接、纸面舒展、文字不变成被拉长/挤压的扇形。拖过纸张可达位置会限位；这是原型需要一起体验的部分。
- 固定样例120页左右，随布局字体变化；独立localStorage前缀，不读取或写入正式书籍、笔记或进度。

`paper-model.js`只负责解析曲面、可达端点求解和沿卷曲线排列的网格；`page-curl.js`负责纹理、GPU绘制/光影和有界缓存；`native-trackpad.js`/`edge-drag.js`/`input-policy.js`沿用此前已验收的手势规则。原生接入只改为读取现有loopback配置接口，未新增监控器或权限。原型具有绘制记录下载，包含phase与模型/有效抓取点；真实触控板手感仍需人工验收。

本模型为平面/半锥面/平面组合的解析近似，可展开回材料平面；不是完整物理薄壳模拟器或论文复现。不会对已卷曲的自由面做书脊位置强拉。正常水平手势使用圆柱退化，纵向偏移进入圆锥；先保证整个内侧材料边处于固定平面。无法达到的位移投影到可达曲面，不能冒充原始指针百分之百可达。超小纵向位移0.35CSSpx以内使用水平退化以避免病态极细圆锥。

验收：`WR_E2E_EVIDENCE=outputs/paper-shape-reproduce npx playwright test tests/browser/paper-shape-prototype.spec.js`。它是原型套件；正式版存在尚未修复的扭曲红色回归，不能把原型通过写成正式版修复通过。
