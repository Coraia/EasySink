## Question

复用现有Web阅读核心，以最小可安装macOS客户端承载，能否在免开发环境启动的同时保持现有阅读手感、清晰度、记录完整性，并形成可接受的包体、启动和资源成本？

本票需通过实际原型回答：
- 用户无需预装Python/Xcode或运行终端命令，启动、打开书及基本词注可用；资源下载、安装占用和运行内存按应用／词库／OCR／语音分列，重模型不阻塞每次阅读。
- 先探索系统WebView承载，真实验证纸面纹理、字体、DPI、选区、翻页及原生手势，不能将浏览器历史成绩算作客户端实测。
- 原有Web阅读核心和记录语义保留；单／双页、跨范围、取消、接触停驻、连续／交替及收尾满足已确认适用守卫。
- 休眠唤醒、退出／重开、重复启动、端口／进程所有权及数据目录行为有证据；是否后台驻留由体验决定，不从Magpie直接复制。
- 给出冷启动／暖重开、完整资源成本、进程总内存／CPU的实测基线和建议预算，经用户体验后冻结；明确框架取舍和仍待正式分发阶段验证的签名、公证、更新及资料迁移。

收口依据：用户实际体验原型，接受承载方向和客户端预算；失败保留首例与可复现证据，必要时回到替代路线。此票不等于正式对外发布或整产品验收。
