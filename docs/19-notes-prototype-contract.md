# 笔记交互原型 · 2026-10-05

独立原型：`/static/prototypes/notes/index.html`。不调用生产笔记 API；演示记录使用独立的浏览器存储命名空间。`?session=…` 可隔离验收数据。

修改前列出的失败条件与验收约定：

- 底部入口默认显示笔记列表，不能重新出现空编辑大表单。六个连续图标区域维持现有 banner 的开关层级。
- 正文引用有轻微标识；段落外侧标记可打开本段笔记，多条笔记有数量，不能挤占正文或伪装成书签。
- 新选区创建新的记录，不能加载/覆盖旧笔记或未保存草稿；空白新建不落盘。
- 编辑必须明确针对指定 id；不改变引用、章节和位置。输入为空不得隐式删除旧笔记。
- 编辑卡靠近选区，受窗口边界限制；列表进入的编辑不跳阅读位置。引用摘要可展开，正文不需要重复大片展示。
- 自动保存显示保存中/已保存/失败；关闭前尝试保存，失败草稿可继续与重试。可在原型说明中模拟保存失败。
- 删除后列表、标识、底部数量同步，并允许撤销；删除当前编辑的笔记不能因未完成保存重新出现。
- 点击笔记引用定位并高亮原文，保留“回到刚才”；编辑本身不跳转。
- 单/双页、窄屏、重新加载后数据和草稿仍可读取；工具栏回切、Esc、外部点击不会误翻页。

只在原型完成后进行针对性浏览器 E2E；不写单元测试，不运行完整产品 E2E。保留首次失败、截图、观察值、源代码与复现步骤。

补充：笔记原型的选区菜单也须保留翻译、语法分析、书签、朗读、记一笔、取消选择。翻译/语法使用明确标注的固定样例或位置预览，不连接生产 AI；朗读在原入口切换播放/停止，单词音标也只在原入口显示。书签与笔记使用不同标识，各自可撤销/移除。窄屏工具菜单不得越界。
