## What to build

对 PDF 原文和原图留下笔记，在正文和底部入口管理、撤销和定位；书签与自动续读在重排、刷新和重开后仍对应原位置。

2026-10-08 执行更新：用户要求尽量并行、减少新增测试代码，以直接浏览器点击走查与性能记录验收；此约定更新父规格的自动化测试要求，转换依据、数据/费用约束及用户原型验收门槛保留。

## Acceptance criteria

- [ ] 文字笔记保存原文引用与来源，原图笔记保存图像及原页区域，不要求图像先 OCR 成文字。
- [ ] 新增、自动保存状态、编辑、删除撤销、正文标识、列表入口和跳回均可从实际 UI 完成。
- [ ] 书签可增加和撤销，续读区别于主动书签；换字号/单双页/窗口、跨原页和重开后来源正确。
- [ ] 旧笔记引文保持原始记录；重复引文和缺映射状态明确，不凭首个匹配猜测位置。
- [ ] 保存/重开经持久化闭环验证，原图引用和本书阅读痕迹不丢失，旧格式同类目标回归通过。
- [ ] 通过直接浏览器点击完成本票端到端走查，保存可复现步骤、截图、数值测量和首次失败；减少新增测试代码，不默认运行完整自动化套件。
