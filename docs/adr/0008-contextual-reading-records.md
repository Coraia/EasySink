# 收藏、掌握反馈与保留注释各自关联语境出现

2026-10-10，用户在 V1.1 对齐第一轮接受 Q2–Q4：收藏保留每次遇到的词句、原文语境与来源，同词可归组但不据拼写合并词义；掌握反馈只表达理解该次用法，保留注释只作用于该处且不隐含收藏或未掌握。相较于以词为单位覆盖全部记录，这一选择增加记录和来源管理的成本，但避免不同语境互相覆盖，以及把阅读偏好误当学习能力证据。第二轮 Q10 已确认以兼容的旧版偏好/判断承接旧数据，不伪造缺失的语境或意图；Q8 澄清后获确认，明确保留的注释继续显示，不因“已懂这里”而取消。2026-10-11 的 Q14 接受撤销恢复该操作前状态；没有此前反馈即回到未反馈，不推断为不懂、不改写旧记录来源。未来能力归纳仍另行设计。

第二轮 Q7、Q9 确认原文快照、解释和个人笔记分开：更新解释不改写引用，取消收藏不连带删除独立笔记；删除原件默认仍保留收藏快照，除非明确清理关联记录。这增加独立保留资料的成本，但避免来源修订、失去原件或取消收藏时连带丢失读者的摘录与想法；原文定位无法可靠恢复时明确标示不可返回，不猜测替代位置。

第二轮 Q6 经澄清后确认，重叠的句段摘录按划线取并集，独立的词语收藏不因被摘录包含而消失。合并时已有笔记与解释仍对应各自原来的子范围，而非自动成为扩展摘录的说明。这比只保存一条合并文本需要更多来源关联，但同时保留自然划线的体验与读者此前留下的不同意图。2026-10-11 的 Q12 明确每条划线是一个整体：不同范围只合并，不做局部擦除或拆分；相同范围删除整条，合并后菜单即切换为删除操作。牺牲局部擦除的便利，换取摘录身份与删除含义清晰；独立笔记和词语收藏不受删除影响。

2026-10-11 真人体验后的修订：用户明确接受逐词查询与点击整条划线不能同时占用同一点击手势。重新选取时，完全包含于已有划线的子选区（含相等）显示“删除划线”并删除整条；只有超出原范围才按并集扩展。“已懂这里”的界面名称恢复为“已掌握”，语境出现的作用域与保留注释独立性不变。语境解释恢复一键查询，不把上下文范围、选项或截取计划呈现为用户任务；后台仍保留实际输入及缓存身份。此段修订覆盖上文 Q12 的仅相同范围删除表述。
