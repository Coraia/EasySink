# 触控板跟手卷页

2026-10-07，停手收尾参数已更新，见 [收尾优化](33-trackpad-release.md)。替换上一版横向距离超过 80px 即自动播放整段翻页的实现。没有新增正文按钮或改变图标工具层。

## 交互

- 横向手势锁轴后启动一个 `ReadingPages.beginTurn` 预览。每次 wheel 累积位移，经纸页宽度换算为进度，调用同一个 `update`；原有 RAF/WebGL 负责纸张弯曲、背面、反光和投影。
- 原文 DOM、页码和位置锚点在整个手势期间保持。翻过半页也不提前提交；回滑减小进度，退到零停在原页，不在同一手势中改抓另一张纸。
- 连续 240ms 无输入视为手势结束（包含惯性尾部）。最终进度至少一半且最后有效输入仍朝前才完成，否则回弹。连续同方向累计达到 3px 的输入视为有效意图；每次只有 1px 的慢速回滑也会累计识别，交替的微小抖动不改变意图。之后再次有效向前可以恢复提交意图。
- 一次手势只结算一次。单页提交一页，双页提交一跨页。关闭动画/减少动态效果时保留同样的预览与提交判定，但不显示 GPU 动画。
- 缩放、选区、词卡、笔记、译文、工具面板不启动正文翻页。Esc、鼠标按下、打开工具、重排、离开页面、窗口失焦或隐藏会取消，清除结束计时器。

## 边界

章节尚未装入当前 Reader 时没有真实相邻页纹理：边界手势仍可回滑撤销，结束后才切章，**跨章节跟手卷页动画尚未接入**。不使用伪造内容填补。未完成的分页也在提交后走现有等待/导航逻辑。

Web wheel 不提供统一的手指离开与惯性阶段事件，以 240ms 无事件近似结束。浏览器 deltaX 决定方向，手指方向由系统自然滚动设置影响；真实 Mac 触控板手感待人工体验。

## 实现与清退

`web/reading-trackpad.js` 保持独立，只调用 beginTurn/update/release 与边界 adjacent；一个应用生命周期监听器维护输入流，当前手势仅保存当前 Reader，取消和释放后即清除。每个 Reader 首次使用注册一次清理钩子，避免每手势累积 closure。

`ReadingPages.canGrab(ownPreview)` 仅允许当前触控板会话继续更新，仍检查原有浮层/选区/排版边界。`finishAnimation` 通知输入模块取消；Reader dispose 显式结束预览、清除纹理等待计时器。结束判定和计时器统一从处理完成的同一基准计算，首次纸张准备耗时不再错误地算作停手；主动结算会撤销原定时回调，避免其迟到结算新的手势。关闭动画、原有点击、按键和纸边拖动沿用原路径。

删除 app 中触控板模块 import/安装调用即可停用；删除模块后可同时移除 pagination 的可选 trackpad 取消调用。无新的持久化表或用户数据迁移。

## 验证说明

[编码前失败清单](30-trackpad-follow-failure-cases.md)，[交付报告和重现命令](../outputs/wise-reader-trackpad-follow-20261007/RESULT.md)。

跟手时序测试关闭 trace 的 DOM 快照记录，因为录制开销会暂停测试驱动的 native wheel，造成大于 240ms 的间隔；使用真实 wheel、浏览器事件时间戳、折页 pin、源文锚点与中间截图验证。截图期间持续送微量真实 wheel 维持手势。其他 E2E 的 trace 仍保留，首轮带 trace 的失败也保留。软件 GPU 冷启动惯性自动注入仍出现大于 240ms 的实际空档，停止重试；该单次提交用例改为真实翻页预热后验证连续输入。慢回滑修复后，新书首次卷动用例也出现超阈值的注入空档；停止继续重试冷启动自动化。最后的跟手与惯性用例均明确预先通过真实翻页准备纸张，首次卷动的实际 Mac 手感保留为人工验收边界。

跟手渲染只在位移变化时请求 RAF，没有输入时不重复绘制。`curlMetrics.p95FrameMs` 在这种手势下包括人为输入/停手的间隔，不能当成 GPU 帧率；输入响应看 `p95InputMs`，连续动画帧率另由既有 12 次抓页测试检查。停手收尾另外记录无输入等待、纹理准备等待、收尾实际时长和最后输入至落页总时长。
